## 핵심 결정

- 최종 목표는 중요한 의료 VLM 한계와 해결 방법을 검증해 top-tier 기여를 만드는 것이다.
  연구실이 MRI를 연구한다는 사용자 정보를 반영해 MRI를 우선한다. 단순 MRI 점수 개선이 최종 목표는 아니다.
- MedGemma 1.5는 출발 baseline이지 반드시 성공시켜야 하는 대상이 아니다. 입력·정답을 검증한 뒤에도
  해당 과제의 기본 능력이 부족하면 같은 과제의 다른 적절한 VLM/전문 모델과 비교해 모델을 재선택한다.
  모델 교체 자체의 효과를 신규성으로 주장하지 않는다. 자원·라이선스·필요 권한은 기존 정책을 따른다.
- MRI 세부 부위·질환, 임상 협력자, 연구실 데이터 사용 권한은 아직 확인되지 않았다.
  공개 또는 이미 접근 승인된 자료를 기본으로 진행하며 협력자 답변을 자동 대기 조건으로 삼지 않는다.
  연구실이 MRI 연구실이라는 사실을 임상 정답·전문의·IRB·비공개 자료 사용 승인으로 해석하지 않는다.
- iter_055의 OCT/MARIO 후보는 사용자 우선순위 변경으로 보류한다. OCT 능력을 반증한 것이 아니다.
  RSNA·PadChest·MediConfusion의 유효 관찰과 checkpoint, 이전 자료·평가 실패 원본을 보존한다.
  기존 test/reserve를 탐색에 자동 소비하지 않는다. 과거 노출 여부와 분리 목적을 확인하고 유지한다.

## 다음 계획이 선택할 것

1. 위 상위 질문과 직전 관찰에서 검증할 경쟁 가설을 먼저 좁힌 뒤, 이를 구분할 MRI 과제 하나와 공개 정답을 고른다.
   부위·sequence·label 의미·독립 환자 단위·
   접근 조건·실제 입력 예시를 확인한다. 세부 부위 답변이 없으면 공개 자료와 명시적 정답의 준비도를 우선한다.
   대량 다운로드·전수 시각 감사·범용 benchmark 구축 전에 소수 실제 사례의 연결부터 확인한다.
2. 선택한 가설에 필요한 MRI slice/sequence의 근거 역할과 관측 충분성을 확인한다.
   단일/복수 sequence 또는 관측 범위에 따른 차이는 후보 개입이지 확정 가설·신규성이 아니다.
   모든 조건의 조합을 실행하지 말고 경쟁 설명을 구분할 최소 대조를 선택한다.
   단순 분류·segmentation만으로 과제가 끝난다면 VLM의 언어 조건·근거 연결·전이·효율 중 무엇을 연구하는지
   명시하고 전문 모델/모듈형 기준선과 비교한다. 타당한 질문이 없으면 억지로 VLM을 붙이지 않는다.
3. 먼저 정상 사용의 실제 모델 출력과 기본 능력을 확인한다. 다수 class prior/text-only와 영상 기반 답변을
   적절히 비교하고, 연구 label 범위의 오류를 개별 사례로 확인한다. 정답으로 고른 slice/region은
   diagnostic oracle로 분리하며 실제 사용 방법에 GT를 넣지 않는다. 양성 전용 자료에서 일반적 부재 판단을 평가하지 않는다.
4. 결과를 입력 손실·기본 인식 부족·정보 통합/판단 문제로 분리한다. 모델이 과제를 거의 못 하면
   복잡한 reasoning/faithfulness loss를 설계하지 않는다. 예측이 약하다는 이유만으로 MRI 전체도 기각하지 않는다.
   과제 의미에 맞는 기본 신호와 중요한 잔여 문제가 유효 리뷰에서 관찰되면 최소 개입의 method pilot을 검토한다.
5. 같은 질문의 한정 보완을 새 modality 탐색보다 먼저 비용·판별력으로 비교한다. 후속마다 한 관찰을
   설명/반박/미검증 중 무엇으로 바꿨는지 남긴다. 새로운 공개 자료 탐색을 끝없이 이어가지 않는다.

## MRI baseline의 공식 근거와 적용 범위

Google MedGemma 1.5 Technical Report §2.3.1, §3.2.1, Table 13:
https://arxiv.org/html/2604.05081v1

- MRI 학습과 brain/knee/abdomen의 질환 유무 평가가 있다. 지원 자체는 근거가 있으나 선택한 공개 과제의
  성능·일반화나 TOF 혈관 질환 정확도를 보장하지 않는다. 내부 평가의 정답 추출·미언급=음성 처리 한계도 구분한다.
- 공식 volume 경로는 axial 2D slice의 순서 있는 입력, volume별 min-max·동일 RGB 채널이다.
  논문의 학습·평가는 study당 최대 85 slice 및 초과 시 등간격 표집을 사용했다. 여러 sequence도 포함됐다.
  85는 연구에서 쓴 조건이지 아키텍처의 절대 한도가 아니다. 최초 baseline은 공식 조건을 우선 대조하며
  입력 수·정규화·orientation·sequence metadata를 바꾼 실험은 변경점과 손실 가능성을 별도 기록한다.
- 전체 3D를 한 번에 넣거나 더 많은 slice를 넣는 것 자체가 더 정확한 판독/새 기여라는 가정을 금지한다.
- root의 `1.dcm` 수동 TOF 실험은 실행 자산이며 정답 있는 성능 평가가 아니다. 임상 gold로 사용하지 않는다.
  legacy의 극소수 MRI pilot도 MRI 연구 전체의 반증이나 새 가설의 확증으로 사용하지 않는다.

## 사람에게 보고할 것

선택한 MRI 과제·자료·정답, 모델이 기본적으로 할 수 있는 것, 남은 관찰 하나, 다음 비교가 정할 결정을
짧게 보고한다. 준비/모델 적합성/현상 관찰/방법 효과/기여를 구분한다. 새 부위로 옮긴 것을 진전으로 포장하지 않는다.
