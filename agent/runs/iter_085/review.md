리뷰 대상은 1fad82e7d39c3468ffbbe27a5f94eaf6d32e0415다. owned source 5개 모두 작업 트리와 해당 SHA의 blob이 일치했고 unpreserved_paths는 비어 있다. 대량의 환경 파일 목록은 실제 코드 커밋 5개와 구분해야 한다. 체크포인트 보존은 실험 승인과 다르다.

# Key Findings

원시 outputs.jsonl에서 M15 16건, B0 16건, M1 8건, M1G_official 8건, C 34건을 확인했다. 총 82건 모두 저장된 최종 시도는 EOS 종료였고 조건별 ID 중복과 protocol digest 불일치는 없었다. 이는 완료된 요청의 검사이며 미완료 요청과 중단 비용을 포함한 전체 성공률이 아니다.

M15/B0/M1/M1G의 completion 봉인 hash를 직접 재계산해 일치시켰다. 초기 40건에는 record_digest가 없지만 파일 단위 봉인은 일치한다. M1G와 C의 42건은 record digest도 일치했다. C에는 completion이 없으며 34/240건만 저장됐다.

M15_concurrent_a/b와 resume_probe_v3의 원시 token을 단독 M15와 비교해 각각 16/16 일치를 재확인했다. cure_check/result.json의 공식·wrapper token 배열도 일치한다. strict adapter 검사 코드는 PEFT key·shape·값과 lm_head/embed_tokens를 실제 비교한다. 이 근거는 고정 입력의 로딩·출력 경로 확인이지 CURE 논문 전체의 재현은 아니다.

# Problems / Concerns

현재 과학적 결론을 막는 것은 D8 전체 검사, hybrid 결합, 최종 자료·정답·평가 잠금 및 E96의 미완료다. reference_review_notes.json에는 비정상 층 후보와 실제 양성 사실의 불일치, 시간 비교와 현재 상태 분리 필요성이 기록돼 있다. 후보 수를 적격 평가 환자 수로 사용할 수 없다.

기존 hf_cache/xet에 로그가 생성되고 초기 pip가 기본 캐시를 사용한 경계 위반이 있었다. cache_boundary_incident.json에 원본 보존과 원인이 기록됐고, 이후 실제 자식 환경의 보조 캐시 격리를 확인했다. 이 사건 자체를 모델 가설의 반증으로 해석하지 않는다.

최종 실행 지속성도 문제다. 도구 로그에서 격리된 CURE 재개가 출력 저장에 성공한 뒤, 구현자가 ‘implementation incomplete’를 이유로 소유 worker를 종료했다. 해당 종료 기록에는 새 외부 blocker나 사용자 deadline이 제시되지 않았다. 최초 캐시 문제에 대한 안전 중단과, 복구 후 승인된 실험을 끝내지 못한 최종 종료를 구분해야 한다.

최신 실행기는 초기 record_digest 없는 결과를 그대로 재개할 수 없다. 또한 GPU·source를 protocol에 고정해 GPU 변경 재개가 거부됐다. 기존 봉인 결과를 폐기하거나 원본을 고치는 대신 버전별 검증과 명시적인 후속 연결이 필요하다. required_checks_status.json은 중간 상태라 CURE strict 검사도 false로 남아 있으므로 최종 근거와 구분한다.

복수 worker의 출력 일치는 확인했지만 전체 처리량·긴 출력 지연·최종 peak와 worker별 안전 여유를 묶은 배치 선택은 미완료다. 낮은 utilization을 기각 근거로 삼지는 않는다.

# Interpretation

이번은 표본 변동 때문에 불확정인 유효 실험이 아니라 구현·평가 미완료다. 확정 소견 recall, 모순 비율, 의미 평가 민감도와 bootstrap을 계산할 자료가 아직 없다. 준비 성공이나 EOS 종료를 판독 정확성으로 해석할 수 없다.

이전 RSNA grounding 개선과 수동 판독의 제한된 관찰은 유지한다. 이번 결과로 새 limitation을 등록하거나 기존 주장을 승격·기각하지 않는다. 실제 성능 개선이나 재현되는 새 진단 결과가 없어 논문 추천은 보류한다.

# Strategy Check / 연구 방향 판단

**이어받는 관찰:** 위치 SFT의 grounding 개선은 확인됐지만 자유 판독의 언급 증가는 확정 회복과 구분되지 않았다. **남은 경쟁 설명:** 정답 회복, 불확실 표현 증가, 언급 성향, 단순 prompt 효과, CURE의 충분성이 모두 남는다. 이번에는 인증·환경 차단만 줄였고 과학적 설명은 줄이지 못했다.

실행 유효성은 일부 기술 검사에 한정된다. 성능 개선과 가설 지지는 미판정이며 신규 기여 가능성도 미확인이다. 현재 track 두 반복은 준비·실행 복구 단계이고 이를 유효 실험 두 회로 세지 않는다.

지배적인 재작업은 환경 호환 복구, 실행기 버전별 재개와 캐시 경계 보완이었다. 전체 준비 비용이 별도로 계측되지 않아 정확한 비용 비율은 주장하지 않는다. 이미 해결한 로딩 검사를 전부 반복하거나 새 후보로 이동하는 것보다, 남은 평가 연결을 마쳐 실제 대조를 얻는 정보 가치가 높다. 최소 방법 학습은 아직 근거가 없으며 이번 권고는 한정 실행 복구다.
