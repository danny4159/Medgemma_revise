# Problems / Concerns

현재 판독 효과 결론을 막는 것은 원천 이용·release 미확인과 모델 출력 부재다. 자료 감사 수치 자체를 무효화할 불일치는 발견하지 못했다.

새 i140_preflight.py는 이번 고정 감사의 증거 보존 용도로 한정 승인한다. source_use_basis와 eligible 상태 및 중단 gate가 고정되어 있어 이후 접근 문제가 해결됐는지 자동 판단하는 코드가 아니다. 상대 입력 경로를 포함하므로 기존 hash 검증은 research/ 작업 디렉터리를 기준으로 한다.

반입 실행기는 기존 결과 경로·영상 수 제한·presence 규약을 유지한다. 새 입력의 tensor·재개·worker 검사가 수행되지 않았으므로 전체 스냅샷은 승인하지 않는다. 자료 gate가 닫힌 상황에서 이를 미리 전수 복구하지 않은 것은 적절하다.

# Strategy Check / 연구 방향 판단

research_track은 mri-volume-evidence-use를 유지한다. 이번 plan과 iter_135 원 리뷰를 대조했으며, iter_064/133/136의 관찰 범위를 전체 판독 비교로 확대하지 않는다.

1. 중요한 문제: 같은 MRI 관측 범위에서 개별·인접 처리와 직접 적응이 소견 누락·모순을 줄이는가라는 질문은 유지한다.
2. 현재 근거: 이전에는 이용·release 연결이 미확인이었고 이번에도 해결되지 않았다. 추가 증거는 접근 요건과 로컬 자산 상태이며 새 모델 관찰은 없다.
3. 쉬운 해결책: 개별 처리+고정 통합, 입력별 직접 SFT, AutoRG의 충분성은 모두 미검증이다. 전문 모델 자산 보존은 성능 검증을 대신하지 않는다.
4. 남은 설명: 입력 범위와 정답의 적합성부터 미확정이다. ISLES 원자료는 native space이므로 mask와 FLAIR가 같은 공간이라고 가정할 수 없다. 임상 정답을 추정 생성하지 말고 공식 연결이 지원하는 범위를 먼저 확인해야 한다.
5. 다음 결정: BraTS 동일 감사는 종료한다. 공개 원영상과 RadGenome 보고서가 모두 확인된 ISLES22의 연결 여부를 한정 검토한다. 성립하면 실제 비교, 불성립이면 구체적 접근 결정 요청으로 끝낸다.

실행 유효성은 감사에만 한정되고 성능 개선·가설 지지·신규 기여는 없다. 두 번째 감사 시간 20.68초는 전체 준비 비용이 아니며 첫 실패와 수동 조회를 포함한 총시간은 미계측이다. 신규 모델 요청·학습 update·3D 출력은 모두 0이다. GPU를 쓰지 않은 이유는 자료 blocker이며 낮은 utilization에 대한 감점은 없다. 이후 실제 비교가 성립하면 원 자원 정책의 처리량·메모리 검증을 수행해야 한다.

# Recommended Next Experiment

한정 보완으로 RadGenome ISLES22의 원영상 ID–sequence–보고서 대응과 공간 연결을 먼저 결정한다. 뇌종양에서 뇌졸중 자료로 바뀌는 점을 명시하되 동일 관측 판독 질문을 유지한다. 공개 자료 존재만으로 적합성을 승인하지 않는다.
