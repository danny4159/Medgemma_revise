- 결과: 흉부 X-ray의 CURE/MSPC 차별 포착 오류 13개를 비교했으며, 5개는 대체 주석에서 오류가 사라지고 4개는 비교 주석이 없었다.

- 대안: 교정 후보를 삽입하지 않고 현재 오류 검토 투자를 보류할 수 있다. 추가 비용은 줄지만 교정·보존의 판별 가능한 설계 여부는 미확인으로 남는다.

# Assessment

실제 구현 담당은 Claude이며 engineer_backend.json과 claude_meta.json에 Sonnet/medium, 실제 모델 claude-sonnet-5-5가 기록돼 있다. 리뷰 SHA는 `5e825563e85b4eceb93c2cf3b4a6c47b5359228d`다. 신규 소스 5개의 commit blob과 작업 파일이 일치하고 unpreserved_paths는 없다. 계획·구조화된 contract·변경 diff·소스·결과·관련 도구 기록을 확인했다.

새 추론·학습 없이 저장 출력으로 질문을 실제 검토했으므로 valid_experiment=true다. 독립 환자 재현이나 인과 실험은 아니다. 구현 보고서의 음성 탐색 해석은 좁혀야 한다. 현재 자료가 특화 가설을 확립하지 못했다는 결론은 지지되지만, 단순 요인으로 충분히 설명됐다는 결론은 지지되지 않는다.

# Key Findings

리뷰에서 `python -B nr115_verify.py`를 쓰기 없이 실행했다. production 기하 모듈과 독립인 좌표 격자 구현으로 87개·68명·오류37개·K22, 포착16/15/13, 차별7/6·공통9·미포착15, 판독자 불일치26·대체 주석 부재16 및 주요 행별 기하값의 일치를 재현했다.

현재 provenance를 다시 계산해 원시 입력 60개 파일, 영상69개, 제외 전 ledger88행의 연결에 문제가 없음을 확인했다. completion/protocol/verify의 등재 digest도 모두 일치했다. 기존 범위 밖 MG box 1개 제외는 유지됐다. 불변 입력의 과거 후처리 검증은 iter_114의 근거를 계승했으며 신규 logits 후처리나 bootstrap을 반복하지 않았다.

CURE-only 7개는 일부 저coverage 4개·모든 영역 대응 후 면적 불일치 3개다. MSPC-only 6개는 각각 4개·1개와 빈 MG 예측 1개다. 일부 저coverage는 두 집합 모두에서 흔하므로 MSPC만의 고유 유형이라는 근거는 없다. 반대로 전체 오류 중 13/37이라는 빈도만으로 두 집합의 분포가 같다고 결론낼 수도 없다.

CURE-only 3개에서는 CURE가 빈 출력을 냈다. 이는 고정 불일치 점수의 빈 집합 처리 분기이며 두 비어 있지 않은 위치 출력의 기하 차이와 구분해야 한다. 나머지 4개는 순위18/19/21/22다. 경계 근접은 관찰이지 선택 차이의 원인 증명이 아니다.

13개 사례의 공식·대체 주석 비교는 오류 해소5·부재4·유형 변경2·유지2였다. CURE-only에서 동일 유형 유지 사례는 없고, 유지된 두 사례는 MSPC-only다. 소수 집합과 주석 의존성을 넘어 일반적 차이를 주장할 근거는 부족하다.

# Problems / Concerns

현재 수치와 제한된 보류 판단을 무효화하는 blocker는 없다. 다만 계획 준수에는 제한이 있다. 네 선택 집합별 비오류 요약은 두 집합으로 합쳐졌고, 사례별 반대 설명 서술과 13장 전체의 육안 점검은 완료되지 않았다. 87행과 13행의 대응은 보존돼 있어 제한된 기하 진단은 가능하지만 전수 사례 해석 완료로 표현하지 않는다.

실행기에는 재사용 결함이 남는다. `sha_prov_changed(prov, proto)`가 현재 prov를 무시하며 seal도 새 provenance 전체와 저장값을 비교하지 않는다. 실제 의존 파일 일부가 잠금 목록에서 빠져 있다. 현재 입력은 재검사에 통과했으므로 이번 결과의 무효 사유와 구분한다.

부분 저장 후 안전한 재개도 입증되지 않았다. 시험은 덮어쓰기 거부를 확인했을 뿐이다. 최초 analyze의 overlay 디렉터리 부재 오류는 수동 디렉터리 생성으로 복구됐지만 실행기 자체는 보완되지 않았다. 보조 통계는 봉인 이후 추가됐고 import 시 결과를 쓰므로 전체 스냅샷 재사용은 승인하지 않는다.

단계별 비용 측정은 누락됐다. 세션 duration 약307초를 연결·사례 해석·검증 각각의 비용으로 나눌 수 없다. GPU 미사용은 승인 범위에 따른 것으로 실행 결함이 아니다.

# Interpretation

이번에 줄인 불확실성은 차별 포착 사례의 구체적인 구성이다. CURE 빈 출력 분기와 주석에 따른 오류 해소가 상당 부분 포함돼 있음을 확인했다. 그러나 면적·개수·두 번째 모델 정확도가 차이를 충분히 설명하는지 통제한 비교는 없다. 따라서 현재 특화 투자 보류와 가설 기각을 구분한다.

공개 box가 뒷받침하는 것은 고정 MG 출력의 위치 주석 정합성이다. 미표기 영역의 임상 정상 여부, 환각, 임상 오진 또는 자유 판독 정확성은 판정하지 않았다. iter_114의 A/B 불확정과 iter_113의 제한적 양성 관찰을 소급 변경하지 않는다.

# Strategy Check / 연구 방향 판단

**시험 설정:** 현재 순위·threshold·검토율의 확대와 최적화를 보류한다. 같은 13개를 다시 분류하거나 유형별 점수를 맞추지 않는다.

**연구 관찰:** 기하 구성과 주석 민감성은 새로 확인했다. 주석에 안정적인 CURE 특화 실패 조건과 단순 대안의 충분성은 미확인으로 남는다.

**연구 질문:** 이번 분석만으로 CURE 고유 방법 개발의 투자 가치를 확보하지 못했다. 실행 유효성은 확보됐지만 성능 개선·핵심 가설 지지·신규 기여는 확립되지 않았다. 지배 작업은 저장 자료 연결과 검증이며 단계별 시간은 미측정이다.

**최신 삽입 지시가 없었을 때의 권고:** 현재 CURE 특화 오류 검토 투자를 보류하고 승인·피드백을 기다린다. 같은 자료 분석이나 새 모델 비교를 자동 발주할 근거는 없다. 이 판단을 복귀 기준으로 보존한다.

**삽입 지시를 반영한 실제 선택:** 후보는 현재 불일치 분석의 연장과 오류가 섞인 근거를 이용한 교정·보존의 한정 검토 두 가지다. 전자는 새 판별 근거가 부족해 선택하지 않는다. 후자는 사용자 지시에 따라 한 번의 적합성 검토와 조건부 최소 비교를 제안한다. iter_047/053은 본평가 미실행이며 교정 전체의 반증이 아니다. 반면 iter_100/101의 제한된 회복과 초안 유지의 강함, iter_102/103의 정답 연결 부족은 반드시 반대 근거로 이어받는다. 이는 교정 후보의 유망성 확인이나 방법 개발 승인이 아니다.

# Recommended Next Experiment

사용자 승인 후 별도 계획에서 질문을 하나로 고정한다: 오류가 섞인 외부 근거가 있을 때 공개 정답으로 확인 가능한 소견의 잘못된 판단을 고치면서 맞는 판단을 보존하는가? 초안 유지와 근거 없는 직접 판단, 실제 지원되는 강한 기존 교정 대안 이후의 잔여 가치를 확인한다.

가까운 기존 방법이 해결한 범위, 공개 양성·음성 정답과 필요한 위치 정답, 실제 입력 경로를 먼저 한정 점검한다. 성립할 때만 같은 계획의 작은 비교를 수행하도록 표본·요청량·예산·종료 조건을 사전에 정한다. 과거 oracle gate를 소급 완화하거나 100% oracle 성공을 새 보편 gate로 복사하지 않는다.

적합성이 없거나 기존 대안이 충분하면 준비·평가기 정비를 반복하지 않고 종료한다. 복귀 대상은 이미 보류한 CURE 특화 투자 판단이며 존재하지 않는 후속 실험을 만들어 재개하지 않는다. 새 방법 학습과 한정 검증의 연장은 자동 승인하지 않는다. 모든 다음 반복은 --confirm-each-iter 사용자 승인을 기다린다.

이번 결과는 특화 방향의 긍정적 후속 탐구 근거를 확립하지 못했으므로 논문 추천은 보류한다.
