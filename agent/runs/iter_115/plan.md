# Proposed Experiment

## 1. 입력 연결과 규약 고정

새 결과는 research/results/iter_115/에 저장한다. analysis_r1/result_final/report.json·per_item.json, ledger_final.json, data/items.json·raw_manifest.json, runs_init.json·runs_expand.json이 가리키는 원시 출력과 원 주석을 읽는다. r0는 사용하지 않고 기존 범위 밖 MG box 제외1개를 복귀시키지 않는다.

상세 사례 열람 전에 아래 분류 규약과 계산 설정을 저장한다. 이미 집계 결과를 본 사후 규약이며 사전등록·눈가림·독립 확인으로 부르지 않는다. 유형은 MG 대 주석으로 정하고 검토 목록 이름으로 바꾸지 않는다.

기하 유형은 공식 주석과 대체 주석 각각에 동일 적용한다. u_j=area(M∩g_j)/area(g_j), t=0.3을 사용한다. 이 t는 설명용 대응 기준이며 원 union IoU 오류 정의를 대체하지 않는다.

1. 빈 예측: M이 빈 집합.
2. 전체 비중첩: M은 있으나 주석 합집합과 교집합 면적이 0.
3. 주석 영역 일부 저coverage: 주석 box가 2개 이상이고 u_j≥0.3인 영역과 u_j<0.3인 영역이 함께 있음. 이를 곧바로 임상 병변 누락이라고 부르지 않는다.
4. 모든 주석 영역 대응·면적 불일치: 모든 u_j≥0.3이지만 원 union IoU<0.3. 과대 영역/경계 차이 후보로만 기술한다.
5. 나머지 중첩·저coverage: 위 조건에 속하지 않는 양의 중첩. 억지로 경계/다른 병변으로 재분류하지 않는다.
6. 계산/연결 불가: 유효하지 않은 연결이나 좌표. 임상적 모호함은 별도 설명란에 남긴다.

주석 box가 중첩되면 일부 저coverage를 분리된 복수 병변의 누락으로 읽지 않는다. 각 사례에 box 중첩 여부와 u_j 원값을 함께 보존한다. 결과 방향에 맞춰 t·범주·우선순위를 바꾸거나 cutoff sweep을 하지 않는다.
