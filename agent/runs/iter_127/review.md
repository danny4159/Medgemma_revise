이번 중단은 원 계획의 입력·전문 비교군 검사 실패 분기에 해당한다. 결과를 본 뒤 환자나 입력을 소급 교체하지 않은 판단은 적절하다. 다만 영상 부위를 공식 모델 반복 실행보다 먼저 확인했다면 일부 복구 비용을 줄일 수 있었다.

# Key Findings

1. `data/selection_lock.json`, `ordered_candidates.json`, `judgments.json`에서 네 층의 첫15명과 역할8/12/40을 독립 재계산했다. 판단 기록은98명이며 실제 선정 검산 실행은325/325 통과했다. 이는 의미 규약·순서 검사의 근거이지 전문가 임상 정답 인증이 아니다.
2. `diagnostics/*_U_diagnostic.png`와 두 `*_other_series_readonly.png`를 직접 열었다. 7ISDTZ2JVG의 선택 영상은 몸통·척추, PCKMK46BRL은 경부·척수이고, 대체 영상에서는 두개 내 뇌 단면이 확인된다. 작은 spacing 우선 선택은 해부학적 적합성을 보장하지 않는다.
3. UCL 및 FreeSurfer 실행에서 7ISDTZ2JVG의 foreground는0으로 기록됐다. 공식 ICV는36.053/36.054mm³, 우측 측뇌실 부피는0이다. 이 비뇌 입력의 출력을 유효한 전문 점수로 사용하지 않았다. 함께 실행한 5SWPQWD3DD는 실패 시 동료 작업 종료로 returncode -15가 기록되어 완료된 정상 대조로 취급할 수 없다.
4. 신규 MRI 다운로드는0이다. ZIP 합집합114개·15,552,030,509 bytes 및 남은7,159,760,618 bytes를 독립 재계산했다. 현재는 나머지 자료를 내려받지 않은 상태다.
5. 봉인 산출물74개·기존 결과27개·소스9개의 hash를 직접 재계산했고 불일치는0이었다. 코드 보존은 확인했지만 전체 스냅샷 재사용 승인은 아니다.

# Problems / Concerns

현재 결론을 막는 문제는 비뇌 입력 연결과 본 비교 미실행이다. MedGemma 생성·calibration·BA·AUROC·paired CI는 없으므로 성능 수치를 검산할 대상도 없다.

원시 resources 로그를 재집계한 최초 pilot의 최소 GPU 여유는 양쪽1512MiB로2GiB 기준에 미달했다. 후속 fs_compat_pilot은3750/3824MiB로 회복됐다. 그러나 최종 실행기의 시작 검사는 free>=20000MiB에 그쳐 설정한20000MiB와 추가 안전 여유를 함께 보장하지 않는다. peak 집계 수정본도 새 실행 검증이 없다.

QC 검사에는 필수 key와 비어 있지 않다는 조건이 없다. 단계 재실행은 완료 결과의 안전한 재사용보다 재실행·배타적 completion 생성에 의존한다. 현재 실패 판정을 바꾸는 결함은 아니지만 후속 재사용 전에 필요한 경로만 수정해야 한다.

weight 검사 로그에는 CPU 검사 설명과 달리 양 GPU device 초기화가 나타난다. 실제 weight 배열 비교는 통과했으나 자원 사용 설명과 구현을 맞춰야 한다.

# Interpretation

이전 iter_126의 보고서 선정 문제는 기록과 순서 측면에서 보완됐다. 추가 증거는 선택한 영상의 해부학적 대상이 틀렸다는 사실이다. 따라서 이전 zero mask를 전문 모델의 뇌 MRI 실패로 해석하는 설명은 지지되지 않는다. 올바른 뇌 입력에서 공식 ICV/QC가 성립하는지는 아직 모른다.

실행 유효성은 미충족, 성능 개선과 sampling 가설은 미검증, 신규 기여 가능성은 미확정이다. 기존 MR-RATE FLAIR 전원 PRESENT 관찰은 이번 T2 준비 실패와 별개로 유지한다. 새 limitation 상태 갱신이나 마일스톤으로 기록할 결과는 없다.

# Strategy Check / 연구 방향 판단

연구 연결은 `mri-volume-evidence-use`, iter_123~127이며 직전 판단은 iter_126/review.json과 이번 계획의 질문 카드다.

1. 중요한 문제: 제한된 MRI 관측에서 필요한 구조를 선택하면 판단이 회복되는가라는 질문은 유지한다.
2. 현재 근거: 선정 결함 보완에 이어 입력 부위 오류가 확인됐다. VLM 출력 관찰은 추가되지 않았다.
3. 쉬운 해결책: 같은 study의 실제 뇌 series 연결이 우선이다. 전문 부피+threshold의 충분성은 여전히 비교해야 한다.
4. 남은 설명: 입력 오류는 확인했지만 올바른 입력의 segmentation·native slice 충분성·기본 인식·sampling 기여는 미분리다. 이를 구분하는 최소 후속은 기존 뇌 series로 기술 검증 후 원 U/A/S 비교를 수행하는 것이다.
5. 다음 결정: 현재 결과를 실행 실패로 보존하고 별도 한정 수정 계획을 허용한다. 기술 조건이 성립하면 실제 비교까지 완료하고 실패하면 보류한다. 감사만 수행하는 반복은 권고하지 않는다.

준비와 재작업이 아직 실험 진전을 막고 있다. 공식 추론이 진행된 두 단계 wall-clock 합은246.05초지만 선정·설치·진단을 포함한 총비용은 미계측이므로 지배 비용의 비중을 정량 주장하지 않는다. 유효 실험0회를 세 번의 가설 반증으로 간주하지 않는다.

# Recommended Next Experiment

고정60명의 보고서 정답과 역할을 유지한 채 뇌 T2 적합성 규칙을 사전에 명시하는 한정 보완을 권고한다. 같은 규칙으로 전체 입력 연결을 확인하고, 기존 순위 규칙은 적격 뇌 series 안에서 적용한다. segmentation 성능이나 VLM 정답률을 보고 series를 선택해서는 안 된다.

기술8명의 실제 영상 적합성·공식 출력·좌표 연결을 먼저 확인한다. 통과하면 원 계획의 생성 설정·처리량 비교·calibration12·탐색40 비교까지 한 실행에 묶는다. 성립하지 않으면 현재 설계를 보류하며 추가 설치·모델·prompt 순회로 연장하지 않는다. 이번 결과나 과거 중단 판정을 다시 쓰지 않는다.

논문 추천은 보류한다. 이번에는 유효한 성능 개선이나 재현된 모델 진단 결과가 없다.
