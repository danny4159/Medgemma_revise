# Problems / Concerns

현재 제한된 수치와 투자 종료 결론을 무효화하는 blocker는 없다. 다만 구현 보고서의 다음 문구를 정정한다.

- PRESENT는 404건 또는 405건이 아니라 403/405다.
- raw/final 첫 줄 차이는 전체 0건이 아니라 NONE에서 45건이다. 이는 thought 표식으로 시작하는 원문과 UNKNOWN final의 구조적 차이이며 임상 모순은 아니다.
- NONE은 전부 UNKNOWN이므로 영상 유무에 둔감한 PRESENT라는 설명은 틀렸다. 영상 제거와 명시적인 무영상 안내가 함께 바뀌어 픽셀의 인과적 활용도 따로 입증하지 않는다.
- 공식 MSD 이용 조건은 계획과 보존 dataset.json에서 CC-BY-SA 4.0으로 확인된 범위가 있다. 이를 RadGenome 연결·학습 노출 미확인과 섞어 전부 미확인으로 되돌리지 않는다.

원 기술 gate는 SIGKILL된 시도도 result 파일을 남긴다고 가정해 실패했다. 도구 로그와 코드에서 기술 출력 후 `i136_gate.py`가 추가됐음을 확인했다. 실제 12/60 중단, completion 부재, 재개 완료와 token 동일성이 있고 EOS100%·유효율95%·NONE 포함 분모는 유지됐다. 계획이 허용한 한정 구현 결함 수정으로 인정하며 사후 과학 문턱 완화로 보지 않는다. 원 실패와 수정 이력은 유지한다. 다만 다음 실행 전에는 원시 근거를 재검사하는 단일 사전 gate로 정리해야 한다.

# Strategy Check / 연구 방향 판단

1. **중요한 문제:** 추가 관측에서 얻은 정보를 공동 판독이 보존하는가라는 질문은 유지한다. 현재 상태 출력에는 이를 판별할 기본 신호가 부족하다.
2. **현재 근거:** 이전에는 자료·출력 계약이 blocker였다. 이번에는 실제 450출력과 완결성을 확보했다. 새 근거는 거의 고정된 상태어와 일부 명시적인 부재 설명의 공존이다.
3. **쉬운 해결책:** 개별 OR도 BA0.500으로 현재 질문을 해결하지 못했다. 전문 segmentation+OR의 과거 우위는 정보량·지도 조건이 달라 현재 동일 정보량 비교로 옮기지 않는다.
4. **남은 설명:** 기본 인식 부족, annotation과 가시성 차이, 질문·상태어 출력 연결 문제가 남는다. 설명문 사례는 기본 인식 부족 하나로 결론내리는 것을 막지만 새 방법 필요성을 입증하지는 않는다.
5. **다음 결정:** 현재 frozen 장수 비교는 종료한다. 상태 출력과 내용의 불일치를 구분하는 단일 대조에 정보 가치가 있는지 한정 판단한다. 양성이어도 방법 full이나 독립 일반화를 자동 승인하지 않는다.

실행 유효성은 확인, 성능 개선은 없음, 통합 손실 가설은 미판정, 신규 기여 가능성은 미확보다. 준비·재작업 비용 전체는 미계측이다. 이번 main launch wall은 약438.6초다. 기술 비교의 loading 포함 wall은 2 worker125.6초, 4 worker94.0초이며 처리량은 28.66→38.31요청/분이다. 생성 구간만 비교하면33.05→46.65요청/분이다. GPU 전체 peak는 약17,986/17,913MiB로 2 worker당4GiB 여유를 둘 수 있었고 출력 token 동일성을 확인했다. 보고서의 2-worker150초와 생성 처리량을 같은 측정 구간으로 혼용하지 않는다. 재개 비용은 중단 시도 누락 때문에 전체 비용으로 쓰지 않는다.

# Recommended Next Experiment

한정 보완으로 현재 원문에서 확인한 상태–설명 불일치를 구분하는 단일 출력 인터페이스 대조를 검토한다. 같은 pixels·정답·생성 조건을 유지하고, 과거 단독 판별 신호를 대조 설계의 근거로 사용하되 과거 점수를 현재 인과 대조로 대체하지 않는다. 상태 출력 회복과 실제 내용 정확도는 분리한다. 원 결과를 재채점하거나 prompt grid를 순회하지 않는다. 회복 근거가 없거나 정답 의미가 계속 판단을 막으면 현재 존재 인터페이스 투자를 종료한다.
