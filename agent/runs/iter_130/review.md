5. 고정 공식 renderer는 modality·plane 이름에 맞는 첫 파일을 선택한다. 단일 slice 기본값은 중앙이며, `multi_slice_contiguous` 구현은 전체 depth의 균등 index를 사용한다. 대상 병변 가시성을 보장하는 선택 규칙이 아니다.

# Problems / Concerns

현재 자료 감사 결론을 무효화하는 오류는 발견하지 못했다. 다만 `comparison_eligible=false`는 현재 자료 구조와 원문에 근거한 명시적 판단으로 코드에 들어가 있다. 검사 통과 자체가 임상 부적합성을 독립 증명하는 것은 아니다. 본 리뷰는 실제 원행과 3개 cross-sequence 그룹을 확인해 보류 판단을 별도로 검토했다.

단일 sequence 행이라는 사실만으로 비교가 불가능한 것은 아니다. 여러 행을 묶는 대안까지 검토했을 때 동일 병변·sequence별 정답과 관측 연결이 부족하다는 점이 핵심이다. 병변 좌표 부재만을 모든 후속 탐색의 필수 실패 조건으로 일반화하지 않는다.

L2.4 정답·rubric 258행을 열람했다. 공식 test 명칭을 유지했다는 사실과 향후 독립 확인 가능성은 별개다. MR-RATE train과 겹쳐도 이번 설계 선택에 사용한 정답의 노출 이력은 사라지지 않는다.

전체 스냅샷의 기존 코드까지 검증한 것은 아니므로 재사용 승인은 세 metadata 감사 소스에 한정한다.

# Interpretation

이전 판단은 실제 L2.4 행을 확보하지 못해 자료 적합성이 미확인이라는 것이었다. 추가 증거는 원행·환자 연결·단일 신호 bucket 구조와 cross-sequence 사례의 근거 불일치다. 현재 판단은 접근 실패가 아니라 **현재 공개 정답으로 계획한 비교를 구성하기 어렵다는 자료 적합성 판단**이다.

적격 비교 0개는 모델 성능 수치가 아니다. 기존 MedGemma/Qwen FLAIR 및 MedGemma T2 고정 응답 관찰은 그대로 유지한다. 이번 결과는 그 원인을 설명하거나 반박하지 않는다.

최종 확보 파일은 3,906,171 bytes다. 성공 fetch 경로는 약3.79초, 감사 실행은 약0.92초로 기록돼 있다. 최초 실패·재전송·구현·검토 전체 비용은 계측되지 않아 이 수치를 총비용이나 지배 비용으로 쓰지 않는다. 계획대로 GPU 요청·학습·MRI 다운로드는 0이며, 핵심 자료 조건이 실패한 상태에서 모델을 실행하지 않은 것은 타당하다.

# Strategy Check / 연구 방향 판단

연결: `mri-volume-evidence-use`, iter_130 계획 카드와 iter_129 원 리뷰. 기존 MRI 관찰은 유지하고 새 L2.4 후보의 자료 적합성만 갱신한다.

1. **중요한 문제:** 개별 신호 인식과 여러 MRI 근거를 함께 사용할 때의 손실을 구분하는 질문은 남는다.
2. **현재 근거:** 기존 고정 응답은 실제 모델 관찰이다. 이번에는 자료 구조가 확인됐으며 L2.4 결합 실패는 여전히 미검증이다.
3. **쉬운 해결책:** sequence별 판독+고정 결합은 타당한 대조 후보지만 현재 자료로 정답을 구성할 수 없다. 전문 모델·분류기의 충분성도 이번에 평가하지 않았다.
4. **남은 설명:** 기본 인식·부분 관측·질문 인터페이스·약한 정답의 기여는 미분리다. 같은 metadata 재조회는 이를 줄이지 못한다.
5. **다음 결정:** 현재 L2.4 설계를 보류한다. 기존 자료와 원 관찰에서 판별력 있는 최소 비교가 성립할 때만 새 실행을 계획한다. 없으면 준비 반복 대신 근거 부족을 명시한다.

실행 유효성은 자료 감사 범위에서 확인됐다. 성능 개선은 측정하지 않았고, 모델 가설 지지와 신규 기여 가능성도 확인하지 못했다. 이번 준비 결과를 유효 모델 실험 횟수나 method gate 근거에 더하지 않는다.

# Recommended Next Experiment

현재 L2.4 비교에 대한 추가 실험은 권고하지 않는다. 다음 계획은 승인된 MRI 범위에서 실제 정답·관측 연결과 강한 단순 대조가 있는 비교 하나를 선택하거나 보류하는 것으로 끝낸다. 새 후보를 고를 경우 무엇을 입력하고 어떤 출력 차이가 경쟁 설명을 구분하는지, 양성·음성·불확정에서 투자가 어떻게 달라지는지 명시한다.

L2.4 재개에는 같은 대상의 sequence별 원 정답과 실제 관측 연결, 개발·독립 확인 구성의 새로운 근거가 필요하다. 단순 scalar bucket을 질환의 전형적 신호로 보충하거나 선택지를 역추정해 정답을 만들지 않는다. 동일40명 조건 순회·SynthSeg 누락 복구·자동 LoRA 확대는 이어가지 않는다.

유효한 모델 실험에서 후속 탐구의 긍정적 근거를 새로 확인하지 못했으므로 논문 추천과 마일스톤 등록은 보류한다.
