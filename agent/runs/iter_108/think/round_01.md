# 핵심 판단

iter_107의 자연 다중 영역 부분 누락 개입은 보류를 유지한다. 다음 후보는 **원본 context를 보존한 국소 근거 제공의 판단 가치**를 우선 검토하고, **기존 위치 학습의 다른 판단으로의 전이**를 두 번째 후보로 둔다. 아직 실행 가능한 자료·평가와 선행 이후의 잔여 가치를 함께 확정하지 못했으므로 Claude 구현으로 넘기지 않는다. 다음 사고는 같은 iter_108 안의 투자 결정이며 별도 전략 iteration이 아니다.

## 원문에서 확인한 사실

- `agent/GOAL.md`, `iter_107/review.md`, `iter_016/017/018/053/092/094/097/105/review.md`, `iter_102/plan.md`와 기존 `iter_084/105` 조사 기록을 읽었다.
- iter_107은 핵심 10명에서 CURE의 두 영역 보존 10/10, 부분 누락 0이다. 이 반대 근거를 받아들인다. 비핵심 재분류·threshold 변경·표본 교체는 선택하지 않는다.
- iter_016에서 형식 정규화 후 B0−M0 차이는 −0.255에서 −0.0317로 줄었지만 category별 차이는 남았다. `LIMITATIONS.md`의 해당 observed 항목과 사용법 검사도 확인했다. 일반적 forgetting이나 전이 부재의 증거는 아니다.
- iter_017에서 검출 정보의 효과는 있었지만 좌표 추가의 주지표 이득은 없었다. iter_018에서는 범위 안내를 더한 조건의 손실이 불확정이었다. 따라서 단순히 외부 근거를 더 제공하는 반복이나 무관 근거 제거만으로 해결되는 과제는 재개할 가치가 약하다.
- iter_092/094/097은 위치 출력, 판독 출력, NLL이 함께 움직이지 않는 제한된 관찰을 제공한다. 그러나 report-only baseline 부적합과 의미 평가 문제가 남아 있어 추가 LR·epoch·seed를 처방할 근거가 아니다. iter_097은 저LR 학습 약 4.37시간을 기록했다.
- iter_105의 독립 grounding 연결 32/32는 직접 A/B 선택 능력과 다르다. 낮은 영상 기여와 형식 의존 때문에 이를 충분한 인식 이후 제안 손상으로 읽지 않는다.
- iter_102는 선택적 수정·불일치 시 무수정이 기존 방법에 포함됨을 이미 확인했다. P001/P002의 임상 정답 부족도 해결되지 않았으므로 자유 판독 교정이나 해당 사례 재채점을 재개하지 않는다.

## 기존 문헌에서 이번에 좁혀 확인한 것

기존 조사를 재사용했고, 후보 선택에 필요한 학습 대조와 입력 조건의 주장만 원문으로 확인했다.

- [Why Does Grounding Hurt Medical VQA?](https://arxiv.org/html/2604.27720v2)의 §IV-D는 답변 전용 학습, 형식 rehearsal, 실제 grounding 혼합을 구분하며 공동 학습의 성공을 보고한다. 따라서 답변·위치 채널이 다르다는 관찰이나 단순 공동 CE 자체를 새 기여로 삼을 수 없다. §V는 crop 손실에서 context 제거와 분포 변화의 원인을 분리하지 못했음을 명시한다. 이는 후속 후보의 근거이지 우리 모델에서 확인된 실패가 아니다. 해당 논문의 보편적 표현을 iter_107의 성공보다 우선하지 않는다.
- [Does Grounding Improve Radiology Report Generation?](https://proceedings.mlr.press/v315/aas-alas26a.html)의 공식 초록은 전체 영상과 grounding mask, region-to-text 및 부분·노이즈 grounding의 이득을 다룬다. 따라서 전체 영상에 영역을 추가하는 비교만으로 잔여 문제나 신규성이 성립하지 않는다. PDF 링크는 이번에도 도구가 application/octet-stream을 처리하지 못해 본문 확인에 실패했다. 논문 부재나 접근 권한 부재로 해석하지 않는다.
- [Phrase-grounded Fact-checking](https://arxiv.org/html/2509.21356v1)은 소견 진위와 위치를 함께 예측하고 합성 polarity·위치·소견 교란을 사용한다. 오류 탐지 자체는 기존 범위다. 우리의 양성 box 교환이 임상 음성을 보장한다는 근거로 사용할 수 없다. 후속 선택적 교정의 구체적 범위는 이미 확인된 `iter_102/plan.md`를 계승한다.

## Strategy Check / 연구 방향 판단

**시험 설정:** 기존 LoRA recipe, A/B 선택, 복합 phrase 및 자연 다중 영역 누락 개입은 모두 보류를 유지한다.

**연구 관찰:** 위치 출력 성공과 판단 성공은 별개라는 제한된 근거를 계승한다. 정확한 국소 근거의 제공 효과나 일반적인 전이 실패는 아직 확인하지 않았다.

**연구 질문:** 기술 질문은 '질문에 필요한 국소 근거를 더 주었을 때 원래 영상 정보를 보존하면서 판단에 활용하는가'다. 실패 조건은 충분한 위치 연결에도 판단 이득이 없거나 손상이 발생하는 경우이며, 정보량·해상도·형식 차이가 경쟁 설명이다. 공개 정답은 해당 질문의 답과 표적 연결을 함께 제공해야 한다. 자유 판독 전체의 임상 정확성이나 bbox 개수 reasoning을 주장하지 않는다.

### 후보 1 — 원본을 보존한 국소 근거의 판단 가치: 우선 검토

- 중요한 문제: 모듈형 grounder가 제공한 근거가 후속 판단에 실제 도움을 주는 조건이다.
- 기존 해결 범위: crop 손실과 전체 영상+영역 입력의 이득은 이미 연구됐다.
- 구분할 설명: 국소 근거의 유용성, 원본 context 제거, 단순 확대 효과, 질문과 근거의 불일치.
- 최소 비교 후보: 원본 / 원본+표적 근거 / 정보량을 맞춘 비표적 대조 / 단순 입력 선택. 모든 조건의 필요성은 실제 자료를 보고 확정한다.
- 공개 정답·지원 경로: 아직 확정하지 못했다. PadChest-GR 문장–box 연결만으로는 임의의 속성 질문 정답이나 음성을 만들 수 없다. CURE PG를 새로운 판단 인터페이스의 지원 근거로 대체하지 않는다.
- 투자 결정: 단순 대안이 충분하면 방법 투자 보류, 같은 정보에서 중요한 차이가 남으면 한정 진단, 정답이 구분하지 못하면 후보 보류다.
- 비용: frozen 추론 중심일 가능성이 있으나 요청량·처리량은 미산정이다.

### 후보 2 — 기존 위치 학습의 판단 전이: 후순위

- 중요한 문제: 위치 출력의 개선이 실제 영상 판단 개선인지 형식·언급 성향 변화인지 구분하는 것이다.
- 기존 해결 범위: 형식 rehearsal과 실제 위치 학습을 분리한 선행 대조 및 공동 학습 성공이 있다.
- 남은 설명: 프로젝트의 낮은 판독 baseline, checkpoint 선택, 답변 prior, 실제 전이 부족.
- 최소 비교에 필요한 것: 명확한 공개 답 정답, 정확한 base–adapter 비교, 영상 대응 대조 및 강한 직접 SFT. 현재 저장 출력만으로 충분한지 미확정이다.
- 선택하지 않은 이유: 새 조건의 근거 없이 학습을 추가하면 기존 수렴·평가 불확실성을 반복할 위험이 높다. 단순 seed 확대는 선택하지 않는다.
- 재검토 조건: 학습 recipe 구제가 아니라 기존 자산과 명확한 정답으로 경쟁 설명을 구분하는 비교가 성립할 때다.

이 우선순위는 실행 승인이나 기여 확정이 아니다. 후보 1도 선행의 단순 재현을 넘는 질문과 실제 정답 연결이 성립해야 최종 선택한다.

## 다음 라운드의 범위와 종료점

추가 라운드는 문헌 수를 늘리기 위한 것이 아니다. 위 두 후보의 어느 쪽이 강한 기존 대안 이후의 중요한 질문을 실제 공개 정답으로 구분하는지 결정한다. 우선 PadChest 연구의 실제 대조 범위와 로컬 자료의 질문–정답 가능 범위를 확인한다. 성립하면 자료 점검과 작은 실제 비교를 묶은 전체 계획을 완성한다. 성립하지 않으면 임의 질문·평가기·학습을 만들지 않고 보류 범위와 범위 변경 선택지를 제시한다.

## 대규모 GPU 필요 후보

동일 자료·노출량에서 위치·답변 supervision과 시각 encoder 적응을 분리하는 다중 seed 학습은 장기 후보로 보존한다. 현재 recipe 실패가 이를 요구한다는 근거는 없으며 이번에 발주하지 않는다.
