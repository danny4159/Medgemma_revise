# Problems / Concerns

1. **엄격 사실성 구현 부족.** 원 계획은 위치와 명시 속성의 일치를 요구하지만 계산은 D 여부와 위치 접미사만 사용한다. P062의 'Intense scoliosis'에 B0-R의 'mild thoracic scoliosis'가 D로 들어간다. 또한 규약의 '접미사 - 아님'과 코드의 `('', '+')` 허용은 `~` 처리에서 서로 다르다. 보조 지표의 정의와 구현을 정렬해야 한다.
2. **정상·부정 의미의 범위 문제.** 구체적인 심장 크기 정상 reference도 generic_normal로 빠진다. 반대로 P000의 nipple/pseudonodule 사실에 폐가 깨끗하다는 서술을 모순으로 처리했다. 미표기를 음성으로 만들면 안 되지만, 명시된 정상 사실까지 무조건 제외하는 것도 적절하지 않다. 현재 수치의 차이가 실제 오류 감소와 서술 범위 차이를 얼마나 반영하는지 미분리다.
3. **precision 범위의 주장 단위 문제.** supported는 reference 사실 수, 추가 주장은 소견·측 단위이며 부정 주장 N은 contradicted 합계에서 빠진다. D-도 중복 분류될 수 있다. 저장 수치의 산술 재현은 이 의미 문제를 해결하지 않는다.
4. **판정 근거 보존 부족.** positive 상태에는 span이 있지만 내부 모순과 추가 주장에는 충분한 원문 연결이 없다. 같은 assistant의 24명 재판정은 상태 150/160 일치이나, 전문의 검증이나 독립 평가가 아니다.
5. **회귀 보고 정정.** 수동 base와 SFT는 각각 6/8 token 일치다. 같은 두 영상에서 차이가 발생했으며 원인은 미분리다. E96 출력의 무결성과 별개로 수동 관찰과의 동일 실행 주장에는 제한이 남는다.
6. **실행기 재사용 결함.** sibling 행의 검증 없는 완료 처리와 GPU admission의 외부 점유 합산을 고쳐야 한다. 현재 완결된 원시 출력은 별도 검사에 통과했으므로 이 문제만으로 E96 전체를 무효화하지 않는다.

# Interpretation

RSNA adapter의 PadChest 자유 판독 이득은 불확정이다. 이를 기존 RSNA grounding 개선의 부정으로 옮길 수 없다. 체계적 prompt도 이번 저장 판정에서 개선을 보여주지 않았다.

C-G는 같은 MedGemma 1 NF4 GRG 대조보다 확정 reference 회복이 높았다. 그러나 이것은 서로 다른 학습 노출·목적을 가진 checkpoint 비교이며 위치 supervision만의 인과 효과가 아니다. 모순 감소에는 표현 범위와 평가 규약의 영향이 남는다.

C-H는 GRG를 포함하는 더 긴 결합 출력이므로 recall 증가만으로 결합 능력 개선을 주장할 수 없다. 원문에서 확인되는 상충 서술은 후속 점검 가치가 있지만, 곧바로 새 loss 필요성이나 CURE 일반 실패를 뜻하지 않는다. 원문 exact match 감소도 학습 노출 부재의 증명이 아니다.

보고서의 SELF_CHECK: FAIL을 실행 실패로 그대로 옮기지 않는다. 전문의·독립 평가 부재만으로 원 탐색을 소급 무효화하지 않으며, E192 역시 조건부 확대다. 다만 이번에는 환자 변동만 남은 상태가 아니므로 확대보다 평가 보완이 우선이다.

# Strategy Check / 연구 방향 판단

**이어받는 관찰 → 이번 변화:** iter_084/085까지는 생성·평가 미완료로 설명을 줄이지 못했다. 이번에는 같은 track의 본출력을 확보해 단순 prompt나 RSNA adapter가 곧바로 충분한 판독 개선을 만든다는 기대를 약화했고, CURE GRG의 회복과 hybrid의 추가 주장 비용을 함께 확인했다.

- **실행 유효성:** 전체 E96 비교 완료. 저장 규약 아래의 제한적 출력 검증은 유효하다.
- **성능 개선:** RSNA 이득은 불확정. CURE 회복 신호는 있으나 엄격 사실성 개선의 승인에는 평가 보완이 필요하다.
- **가설 지지:** 언급 증가가 항상 정확한 회복은 아니라는 설명과 일치한다. 인식 변화·선택·결합 내부 원인은 구분하지 못했다.
- **신규 기여:** 미확인. 알려진 recall–precision trade-off나 단순 결합의 문제를 재관찰한 것만으로 기여가 되지 않는다.

후속 투자는 **한정 보완**을 선택한다. 새 모델·자료로 전환하면 현재 확보한 비교의 판단 가치를 잃고, 즉시 학습하면 평가 오류에 맞춘 방법을 만들 위험이 있다. 저장 출력의 의미 규칙과 충돌 근거를 보완하면 작은 추가 비용으로 기존 방식 채택·최소 개입·투자 보류를 구분할 수 있다. 이번 비용은 실제 CURE 생성과 의미 판정·재작업에 걸쳐 있으며 정확한 지배 비용 비율은 기록만으로 확정하지 않는다.

기존 grounding·QA 관찰은 유지하고 MRI 보류를 재개하지 않는다. 이번 리뷰에서는 새 limitation을 observed/validated로 등록하지 않는다. 평가 보완 전 방법 진입 근거로 사용하는 것을 피한다.

원 E96 출력과 원 판정을 보존한 별도 재평가를 수행한다. 고정 24명과 발견된 오류 유형에서 범위·정상·속성·주장 단위를 정리하고, 영향받는 전체 조건에 동일 규칙을 적용한다. 기존 지표와 수정 결과를 함께 보고하며 유리한 평가기만 선택하지 않는다. C-H 모순에는 충돌하는 두 span과 영역 출처를 붙인다.
