# 요약

- 다음: 보존20명은 열지 않고, 단순 대안 이후의 잔여 가치로 다음 투자 방향을 선택한다.

- 후속: 현재 품질 비교를 종료하고, 강한 단순 대안으로 해결되지 않는 MRI 질문에만 다음 투자를 검토하도록 권고한다.

# Problems / Concerns

현재 결론을 무효화하는 문제는 발견하지 않았다. 비EOS1건은512-token cap에 도달했으나 사전 invalid=0 규칙으로 분모에 남았다. 이를 최대로 유리하게 처리해도 직접 비교의 큰 열세와 낮은 순서 일관성은 해소되지 않는다. 따라서 전체 재실행은 필요하지 않다.

batch2는12건 중7건 token 불일치로 미채택됐다. 본실행은 두 GPU에 batch1 worker 각1개를 사용했다. 관측 peak11,521/11,449MiB와 worker별2GiB 여유를 고려하면 GPU당2worker를 강제할 이유가 없다. 개발 실행26.73분, 총456요청과 영상 반입1,436,108,361bytes가 기록됐다. 전체 준비·리뷰 비용은 이 수치에 포함되지 않는다.

I/O 보완 계측은 사후다. IQM 생성 전체 비용도 미측정이므로 서비스 비용 우월성은 주장할 수 없다. 전체 volume 전문가 등급과8장 입력은 관측 범위가 다르다. 동일 slice index는 움직임 촬영 간 정확한 해부학 정합을 보장하지 않는다.

재사용에서는 고정 경로, 감독기 밖 진입의 gate 의존, 미실행 holdout을 구분해야 한다. 유용한 렌더링·parser 모듈은 제한 승인하되 전체 스냅샷은 승인하지 않는다.

# Interpretation

실행은 유효하지만 성능 개선은 없다. 절대 점수 보정을 직접 비교로 회복한다는 설명은 현재 조건에서 지지되지 않았다. H2의 손상 인식 부족과 부분 관측 부족은 서로 분리되지 않았다. 첫 위치 선택 현상도 내부 원인이나 영상 무사용의 증명이 아니다.

MRIQC가 훨씬 높다는 결과는 현재 실용 과제의 추가 투자 가치를 낮춘다. 다만 전체 volume을 사용하는 대안이므로 동일 시각 정보에서의 모델 우열로 표현하지 않는다. 보존20명 미실행으로 validated 승격은 하지 않는다. 신규 기여와 방법 개발 필요성은 확보하지 못했다. 기각한 방향이며 긍정적인 후속 탐구 근거가 부족해 논문 추천은 보류한다.

# Strategy Check / 연구 방향 판단

출처는 iter_132 계획 카드와 iter_131 리뷰 판단이다. research_track=mri-volume-evidence-use를 유지하며 과거 MR-RATE 관찰은 정정하지 않는다.

1. 중요한 문제: 반복 관측 중 사용할 영상을 고르는 문제는 중요하지만 현재 거친 품질 순위는 강한 단순 지표로 대부분 해결됐다.
2. 현재 근거: 이전에는 자료 연결만 확인됐고 모델 비교는 미실행이었다. 이번에는 직접 비교 열세와 순서 불안정이 실제 출력으로 확인됐다.
3. 쉬운 해결책: SNR_total98.72%와 개별 채점65.38%가 직접 비교49.57%보다 높다. 현재 과제의 VLM 방법 투자는 보류한다.
4. 남은 설명: 위치 선호·부분 관측·손상 인식·인터페이스의 기여는 남는다. 그러나 이를 분리하는 추가 실험이 현재 실용 투자 결정을 바꿀 근거는 없다.
5. 다음 결정: 현재 후보는 종료한다. 기존 MRI 관찰을 살릴 경우 단순 대안 이후의 구체적인 잔여 가치를 먼저 요구한다. 같은 보류 기록을 작성하는 구현 반복은 만들지 않는다.

실행 유효성은 확보, 성능 개선과 회복 가설 지지는 없음, 신규 기여 가능성은 미확보다. 누적 진단 횟수만으로 MRI를 기각하지 않되 실제 잔여 가치 없이 새 frozen 과제를 계속 순회하는 비용도 다음 선택에 반영한다.
