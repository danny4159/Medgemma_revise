# Assessment

원 계획의 192/192 oracle 기준과 실패 시 E 미실행 규칙을 적용한다. D_gate.json의 run=false와 실제 E/F 생성 디렉터리 부재를 확인했다. 이는 가설 기각이 아니라 사전 기술 gate 실패다. 구현 보고서의 '현재 결론 무효 없음'은 D 집계 자체에 대해서만 맞으며, 계획한 본 가설 판단에는 oracle 실패가 blocker다.

구현 담당은 engineer_backend.json과 claude_meta.json상 Claude Sonnet, medium이다. 시작 시각은 04:30 KST 이후로 담당 복귀 지시와 일치한다. iter_050의 무효 영상 감사를 이번 실험 근거로 승계한 흔적은 확인되지 않았다.

리뷰 대상은 7217b7045f48f95d8dc9b750544634e1c28d4f5c이다. changes.patch의 신규 파일과 관련 의존 경로를 검토했고 변경 파일 14개의 commit 내용과 작업 파일이 모두 일치했다. unpreserved_paths는 비어 있다.

# Key Findings

1. **원시 결과 독립 확인:** gen/D/gen_worker*.jsonl에서 448건·고유 ID 448개·EOS 448건을 확인했다. 별도 JSON 처리와 manifest 정답 연결로 oracle을 재집계했으며 CheXpert image 63/64, text 60/64, PadChest image/text 각각 30/32로 보고서와 일치했다.
2. **오류 범위:** 9건 모두 truth=(present, absent), draft=01이었다. 이 중 4건은 초안 상태 (absent, present), 5건은 (absent, absent)를 반환했다. 따라서 모든 오류를 완전한 초안 복사로 설명할 수 없다. text-only의 동일 prompt 반복을 독립 환자 재현으로 세어서도 안 된다.
3. **D 점추정 재현:** R1의 수정률/보존 실패율은 0.421875/0.109375, R2는 0.40625/0.078125, BJ는 0.8125/0.1875, BI는 0.84375/0.15625였다. 이는 D16 기술·개발 자료의 기술통계이며 본 가설의 양성 판정에 사용하지 않는다.
4. **검증 근거:** D_verify.json의 107개 검사와 도구 로그의 불일치 0, fixtures_rr53.json의 92/92를 확인했다. D_gate가 참조하는 모든 입력 digest를 리뷰에서 재계산해 일치시켰다.
5. **정상 입력:** input_tensor.json은 고유 입력 2,008개에서 token·pixel·padding 불일치 0을 기록한다. 초기 검사 실패는 수동 비교 경로의 BOS 중복과 image token 선택을 수정한 뒤 해결됐다. 실제 환경 기록의 모델 revision·bf16·processor를 확인했다. T/R2와 BT/BJ는 같은 텍스트를 사용한다.
6. **자원:** 48요청 pilot에서 2 worker 90.4초, 4 worker 75.3초와 token 불일치 0을 근거로 4 worker를 선택했다. D는 두 GPU에서 437.0초, 종료 코드 모두 0으로 완료했다. 프로세스 peak reserved 8.27 GiB와 보고된 GPU 점유는 worker당 2 GiB 여유를 둘 수 있는 범위다.

# Problems / Concerns

현재 본 가설 판단을 막는 문제는 oracle 기준 미달이다. 내용 오류를 parser 오류로 재분류하거나 허용되지 않은 prompt 재시도로 해소하지 않은 점은 적절하다.

재사용 문제는 별개다. P_resume/completion.json은 loading 포함 device 시간이 101.5277초로 generation union 101.8067초보다 작다. 이는 iter_047/048에서 지적된 재개 비용 집계 문제가 남았음을 뜻한다. 현재 단회 D의 oracle 집계는 무효화하지 않지만 전체 재개 비용의 정확성을 승인할 수 없다.

rr53_run의 gate 검사는 입력 digest의 존재와 일치를 확인하지만 필수 근거 집합·결정 재계산을 강제하지 않는다. 실제 launch 경로는 pg43_run이다. 평가 결과 전체의 완료 봉인도 없다. 이번에는 리뷰가 실제 파일 연결을 확인했으므로 중단 결론은 유지하지만 전체 스냅샷 재사용은 승인하지 않는다.

출력 디렉터리 부재로 평가 첫 실행이 실패한 뒤 디렉터리를 준비해 완료했다. 이는 복구된 실행 문제이며 oracle 내용 오류의 원인이 아니다. E/F 판정 경로는 실제 본평가로 검증되지 않았다.

# Interpretation

명시적 정답 복사 경로가 출처 우선순위 문장 추가 후에도 완전하지 않았다는 제한된 결과는 보존한다. 하지만 초안 의존, 상태 표현, ID 대응 또는 시각 판독 중 무엇이 원인인지 확정할 수 없다. 특히 text-only 오류도 있어 이를 의료 영상 이해의 결함으로 해석할 수 없다.

자료 gate와 입력 검사가 통과했다는 사실은 연구 가설의 지지를 뜻하지 않는다. D16에서 보이는 수정–보존 차이는 후속 학습이나 F 소비의 근거로 승격하지 않는다. 기존 limitation 상태는 변경하지 않는다.

# Strategy Check / 연구 방향 판단

- **실행 유효성:** D 기술 실행과 집계는 확인했다. 계획된 E/F 가설 검증은 미실행이다.
- **성능 개선:** 새 방법·학습을 수행하지 않았으며 개선을 주장할 근거가 없다.
- **가설 지지:** 수정–보존 trade-off와 단순 대안의 부족함은 미판정이다. oracle 실패는 그 가설의 반증이 아니다.
- **신규 기여 가능성:** 이번 결과만으로 교정 특화 방법의 필요성이나 선행 대비 차별성을 승인할 수 없다.

iter_047의 oracle 실패는 이번 새 조건에서도 해소되지 않았다. 이를 보존하되 추가 복사 진단에 투자할 가치는 낮다. 원시 출력의 정답·초안 대응은 이번 리뷰에서 이미 확인했으며, 같은 내용을 별도 반복으로 분석해도 투자 결정이 바뀌지 않는다.

iter_048의 공동 SFT 회복과 잔여 손실, iter_046의 모듈형 적응 효과는 이번 비교로 설명되거나 반박되지 않았다. 해당 관찰은 유지하지만 기존 투자 보류를 자동 해제하지 않는다. CT 자료·기술 gate 실패도 그대로 남는다.

따라서 현재 교정 설계는 증거 부족과 사전 종료 조건 때문에 보류한다. 교정 연구 전체의 가치가 작다고 입증한 것은 아니다. 다음 계획에서는 누적 준비·진단 비용을 고려해 중요한 기존 observed/validated 문제에 대한 최소 방법 시험과 다른 질문을 비교하고 하나를 선택해야 한다. 새로운 근거 없는 prompt·질환·자료 감사의 연장은 권고하지 않는다.

# Recommended Next Experiment

현재 E/F를 실행하거나 oracle 문구를 추가 탐색하지 않는다. 다음 전략 계획에서 선택할 후보는 실제 사용 과제, 강한 단순 baseline, 남은 경쟁 설명과 결과별 종료 행동을 구체화해야 한다. 방법 pilot은 이전 유효 리뷰의 한계 근거와 연결하고, 이번 실패를 새 진입 근거로 삼지 않는다.

코드 보완은 선택된 후속 경로에 필요한 것만 수행한다. 기존 원시 출력과 checkpoint는 보존한다. 이번에는 유효한 방법 개선이나 후속 탐구의 긍정적 근거를 확보하지 못했으므로 논문 추천과 milestone 기록은 보류한다.
