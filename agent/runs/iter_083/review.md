# Key Findings

1. 리뷰 대상 SHA는 `60b471e524aa59709473c8663db6d8f1c36d8870`이며 unpreserved_paths는 없다. before_sha 대비 25개 소스가 추가됐지만 그중 24개는 선별 반입이다. 신규 구현은 `rg83_preflight.py`다. 반입 파일의 commit blob 24개가 reuse_manifest와 일치하고 신규 파일도 작업 파일과 일치했다.
2. `research/results/iter_083/preflight_a1/completion.json`의 산출물 digest 7개를 독립 대조했다. 원 split에서 train 161 scan·159 prefix를 다시 계산했고, label 적격성 판정 전 환자별 첫 scan 및 첫 8명 선택과 일치했다.
3. 8건은 HIGH 1건, MIXED 4건, 모호 3건이다. 정답 후보 span을 재확인했다. 미언급을 음성으로 대체하지 않았고, midline crossing과 구조 변위를 구분했다. 이는 원문 후보 검토이며 영상 정답의 적합성 검증은 아니다.
4. `access_attempts.json`은 mapping metadata 및 access requirement 조회 200, 다운로드 403을 기록한다. 오류 본문은 미충족 접근 요건을 명시한다. 다만 요청은 인증 없는 requests 경로이며, 이 결과로 모든 승인 자산이나 사용자 계정의 접근 가능성을 판정할 수 없다.
5. `incident.json`과 실제 초기 조회 로그는 공식 test 보고서 일부 및 val 보고서 일부의 우발적 노출을 뒷받침한다. 공식 val/test를 전혀 열지 않았다는 주장은 불가능하다. 이후 train guard를 적용했고 이번에는 학습·평가 자체가 없으므로 학습 누수가 발생했다고 단정하지 않는다.

# Problems / Concerns

**현재 결론을 막는 문제:** 실제 train 영상·mask 연결, release 대응, 최종 적격성 및 모델 출력이 없다. 따라서 성능 비교와 가설 판정은 불가능하다.

**재사용 전 수정:** preflight는 네트워크 응답이 달라져도 접근 요건 미충족과 run_training=false를 고정 기록한다. 현재 실패 기록과는 일치하지만 복구용 gate로 그대로 사용할 수 없다. release 설명과 incident도 실행별 증거에서 도출되지 않는 고정 기록이다. 다음 실행에서는 과거 incident를 보존하면서 현재 응답·접근 상태·영상 연결 여부를 분리해야 한다.

fixture 6개는 제한적인 guard·수동 후보·span 검사다. 일반적인 label 추출기나 영상 연결 검증을 통과했다는 뜻이 아니다. 반입 학습 코드도 이번 입력에서 실행하지 않았으므로 포괄적 재사용 승인을 부여하지 않는다.

GPU 미사용은 자료 gate 미완료에 따른 적절한 중단이다. 처리량 비교 누락을 별도 과학적 실패로 추가하지 않는다. 다만 gate가 해결되면 원 계획의 실제 메모리·처리량 비교와 새 입력 회귀 검사는 수행해야 한다.

# Interpretation

이번 결과는 접근·자료 준비 실패다. 직접 SFT가 정보 보존 손실을 해소하는지, 추가 영상의 내용이 방해하는지, 기본 인식이 부족한지, 단순 분류기가 충분한지는 모두 미검증이다. 기존 limitation의 상태를 바꿀 실제 모델 출력이 없으므로 limitation_updates는 비운다.

공개 mirror의 license 표기만으로 공식 접근 요건 충족을 선언하지 않은 판단은 타당하다. 반대로 mapping 한 경로의 403만으로 자료 전체가 사용 불가능하거나 사용자 승인이 반드시 필요하다고 확정해서도 안 된다. 승인 자산·정당한 배포 경로와 실제 대응 근거를 한정 확인할 여지가 남는다.

이번에 줄인 것은 보존 코드의 출처 불확실성과 일부 보고서 문구의 모호성뿐이다. 모델에 관한 경쟁 설명은 줄이지 못했다. 새 뇌 MRI 후보는 기존 F/R 차이의 원인 규명이 아니라 새 현상 탐색이라는 구분을 유지한다.

실행 유효성은 미확보, 성능 개선은 미측정, 가설 지지는 없음, 신규 기여 가능성은 미검증이다. 관찰 없이 method pilot으로 넘어갈 근거는 없다. 이번 비용은 자료 조회·준비·감사에 집중됐으며 정확한 전체 시간은 기록되지 않았다. 접근 경로 보완이 완료될 때까지 학습기를 더 구현하는 투자는 보류한다.
