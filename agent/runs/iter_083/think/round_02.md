# 사고 라운드 2

# 이번 판단

**SPIDER 투자 보류는 유지한다. 새 뇌 MRI 후보의 학습 발주는 잠시 보류하고, 같은 자료를 사용한 가까운 선행 이후에 남는 질문을 먼저 결정한다.** 이번에는 정답·입력·재사용 경로를 좁혔지만, 새로 확인한 PerFact 때문에 단순 전체/영역 비교의 투자 가치를 다시 판단해야 한다. 자료 확보 자체나 crop 효과를 연구 진전으로 삼지 않는다.

## 직전 질문에 대한 답

### 1. 두 질문의 정답과 영상 범위를 연결할 수 있는가?

보고서 수준의 정답 후보는 있다. 그러나 실제 train 영상의 범위별 판독 충분성은 아직 확인하지 않았다.

`agent/runs/iter_083/think/round_01.json` 원문과 보존된 global/FLAIR 보고서를 직접 읽었다. 재독해 목적은 이전에 확인한 문구의 존재가 아니라, 두 질문을 같은 FLAIR 입력의 정답으로 연결할 수 있는지 확인하는 것이었다.

- `BraTS-GLI-00017-000`: global과 FLAIR 모두 고신호 및 명시적 midline shift 부재를 기술한다.
- `00021-000`: 두 원문 모두 고·저 혼합 신호와 좌측 구조 변위를 기술한다.
- `00053-000`: 병변의 midline 통과와 구조의 우측 변위를 별도로 기술한다. 두 표현은 다른 정답 개념이다.
- `00024-000`: 고신호와 내부 mixed 표현이 함께 있다. 이를 단순 HIGH/MIXED 키워드 규칙으로 확정하면 안 된다.
- `00045-001`: global은 shift 부재를 명시하지만 FLAIR는 영향에 대한 언급이 없다고 기술한다. 후자를 시각적 음성 근거로 사용할 수 없다.
- `00061-000/001`: 복수 scan과 복수 병변 기술이 있다. 환자별 분리뿐 아니라 보고서의 대상과 제공 영역의 대응이 필요하다.

원문 경로는 `research/results/iter_070/data/radgenome/BraTS_GLI/global_finding.json`, `modal_wise_finding.json`, `train_val_test_split.json`이다. 이전 라운드의 SHA256과 split 조사 결과는 유지한다. 새로운 class 적격 수를 계산했다고 주장하지 않는다.

영상 provenance도 미완료다. `research/results/iter_070/data/brats_manifest.json`은 `MedOtter/brats2023-gli-dataset`, revision `b032d353a3e80911a5f850bc54e6fb575298a354`를 기록한다. 반면 AutoRG 공식 설명은 glioma 원천을 BraTS2021로 기술한다. ID 일치만으로 release 간 영상·annotation 동등성을 확정할 수 없다. 기존 파일의 존재는 확인했지만 이번 train 영상 연결은 검증하지 않았다. [AutoRG 공식 구현](https://github.com/ljy19970415/AutoRG-Brain)

따라서 자료 검사는 조건부 구현 단계로 넘길 수 있으나, 지금 상태에서 좁은 crop이나 소수 slice가 보고서 정답을 충분히 포함한다고 가정해서는 안 된다. global label의 사용과 FLAIR 단독 충분성은 별개다.

### 2. 전체·영역 비교에서 무엇을 통제해야 하는가?

설계 원칙은 좁힐 수 있었다. 별도 F/R adapter를 비교하는 대신 동일 checkpoint와 질문을 사용하고, 전체+영역 조건에서 각 구성 tensor를 단독 조건과 같게 유지해야 한다. 추가 이미지 수의 영향은 동일 영상 복제로 구분할 수 있다. 다만 이 대조도 영역 확대에 따른 정보와 해상도의 차이 자체를 제거하지 않는다.

영역에만 신호가 있고 주변 구조가 잘려 있다면 shift 성능 저하는 입력 정보 손실일 수 있다. 반대로 전체+영역에서 충분한 국소 정보가 그대로 있는데 성능이 떨어지는 경우가 선택·간섭 후보에 더 가깝다. 어느 경우든 기본 인식이 확보됐는지 먼저 보아야 한다. 두 질문이 다른 답을 요구한다는 사실만으로 복수 근거 결합 필요성을 주장하지 않는다.

Targeted Visual Prompting 공식 저장소에는 crop region과 draw region의 fine-tuning·평가 경로가 있다. 따라서 crop 추가나 표시에 따른 개선은 이미 가까운 표준 대안이다. [공식 구현](https://github.com/sergiotasconmorales/locvqallm), [crop 학습 스크립트](https://raw.githubusercontent.com/sergiotasconmorales/locvqallm/master/scripts_vqa/ris/crop_region.sh)

### 3. 최초 비교에 직접 SFT와 분류기가 필요한가?

**실질적인 투자 판단을 하려면 필요하다.** iter_070의 AutoRG frozen 결과 BA 0.6136과 iter_077의 적응 후 영상 대응 신호를 고려하면, 새로운 frozen 모델 출력만으로 같은 기본 인식 문제를 다시 선별하는 설계는 정보 가치가 낮다. 다만 정답·입력 연결과 잔여 연구 가치가 미확정인 지금 전체 학습을 승인할 근거도 부족하다.

기존 코드 원문을 확인했다. `d397b723c8cc377f1557b2f55a102ea8f8bc951a`의 `sp75_vlm.py`에는 공식 chat template, assistant-only labels, 입력 tensor 대조와 CE 계산이 있다. `sp75_train.py`에는 rank16 LoRA, checkpoint/RNG 복구, 실제 비LoRA 동결 검사가 있다. 하지만 3영상·Pfirrmann·두 답변 token·SPIDER split에 연결되어 있어 새 과제에 그대로 실행할 수 없다. `sp75_c.py`도 3개 crop 평균 feature와 5-class head에 고정되어 있다.

현재 브랜치에는 이 파일들과 `rsna_diag/generate.py`가 없지만 보존 commit에 존재한다. 코드 소실이 아니며 새로 구현할 이유가 아니다. `agent/CODE_ASSETS.md`, iter_075/077의 `review.json/code_assets`를 확인했다. 재사용 시 실제 선택한 경로의 출처·새 label token 수·완료 산출물 hash·현재 GPU 메모리 배정 문제를 검증해야 한다. 이번에는 실행 설계가 미확정이므로 선별 반입을 승인하지 않았다.

## 새로 확인한 가까운 선행이 바꾼 판단

[PerFact 원문](https://arxiv.org/html/2608.17926v1)은 RadGenome 기반 뇌 MRI에서 전문 3D 인식 결과를 사실 문장으로 제공하고 LoRA VLM과 연결한다. 직접 SFT·retrieval·예측 사실·oracle 및 closed-ended VQA를 비교한다. Table 1의 보고서 F1은 SFT 0.644, 예측 사실 0.775지만 VQA AUROC는 0.697/0.720이다. 이는 저자 보고 수치이며 독립 재현하지 않았다. 보고서 개선을 질문별 시각 근거 사용 개선으로 동일시할 수 없다. 논문의 생성기는 제한된 2D 입력을 사용하므로 현재 전체/영역 대조를 직접 검증한 것도 아니다.

이 발견은 두 방향의 근거다. 전문 분류+언어 생성이라는 대안을 반드시 고려해야 하지만, 논문만으로 현재 후보가 해결됐다고 단정할 수도 없다. 현재 HTML에서 프로젝트 구현 링크를 확보하지 못했으며 코드가 없다고 판정하지 않는다. 이번 문헌은 조사 근거이고 사용자 추천 논문으로 승격하지 않는다.

## Strategy Check / 연구 방향 판단

이전 라운드의 전략 결정은 유지한다. iter_064의 모델별 context 차이, iter_077의 전체/영역 차이는 유효 관찰이지만 이번 조사로 원인이 설명되지 않았다. iter_078의 참고영상, iter_081의 자동 교정, iter_082의 불일치 순위 투자 보류도 바꾸지 않는다. iter_079는 자료 연결 실패이며 모델 반증이 아니다. 인계는 iter_081에서 완료됐으므로 다시 실행하지 않는다.

새 후보는 기존 현상의 원인 규명이 아니다. 같은 MRI 근거 사용 상위 질문 안의 새로운 현상 탐색이다. 이번에 줄인 불확실성은 두 질문의 문구 차이와 비교 설계의 혼동 요인이다. 아직 줄이지 못한 것은 전문 분류기 이후에 VLM 연구로 투자할 구체적 가치다.

- 현재 입력 비교 개선: 직접 적응과 tensor 통제로 더 명확한 결과를 얻을 수 있으나 단순 분류 두 개로 끝날 위험이 있다.
- 근거 보존 조건으로 집중: 같은 정보가 제공됐는데 질문에 따라 활용하지 못하는 조건을 정의할 수 있다면 의미가 있다. 아직 관찰되지 않았으므로 기여나 방법 효과를 가정하지 않는다.
- 현재 후보 보류: 강한 단순 대안 이후의 중요한 잔여 질문을 연결하지 못하면 타당하다. 새 데이터셋 목록을 만드는 것으로 대신하지 않는다.

다음 판단은 일반적인 문헌 추가가 아니라 이 세 선택 중 실제 투자 하나를 고르는 일이다. 가까운 선행과 직접 겹친다는 새 근거 때문에 핵심 기여 범위의 판단으로 올린다. 필요한 조회는 이번에 수행했으며, 다음 라운드는 기존 원문과 설계의 해석에 집중한다.

## 비용·한계·보존

신규 실행은 하지 않았다. iter_077의 약 2.73시간 worker wall을 새 뇌 MRI 학습 시간으로 복사할 수 없다. 영상 수와 token 길이가 달라 실제 peak·처리량 측정이 필요하다. 실행을 선택하면 데이터 점검→동작 확인→가능성 탐색→조건부 확대를 한 계획으로 묶고, 두 GPU의 batch/worker 배치를 실측으로 정한다.

현재 `limitation_ids=[]`를 유지한다. 기존 SPIDER observed 주장을 새 뇌 MRI 방법의 진입 근거로 대신 쓰지 않는다. `reuse_iteration=82`와 빈 `reuse_assets`는 구현 승인 전 임시 상태다. 기존 원본·checkpoint·test/reserve를 변경하지 않았다.

### 대규모 GPU 필요 후보

질문별 국소 세부와 전체 구조를 보존하는 3D encoder·connector 공동 적응은 장기 후보다. 표준 다중 규모 입력·직접 SFT·전문 인식 대안 이후의 부족함이 확인되지 않았으므로 필요성이나 신규성을 확정하지 않는다.
