# 사고 라운드 1

# 이번 판단

**SPIDER 활용 후보 묶음은 보류하고, 뇌 MRI에서 질문별로 필요한 국소·주변 근거가 달라지는 후보를 한정 검토한다.** 직전 리뷰가 제시한 전환 분기를 선택했다. 전체/영역 입력 차이의 원인은 남아 있지만, 이를 줄였을 때 분류기 이후에 얻을 추가 가치가 아직 없다. 따라서 기존 F/R의 해상도·context 분해 실험을 자동 발주하지 않는다.

다음 후보를 막연한 자료 탐색으로 남기지 않는다. 구체적인 입력·질문 후보는 **같은 뇌종양 MRI에서 병변 내부의 FLAIR 신호와 주변 midline 구조의 변위를 각각 묻는 것**이다. 자료는 이미 보존된 RadGenome-Brain MRI의 BraTS-GLI 보고서·영상 연결을 우선 검토한다. 두 질문이 서로 다른 근거를 필요로 하는지, 표준 전체+영역 처리로 충분한지는 아직 검증하지 않았다.

# Strategy Check / 연구 방향 판단

## 이어받는 관찰과 선택·회피 근거

관련 원 리뷰를 직접 확인했다.

- **iter_064 — 관찰 유지, 투자 보류:** MedGemma의 복제 대비 다른 slice 추가 손실은 BA 0.27083, 95% CI [0.20313, 0.33854]였다. Qwen에서는 같은 손실이 없었다. 기본 인식과 명시적 index routing 이후의 가치 문제가 남으므로 공통 선택 실패로 확대하지 않는다.
- **iter_077 — 관찰 유지, 원인 미검증:** 전체/영역 입력의 MAE 차이 0.29357은 유효하다. 영역 입력의 영상 대응 신호도 확인됐다. 그러나 영역 VLM과 분류기의 MAE는 0.77690/0.77619이며, 별도 적응·해상도·context가 얽혀 있다. 입력 차이 자체만으로 새 방법 투자를 정당화하지 않는다.
- **iter_078 — 투자 보류 유지:** 참고영상 MAE 0.82619는 분류기 0.77619보다 높았다. 등급만 제공한 조건 대비 작은 개선 방향은 불확정이며, 새로운 검색기·참고 수 탐색의 근거로 삼지 않는다.
- **iter_079 — 모델 가설 미검증:** LUMIERE의 명시적 음성과 비교 검사 연결 실패였다. MRI 능력의 반증이 아니다. 새 후보에서는 소수 실제 정답의 의미를 먼저 확인한다.
- **iter_080/081 — 설명 진전과 후보 종료를 구분:** 영상 교환에 답변이 반응하므로 모든 출력이 자동 등급 복사라는 설명은 약화됐다. 그러나 실제 영상+자동 등급의 분류기 대비 MAE 차이 −0.04333, CI [−0.19584, 0.08730]은 유용한 교정을 확정하지 못했다. 인계는 iter_081에서 완료됐으며 다시 실행하지 않는다.
- **iter_082 — 현재 순위 후보 종료:** 같은 12개 검토에서 큰 오류 포착은 confidence 5개, 불일치 3개였다. 추가 정보의 절대 부재는 아니지만 현재 고정 순위의 후속 투자 근거는 확보되지 않았다.

**비교한 선택:** 기존 판독 개선은 강한 분류기 이후의 가치가 약하다. F/R 원인 진단은 원인을 구분할 수 있어도 그 결과가 바꿀 실용 투자 선택이 부족하다. 새 후보는 단일 등급 판독에서 질문에 따른 근거 범위로 조건을 바꾸므로 판별 가치가 있을 수 있다. 다만 새로운 현상의 탐색이며 기존 관찰을 설명한 진전은 아니다.

재개 조건은 기존 설계 밖에서 확인한 중요한 사용 조건과 단순 대안 이후의 잔여 가치다. 반복 횟수나 CI 폭만으로 기존 설계를 재개하지 않는다.

iter_077은 실행 복구 후 네 trajectory의 본학습 worker wall 합계 약 2.73시간을 사용했다. iter_081 본생성 wall 합계는 약 82.7초, iter_082 통계 분석은 약 3.41초였지만 준비·감사·재작업의 전체 비율은 기록되지 않았다. 이번에는 기존 소규모 출력에 점수만 추가하는 경로를 종료하고, 새 후보의 자료·대조 적합성을 구현 전에 좁힌다. 이 수치를 누적 GPU 비용이나 비용 절감률로 환산하지 않는다.

# 새로 확인한 자료와 의미

## 1. NeuroQA는 참고할 schema가 있지만 그대로 채택하지 않는다

공식 논문은 영상 관찰 기반 질문과 정량 측정·임상 정보 기반 질문을 구분한다. 공개 저장소는 QA만 배포하며 원 영상 이용 조건은 별도다. 따라서 dataset 이름이나 image-grounded 표지만으로 특정 부분 영상의 답변 충분성을 인정할 수 없다. [논문](https://arxiv.org/html/2605.20525v1), [공식 저장소](https://github.com/mhabbasiit/neuroqa)

공식 BraTS 생성 문서는 신호·위치·주변 구조 등의 정답을 보고서에서 추출한다고 설명한다. 이는 기존 RadGenome 원문과의 직접 대조가 필요하다는 뜻이다. 배포 QA의 val JSON은 web의 blob/raw/resolve 조회가 실패했고, shell curl도 DNS 해석에 실패했다. **QA가 없거나 접근 권한이 없다고 판정한 것은 아니다.** [생성 경로 설명](https://raw.githubusercontent.com/mhabbasiit/neuroqa/main/tier1_pipeline/datasets/BraTS_WMH/README.md)

측정값에서 정의한 위축·부피 질문을 눈으로 충분히 판독 가능한 정답으로 바꾸는 후보는 피한다. T1/T2 이름만으로 선택할 수 있는 sequence routing을 새로운 근거 선택 방법으로 제안하지 않는다.

## 2. 이미 보존된 원문에서 두 질문군의 구체적 예를 확인했다

읽은 파일:

- `research/results/iter_070/data/radgenome/BraTS_GLI/global_finding.json`
- `research/results/iter_070/data/radgenome/BraTS_GLI/modal_wise_finding.json`
- `research/results/iter_070/data/radgenome/train_val_test_split.json`

global 보고서는 230 scan이다. BraTS-GLI의 공식 목록은 train 161 scan, val 23 scan, test 46 scan이다. scan 마지막 suffix를 제거한 환자 prefix 기준으로 train은 159개이며 split 간 prefix 교집합은 0이었다. 이는 ID 규칙에 따른 확인이며 임상 환자 독립성의 최종 검증은 아니다.

train ID순 첫 8개 원문을 읽었다. `00017-000`에는 FLAIR 고신호와 명시적 midline shift 부재가 함께 있다. `00021-000`에는 FLAIR 고·저 혼합 신호와 좌측 midline 변위가 있다. 따라서 적어도 원문 수준에서는 두 질문의 서로 다른 정답 조합이 존재한다.

동시에 주의할 사례도 확인했다. `00024-000`은 고신호와 내부 mixed 표현이 함께 있어 단순 키워드 분류가 불충분하다. `00045-001`은 global 원문에 명시적 shift 부재가 있지만 sequence별 문장에서는 효과가 언급되지 않았다는 표현을 쓴다. `00061-000/001`처럼 동일 환자 prefix의 복수 scan도 있다. **미언급을 음성으로 만들거나 mixed라는 단어를 고·저 혼합의 확정 정답으로 쓰면 안 된다.**

간단한 문자열 선별에서는 shift 부재 문구 74행과 나머지 midline 관련 후보 156행이 나왔지만, 이는 적격 양성·음성 수가 아니다. 부정 범위·병변의 midline 통과와 구조 변위를 구분하지 않은 탐색 집계이므로 표본 계획의 class 수로 사용하지 않는다.

확인한 SHA256:

- global_finding: `b5deb0ce13fa6a987abe7dbaa01d3be90eb322c184e6d3c42cf695aa01b03865`
- modal_wise_finding: `978952a16c1f99ed11b62c8b47c5e2266f0d21819873da86aa70a778edfd51ee`
- split: `a6c32048292cdd869280d643da31e381a2fa47c1241efb79080cefd7ed1901e5`

## 3. iter_070의 재사용 한계도 이어받는다

원 리뷰에서 AutoRG의 FLAIR 15 case는 P/G 모두 BA 0.6136으로 frozen 후보 채택 기준에 미달했다. 높은 mask 중첩, 보고서 대상과 mask 의미, BraTS release 연결 및 학습 노출의 미완결이 남았다. 이번 후보는 같은 신호 질문만 다시 묻는 재실험으로 만들지 않는다. 필요하면 기본 판독의 직접 적응과 강한 분류기를 비교하는 설계여야 하며, 과거 음성을 새 모델 이름으로 초기화하지 않는다.

현재 보존 영상은 일부 FLAIR·seg 파일이며 새로운 train 집단의 영상 연결은 아직 확인하지 않았다. 새 영상 확보가 필요하더라도 전체 archive 다운로드를 먼저 발주하지 않는다. 실제 여섯~여덟 사례의 정답·입력 연결을 확인한 뒤 필요한 범위만 정한다. 이 사례 수는 확증 표본이나 실험 상한이 아니다.

# 가까운 기존 방법과 남은 설계 문제

Targeted Visual Prompting은 의료 VQA에서 crop region과 draw region 비교·적응 경로를 이미 제공한다. 따라서 ROI 추가나 표시의 효과 자체는 신규성이 아니다. [공식 구현](https://github.com/sergiotasconmorales/locvqallm)

새 후보의 의미가 있으려면 전체+영역을 단순 제공하는 방법, 직접 SFT, 같은 정보를 받는 분류기가 해결하는 범위를 먼저 확인해야 한다. 질문 이름에 따라 두 분류기 중 하나를 고르는 것으로 충분하다면 그 결과를 인정하고 VLM 방법 투자를 보류한다. 반대로 모든 기본 모델이 약하면 선택·결합 실패를 선언하지 않는다.

현재 미확정인 것은 다음 세 가지다.

1. 보고서의 병변 신호와 주변 구조 변위를 실제 입력 범위에 연결할 수 있는가.
2. 전체·영역 비교에서 해상도와 별도 적응의 혼동을 피하면서, 단순 전체+영역 baseline을 공정하게 구성할 수 있는가.
3. 과거 frozen 신호 부족을 고려할 때 최초 비교에 직접 적응을 포함할지, 작은 타 계열 적합성 비교로 먼저 분기할지.

이를 정하지 않은 상태에서 학습량·표본 수·효과 문턱을 임의로 채운 구현 계획을 발주하지 않는다. 다음 라운드는 이 후보의 세부 설계에 한정하므로 deep_medium으로 낮춘다.

# 한계와 코드 재사용 상태

`agent/LIMITATIONS.md`와 iter_064/077의 `review.json/limitation_updates`에서 evidence·usage_checks·remaining_questions를 확인했다. 두 observed 주장은 유지하지만 새 뇌 MRI 질문의 한계 근거로 대신 사용하지 않는다. 따라서 현재 `limitation_ids=[]`, diagnostic/none이다.

`agent/CODE_ASSETS.md`, iter_081/082 원 리뷰와 현재 파일 목록을 확인했다. 현재 HEAD는 재사용 승인된 `ee8078ab0acba94f0d84d3ab2997e76eeb117bb9`이고 작업 트리는 깨끗하다. 현재 브랜치의 SPIDER metric을 새 질문 평가기로 그대로 사용하지 않는다. 필요한 GPU·학습 실행 경로가 확정되면 보존 SHA에서 의존 파일을 선별하고 해당 재사용 결함만 수정하도록 계획한다. 이번에는 선별 반입을 승인하지 않아 `reuse_assets=[]`다.

## 대규모 GPU 필요 후보

질문별로 국소 세부와 전체 구조 정보를 보존하는 3D encoder·connector 공동 적응은 장기 후보로 남긴다. 현재는 표준 다중 규모 입력과 경량 직접 적응 이후의 부족함이 확인되지 않았으므로 대규모 학습의 필요성이나 신규성을 주장하지 않는다.
