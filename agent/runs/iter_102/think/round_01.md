# 사고 라운드 1

## 핵심 판단

현재 frozen 교정 설정의 보류를 유지한다. 다음 질문은 이미 선택했다. **기존 선택적 fact-checking 교정 이후에도 올바른 초안의 보존 문제가 남는가**이다. 현재 인터페이스를 다시 시험하거나 새로운 학습을 시작하지 않는다.

## 직접 확인한 로컬 근거

- `agent/GOAL.md`, `agent/runs/iter_101/plan.md`, `review.md`, 관련 `agent/LIMITATIONS.md`와 `agent/CODE_ASSETS.md` 항목을 확인했다.
- iter_101 원 리뷰는 유효한 탐색이지만 inconclusive다. 저장 규약의 K/A/T/V/W 안전 정답은 6/2/4/3/0명이고 T 5/6건이 bbox JSON이다. 여섯 환자 모두 흉수 양성이므로 일반적인 영상 교정 효과나 텍스트 편집의 충분성은 판정되지 않았다. 안전 정답 총수에는 복합 atom·속성 보존 문제가 남아 잠정치임을 유지한다.
- `research/results/iter_101/data/lock/atoms.json`과 `eval/judgments.json`을 확인했다. index12의 초안에는 central venous catheter와 nasogastric tube가 있으며 저장 교정 판정에는 두 사실의 소실이 기록돼 있다. index15에는 새 정상 주장이 reference와 상충하는 것으로 기록됐다. 이번에는 이를 재채점하거나 새 빈도로 집계하지 않았다.
- 실제 생성 원문 조회에서도 기구가 포함된 초안 및 T의 bbox JSON 출력을 확인했다. 다음 비교를 승인하려면 index12·15의 해당 조건 원문과 reference를 완결된 쌍으로 연결해야 한다. 저장 판정표만으로 임상적 오류를 새로 확정하지 않는다.
- `git -C research status --short`는 비어 있었다. iter_101 생성·평가 모듈은 모두 needs_fix 범위가 있으며 아직 재사용 대상으로 선택하지 않았다. 코드 반입이나 수정은 없다.
- iter_101 원 계획은 iter_090 인계 학습이 이후 반복에서 완료됐음을 명시한다. 과거 인계 checkpoint를 재개하지 않는다. 원본 보존·인증 값 비노출·supervisor 대기 원칙만 계속 적용한다.

## 새로 확인한 선행 근거

[Anatomically-Grounded Fact Checking 원문](https://arxiv.org/html/2412.02177v1)은 영상과 구조화된 소견을 이용해 오류를 검출하고, 잘못된 소견의 단어를 제거한 문장만 Llama3.2로 복원한다. 따라서 전체 문장 삭제의 부작용과 세분화된 교정은 이미 다루는 문제다. 이는 현재의 전체 판독문 재작성과 입력·수정 범위가 다르다. 해당 연구의 성공을 받아들이되 현재 사례를 해결했다고 단정하지 않는다.

[저자 공식 출판 목록](https://razi-mahmood.github.io/publications.html)에서 후속 연구 **Automatic Correction of Generative AI Reports using Fact-Checking Model-guided LLMs**와 RadCheck 배포 링크를 새로 찾았다.

[후속 교정 논문](https://razi-mahmood.github.io/reports/NeurIPSHealthcareWorkshop.pdf)의 §3.4와 Table 2는 올바른 소견은 그대로 두고, 오류 유형에 따라 해당 문장을 수정하며, 검증기 출력 조합이 일관되지 않으면 교정을 하지 않는 규칙을 명시한다. 이는 단순한 오류 삭제보다 현재 보존 질문에 가까운 대안이다. 논문의 평균 품질 개선이 기존 정답의 손상률이나 잘못된 자동 영역 설명에 대한 내성을 직접 입증하는지는 아직 확인하지 않았다.

[RadCheck 공식 배포](https://huggingface.co/datasets/razi-mahmood/RadCheck)의 실제 자료 카드와 예시 행을 확인했다. 데이터 공개와 FC checkpoint·추론 코드 공개는 별개다. 현재 조회만으로 공식 실행 모델이 공개됐거나 부재한다고 결론 내리지 않는다. 대량 다운로드는 하지 않았다.

저자 목록의 CVPR 2026 후속 링크는 조회 오류가 났다. 내용은 확인하지 못했으며 이를 선행의 성능·실행 가능성 근거로 사용하지 않는다.

## Strategy Check / 연구 방향 판단

직전 리뷰가 이미 두 후보를 비교했으므로 과거 후보 전수 재선별은 반복하지 않는다.

1. **기존 선택적 교정 이후의 잔여 문제 확인 — 선택:** index12·15의 보존 손상을 강한 기존 수정 범위 제한과 연결한다. 이번에 발견한 후속 방법은 무수정 규칙까지 있어 비교군 선택에 직접 영향을 준다. 지배 비용은 공식 자산 확인과 사례 대응이며 실제 시간은 미측정이다.
2. **현재 frozen 인터페이스 재시험 — 보류 유지:** 초안 유지가 충분했던 표본, T 형식 실패, 원 종료 조건 때문에 추가 prompt·표본의 정보 가치가 낮다.

**시험 설정:** 전체 재작성 frozen 설정은 보류한다. **연구 관찰:** 특정 출력의 기구 누락과 새 오류를 보존하지만 빈도·일반 원인을 확대하지 않는다. **연구 질문:** 선택적 교정 이후의 잔여 가치가 확인될 때만 다음 실제 비교를 발주한다. ‘연구 질문이 남는다’는 이유만으로 투자를 지속하지 않는다.

## 남은 확인과 결정 변화

후속 논문의 전체 평가·부록 및 공식 모델 배포를 한정 확인해야 한다. 실행 가능한 비교군과 현재 사례가 구분할 실패 조건이 있으면 diagnostic 계획을 완성한다. 기존 방법이 이미 설명하거나 실행 가능한 강한 대조를 구체화하지 못하면 현재 교정 묶음의 보류를 확정한다. 공개되지 않은 대형 FC 모델의 처음부터 재학습을 자동 대안으로 삼지 않는다.

## 대규모 GPU 필요 후보

대규모 합성 소견–영상 자료로 FC encoder를 다시 학습하는 경로는 비용 검토 후보로만 보존한다. 현재 중요한 잔여 문제와 재현 경로가 확정되지 않았으므로 발주하지 않는다. 논문의 사용 GPU를 근거로 두 RTX 3090에서의 실행 불가능성을 단정하지 않는다.
