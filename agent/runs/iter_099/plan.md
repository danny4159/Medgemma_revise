# Proposed Experiment

## 1. 적격성 정정과 잠금

먼저 P008·P033·P053의 원 reference, amended reference, C-G와 관련 영역 출력 전체 문맥을 대조한다. 각 사실에 원문 span, 현재 소견, 위치·양측성, 확실성, 시간, 원인·속성, 초안 대응, 영역 대응을 연결한다. 사실 ID는 원 문장 ID와 연결된 세부 ID로 보존한다.

- P008: persistent와 현재 atelectasis-condensation을 분리한다. density/volume loss가 같은 현재 사실을 이미 표현한 것인지 별도 판단한다. 자동 동치나 자동 누락으로 처리하지 않는다.
- P033·P053: opacity 존재와 추정 원인에 붙은 hedge를 구분한다. 원인 hedge 제거만으로 위치·소견 대응이 명확해졌다고 판정하지 않는다.
- P는 양성만이 아니라 초안이 명확히 표현한 모든 reference-supported 원자 사실이다. 구체적 음성·범위가 명확한 정상 사실도 검토하되 포괄 정상문을 구체적 부재로 확장하지 않는다.
- marked, small, metapneumonic 등의 미표현 속성을 공통 소견과 분리한다. 공통 소견 대응을 인정해도 reference 전체 문장을 보존했다고 계산하지 않는다. 원 reference가 지지하지 않는 생성 위치·시간·원인은 별도 unknown 또는 미지원 주장으로 남긴다.
- 양측·복수 위치는 부분 대응을 전체 회복으로 계산하지 않는다. lobe–zone와 opacity–consolidation의 불확실한 동치는 unknown으로 둔다.

같은 오류가 전파되는 시간·원인·속성 사실과 자동 색인 누락 경로만 보완한다. P005·P042·P082의 P 제외 사유도 기록한다. 기존 48명에 대한 전체 적격성 ledger를 만들되 불변 원문 추출 검사는 출처로 재사용한다. 자동 색인 밖이라는 이유만으로 제외하지 않으며, 보편적인 의미 평가기를 새로 만들지 않는다.

P와 Q가 각각 명확히 존재하는 환자를 회복 집단으로 고정한다. 명확한 적격자가 1명이라도 있으면 사례 탐색은 가능하나 원 양성 기준을 낮추지 않는다. 나머지 중 P가 있고 Q가 없는 환자를 원 고정 hash 순서로 최대 회복 집단 수만큼 보존 대조로 선택한다. 총 M≤48이다. 정렬 키와 hash 방식을 manifest에 기록한다.

모든 quote·ID·중복·입력 연결 검사를 마친 뒤에만 잠금 결정 파일을 원자적으로 확정한다. 실패 시 오류 기록은 보존하되 유효한 잠금·생성 허용 파일은 만들지 않는다. `inputs_E96.json`, `reference_facts_E_private.json`, amendment, readings, linked와 실행 소스의 파일 hash를 포함한다. 변경 전후 P/Q·제외 이유와 실제 N 변화로 민감도를 계산하며 수동 서술로 불변을 단정하지 않는다.

N=0이면 생성 없이 종료한다. unknown을 clear로 바꾸기 위한 규칙 탐색은 하지 않는다.

## 자원·예상 비용·재개

실행 직전 nvidia-smi와 상속 CUDA_VISIBLE_DEVICES를 확인한다. 허용된 두 GPU에 독립 shard를 배치하며 논리·물리 장치 대응을 기록한다. 모델 추론 8~10GB는 참고값일 뿐이며 긴 입력의 실제 peak를 측정한다.

예상 wall-clock은 현재 미측정이다. 기술 실측 q requests/min으로 남은 기본 요청/q와 loading, cap 확장 비용을 계산해 본실행 전에 기록한다. 의미 검토 시간은 별도 계측한다. 임의 시간 상한은 두지 않는다.

중단 후 유효 완료 요청은 hash 확인 뒤 재사용하고 미완료만 새 attempt에서 재개한다. source/config 변경, 동시 중복 실행, 완료 파일 변조, 허용 밖 GPU를 거부하는 실제 검사를 수행한다. 장시간 작업은 supervisor와 experiment_wait.py 또는 동등한 완료 대기를 사용한다. 기존 환경·hf_cache는 변경하지 않는다.

# Evaluation (성공/실패 기준 포함)

원 평가 기준을 변경하지 않는다. 안전한 회복 환자는 Q를 최소 하나 회복하고 P를 모두 보존하며 K 대비 새 명시 반박·내부 충돌이 없는 환자다. 임상 안전성 보증이 아닌 reference 범위의 운영 지표다.

**양성:** T 또는 L이 K 대비 최소 3명의 안전한 회복을 보이고 N과 A 각각 대비 안전한 회복 환자 순증가가 최소 2명이어야 한다. P 손상·명시 오류 환자가 각 대조보다 증가하지 않고 두 보수적 분석에서도 방향이 유지돼야 한다. 충족한 요소에 한해 독립 확인 또는 method pilot의 투자 가치를 리뷰한다.

**출처 효과:** 위 조건에 더해 L−T 안전한 회복 순증가가 최소 2명이며 보존·오류 악화가 없어야 한다. 미달이면 내용 효과와 출처 효과를 구분한다.

**음성:** 명확한 기회가 있으나 N/A보다 개선하지 못하거나 손상으로 상쇄되면 현재 인터페이스 투자를 보류한다. 단순 추가가 충분한 범위는 받아들인다.

**불확정:** 표본 부족·unknown·검증 불가 증가에 따라 결정이 달라지면 현재 후보를 보류한다. 같은 자료의 prompt·규칙·표본을 더 조정하지 않는다. 재개에는 어느 결정을 바꿀지 특정된 독립 정답 근거나 새로운 대조 근거가 필요하다.

**자료/기술 종료:** 적격자 없음은 이 저장 출력 설계의 자료 적합성 부족이다. 입력·잠금·생성 실패는 실행 실패다. 어느 경우도 교정 효과나 위치 학습 전체의 음성 결과가 아니다.
