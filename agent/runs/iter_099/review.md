# Key Findings

1. 리뷰에서 저장 ledger를 독립 집계해 P-clear 14명, finding Q-clear 2명(P085/P090), 교집합 0명을 확인했다. 이 수치는 구현된 제한 아래의 산술 결과다.

3. P053 원문은 reference 'Small metapneumonic effusion', 초안 'Left pleural effusion', 영역 D08/D11의 small left pleural effusion이다. 원 계획은 크기와 공통 소견을 분리하도록 했으며, 속성 회복을 일괄 제외하지 않았다. left와 metapneumonic의 지지 여부는 별도 기록하면 된다.
4. P008의 초안 대응, P033의 apex–upper lobe 대응, P053의 consolidation–opacity 대응은 여전히 불확실하다. 이들을 clear로 바꿀 근거를 추가하지 않았다.
5. completion.json의 세 산출물 hash, provenance hash, 기록된 quote 검사의 무오류를 독립 확인했다. 실제 중복 fixture를 읽어 ValueError 발생도 재확인했다. 저장 회귀 검사는 9/9 통과지만 의미 규약 준수의 증거는 아니다.

# Problems / Concerns

현재 결론을 막는 문제는 finding-only 제한이다. 원 계획의 원자 사실 정의를 좁힌 뒤 N=0을 자료 적합성 부족으로 해석했다. 보고서의 '속성 포함은 완화'라는 설명도 원 계획에 근거하지 않는다. 정확한 전체 적격자 수를 이번 리뷰가 확정한 것은 아니지만 N=0 승인을 막기에는 P053 반례가 충분하다.

P 기록도 생성 평가 전에 보완해야 한다. P062의 더 구체적인 부정은 reference 전체를 재현하지 않아도 reference-supported 사실일 수 있다. P069의 suggestive 표현 등 확실성은 별도 atom으로 보존해야 한다. 문자열 포함 검사는 이러한 의미 대응을 검증하지 않는다.

ledger에 없는 환자의 제외 이유는 일괄 문구에 머물며, 고유 atom ID와 영역 출처 연결도 부족하다. 다만 전면 평가기 재개발 대신 현재 속성 제외의 영향 경로와 실제 선택 환자만 보완한다.

로그에서 보고된 실행과 테스트 명령을 확인했다. 두 권한 거부 후 대체 조회를 수행했으며 이것이 최종 미실행 원인은 아니다. 이번 로그에서 기존 결과 삭제는 확인되지 않았다. 의미 검토 시간은 미측정이고, 계획한 별도 계측은 빠졌다.

# Interpretation

시간 표현과 원인 hedge를 분리한 점, 중복 거부와 검사 실패 시 잠금 방지는 유용하다. 하지만 이 보완으로 회복–보존 가설의 경쟁 설명이 줄어들지는 않았다. 실제 교정 출력이 없으므로 성능·안전한 회복·출처 효과를 판단할 수 없다.

작은 N으로 원 양성 기준을 충족하기 어렵다는 점은 그대로 보고해야 한다. 그러나 원 계획은 적격자가 1명이어도 사례 탐색을 허용했다. 표본이 작다는 이유로 잘못된 제외를 정당화하거나 양성 기준을 낮추지 않는다.
