# Key Findings

1. **출력 완전성과 출처:** 696개 고유 요청과 출력이 정확히 대응했다. 695개는 EOS 종료했고 1개는 3회 cap 시도 후 unresolved로 남았다. 총 attempts는 698개다. 고정 명세로 696개 prompt를 재구성해 모두 일치함을 확인했다. completion 17개, 재사용 입력 115개, 평가 잠금 131개 hash 대조에서 불일치는 없었다.
2. **불일치 집단:** K/B/G/M/N/E/R/S 정답은 47/40/54/54/34/29/26/53명이다. R의 확정 손상은 0명이지만 원 보수적 harm은 unresolved를 포함한 21/47명이다. R 정답 범위는 26–69명, 교정 범위는 0–22명이다.
3. **일치 대조:** K/B 모두 정답 76명 중 R은 56명 보존, 20명 unresolved, 확정 오답 전환 0명이다. 보수적 harm 26.32%는 원 5% 기준을 충족하지 못한다. K/B 모두 오답인 11명에서는 R 교정 0명, unresolved 9명이다.
4. **독립 검산:** 저장 verifier 458/458 검사와 별개로 리뷰에서 원출력 계수 및 주요 paired bootstrap을 재계산했다. R−N −9.20pp [−17.24, −2.30], R−E −3.45pp [−12.64, 5.75], R−S −31.03pp [−41.38, −21.84]를 재현했다. verifier의 전체 집계·범위·CI·최종 부등식도 메모리에서 재실행해 일치했다.
5. **남는 관찰:** 불일치의 resolved R 44/44, N 63/63은 초안을 유지했다. E가 교정한 8명의 R은 고정 평가상 1명 오답·7명 unresolved였다. 8개 원문을 직접 확인했으며 모두 최종 답 방향이 잘못된 초안과 같았다. 이는 보조적인 원문 관찰이며 기존 점수를 변경하지 않는다.
6. **위치 공동 지표:** IoU0.3 공동 성공은 불일치에서 R 19명, B 36명, S 32명이다. 최종 답으로 고정 detector box를 유지·제거하는 평가이며 새로운 위치 생성이나 box 수정 성능이 아니다.
7. **자원:** 기존 2/4 worker 비교를 재사용해 GPU당 2 worker로 본생성 873.879초, 약 47.79요청/분을 기록했다. OOM은 없었다. 관측 최소 free는 GPU별 약 6.4GiB로 두 worker의 합산 4GiB 여유를 넘었다. 현재 기록에서 계측된 생성 비용은 준비 경로 32.865초보다 크지만 구현·검증 전체 비용의 비율은 미측정이다.

# Problems / Concerns

**GT 접근 조건 위반:** `ed117_run.py`가 평가 파일까지 locked_files에 포함했다. worker의 `verify_protocol`은 GT/labels 파일을 hash 계산으로 읽었다. 원 계획의 읽기 분리는 지키지 못했다. 다만 해당 값은 무결성 검사에만 사용되고, 실제 생성 입력은 요청의 영상과 prompt다. 전체 prompt 재구성도 일치했다. 따라서 이 위반만으로 현재 출력을 누수 실험으로 기각하거나 696개를 재생성할 근거는 없다. SELF_CHECK FAIL은 보존하고 다음 실행 전 수정 사항으로 판정한다.

**응답 해석:** R의 불일치 unresolved 43건은 고정 규칙의 hedge_or_conditional이다. 실제 원문에는 명시적 Yes와 'could', 'possible' 등이 함께 있다. 이를 모두 답변 거부나 내용 오답으로 표현하면 과장이다. 반대로 사후 parser 변경으로 교정 성공을 만들 수도 없다. 현재 불확정 판정과 보수적 점수를 유지한다.

**재사용:** 외부 중단 후 `ed117_run launch` 재호출은 execution_start 때문에 거부된다. 기존 runner를 이용한 재개는 별도 검증 절차가 필요하다. 이번에는 중단이 없어 현재 결과를 무효화하지 않지만 전체 스냅샷은 승인하지 않는다.

**범위:** 반복 개발 RSNA에서 K/B 불일치로 선택한 집단이다. 이진 불일치에서는 둘 중 하나가 맞는 구조이며 모집단 성능이나 독립 일반화로 해석할 수 없다. T와의 차이로 영상의 인과적 사용을 주장하지 않는다.

# Interpretation

공개 정답은 사전 지정 opacity의 존재와 표시된 위치에 대한 비교를 뒷받침한다. 자유 판독문 전체의 임상 정확성이나 위치 학습의 인과 효과를 평가한 것은 아니다.

원 가설의 실용적 성공은 확인되지 않았다. R의 보수적 효용은 단순 대안보다 낮다. 그러나 unresolved가 많아 내용 수준의 교정 불능을 확정할 수 없다. E도 기본 수행과 응답 해석 문제가 남으므로 R의 저하를 순수한 선택적 근거 사용 결함으로 단정하지 않는다.

- **실행 유효성:** 준비만 완료한 iter_116과 달리 실제 본출력을 얻었고 수치를 재현했다. GT hash 접근은 재사용 결함으로 한정한다.

- **신규 기여 가능성:** 선택적 교정 자체는 기존 연구 영역이다. 새 방법의 필요성이나 기존 강한 교정 방법 이후의 잔여 가치는 아직 입증되지 않았다.

**시험 설정:** 보류한다. **연구 관찰:** 원출력과 불확정 범위를 보존한다. **연구 질문:** 독립 자료에서 초안 내용만 바꾸는 비교가 가능한 경우에 한해 좁게 유지한다.

투자 후보는 두 가지다. 첫째, E에서 교정됐지만 R에서 사라진 8개 사례를 출발점으로 독립 자료의 초안 내용 대조를 검토한다. 목적은 기초 인식이 전혀 없다는 설명과 초안에 따른 답변 변화의 구분이며, 비용은 제한된 추가 추론과 자료 연결이다. 둘째, 현재 교정 설정과 iter_115의 CURE 특화 투자를 함께 보류한다. 후자는 현재의 낮은 효용과 높은 평가 의존성에 근거하며 비용이 가장 작다.

다음 계획에서는 첫 후보의 성립 여부만 한정 판단할 것을 권고한다. 구체적 대조가 성립하지 않으면 두 번째 선택으로 종료한다. 현 자료 재채점·범용 평가기 보수·후속 loss 탐색은 선택하지 않는다. 현재 중요한 불확실성을 그대로 둔 채 새 모델·자료 이름만 바꾸지 않는다.

논문 추천은 보류한다. 이번은 성능 성공이나 방법의 유망성이 확인된 결과가 아니라 원 성능 판정이 불확정인 제한적 진단이다.
