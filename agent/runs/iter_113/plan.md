## 1. 분석 잠금과 동작 확인

새 결과 경로는 `research/results/iter_113/`이다. 아래 규칙과 코드·입력 hash를 protocol에 기록한 뒤 순위와 GT 오류를 결합한다. 기존 자료의 과거 결과는 이미 알려져 있으므로 미사용 test 사전등록이라고 부르지 않는다.

## 2. 검토 단위·순위·검토량

- 단위는 영상–소견 하나다. 한 환자의 여러 소견은 별도 검토 항목이며 통계 의존성은 환자 단위로 처리한다.
- MG 예측 집합 M은 기존 0.8 출력 그대로다. CURE 집합 C는 기존 엄격 parser와 최종 EOS로 읽는다.
- 불일치 위험 D = 1−IoU(union(M), union(C)). 둘 다 빈 출력이면 D=0, 하나만 비면 D=1이다. 이는 공유 누락을 탐지하지 못하는 신호의 한계다.
- confidence 위험 B = 1−min(MG 유지 box scores). MG가 비면 confidence=0으로 둔다. 누락된 score를 0으로 대체하지 말고 기술 결함으로 처리한다.
- CURE malformed/truncated는 공간 불일치와 구분해 기록한다. 해당 항목은 두 순위 모두에서 공통 제외하고 제외 규모를 보고한다. 정상적으로 종료한 좌표 없는 출력은 빈 집합으로 유지한다.
- 순위는 위험 내림차순, 동률은 SHA256(`iter113|item_key`) 오름차순이다. GT·환자 결과를 tie-break에 쓰지 않는다.
- 검토량 K=ceil(0.25N). N=47이면 K=12다. 다른 검토율·가중치·결합 점수는 만들지 않는다.

## 3. 공개 주석 오류와 모호성

공식 주석 집합 G에 대해 E_G = 1[union IoU(M,G)<0.3]으로 고정한다. 빈 MG는 오류다. 이 endpoint는 소견 전체 영역 합집합의 낮은 정합성이며 box 개수·개별 병변 누락·임상적 FP와 다르다. 분할 방식 차이에 덜 의존하도록 합집합을 사용한다.

대체 판독자 주석 H가 있으면 같은 E_H를 계산한다. 두 주석에서 모두 오류면 일치 오류, 둘 다 비오류면 일치 비오류, 판정이 다르거나 H가 없으면 미확정으로 둔다. 미확정을 정상이나 확정 오류로 강제하지 않는다. 순위와 검토량은 주석별로 바꾸지 않는다.

공식 주석 주수치와 함께 미확정 항목의 오류 상태를 0/1로 배정했을 때 포착 차이의 정확한 최소·최대 범위를 계산한다. 계수는 D-only 선택 +1, B-only 선택 −1, 양쪽 또는 미선택 0이므로 전수 조합 생성 없이 계산할 수 있다. 공유 선택 항목은 두 조건에서 동일 상태를 사용한다.

## 4. 가능성 탐색

연결된 전체 범위에서 한 번 계산한다. 주수치는 D와 B의 오류 포착 건수, 차이/N, 검토 precision이다. N과 전체 오류 수도 함께 보고한다.

상보성은 D-only가 잡은 오류, B-only가 잡은 오류, 공통 포착, 양쪽 모두 놓친 오류 및 해당 환자 수로 보고한다. 두 선택 집합의 합집합 포착을 K개 검토 성능처럼 표현하지 않는다. D-only의 추가 포착이 있다는 사실만으로 대체 우위나 결합 정책의 효과를 주장하지 않는다.

환자 cluster bootstrap 10,000회, seed113으로 95% 구간을 보고한다. 환자를 복원 추출해 그 환자의 모든 소견을 복제하고 N_b·K_b를 다시 계산해 두 순위를 재선택한다. 복제 항목의 동률은 원 hash 뒤 복제 순번을 사용한다. 최대 36회 leave-one-patient-out에서도 K를 다시 계산한다. CI는 탐색 불확실성이지 확증 gate가 아니다.

검토 경계 동률에 대해서는 각 순위의 가능한 최소·최대 오류 포착을 산출한다. 보수적 차이는 D 최소−B 최대다. 주석 미확정까지 포함한 보수적 분석도 같은 선택 규칙으로 계산한다.

# Evaluation (성공/실패 기준 포함)

**양성 탐색:** 공식 주석 기준 순포착 이득이 ceil(0.05N)개 이상이고 D-only 추가 오류가 최소 2명에 걸친다. 주석 미확정과 경계 동률의 보수적 분석에서도 순이득이 양수이며 leave-one-patient-out에서 음수로 바뀌지 않아야 한다. N=47에서는 최소 3개 순증가로, 한 사례의 우연한 교환을 넘어 독립 확인을 검토할 최소 탐색 이득이다. 통계적 유의성이나 논문 기여 기준은 아니다.

**음성:** 유효한 주비교에서 순포착 차이가 0 이하이면 고정 불일치 순위의 대체 가치는 지지되지 않는다. 상보성 표는 보존하되 현재 오류 검토 묶음 투자를 보류한다. 추가로 잡은 오류가 있어도 놓친 오류와 비용을 생략하지 않는다.

**불확정:** 작은 양의 차이, 주석·동률·환자 의존, 사건 부족이면 현재 투자를 보류한다. 의미가 불분명한 상보성을 이유로 점수 결합·새 모델을 발주하지 않는다. 연결 실패는 실행·자료 문제이며 가설 음성과 분리한다.

이 종료 기준은 이번 새 분석에만 적용한다. iter_107의 핵심 사건 정의나 iter_112의 원 판정을 바꾸지 않는다. 다음 반복은 full review와 사용자 승인 이후에만 진행한다.

# Risks / Checks

- 반복 개발 자료이며 CURE 사전학습 노출은 미확인이다. 독립 일반화·동일 학습 예산 비교가 아니다.
- 모델 간 불일치 자체를 오류 정답으로 쓰지 않는다. 양쪽이 같은 오류를 내면 이 신호는 놓친다.
- union IoU는 영역 면적 지표다. 작은 영역의 누락을 모두 반영하지 않으며 임상적 중요도와 동일하지 않다.
- 두 판독자의 분할·경계 차이와 대체 주석 부재를 보존한다. 전문의 판정을 대신 만들지 않는다.
- MG scores는 기존 후처리 결과와 연결한다. 다른 운영점의 box에 score를 섞지 않는다.
- CPU 분석이 이번 질문에 충분하므로 GPU를 쓰지 않는다. GPU 진입 조건은 이번에는 없으며, 새 실행은 양성 결과의 독립 확인 가치를 검토한 다음 승인 대상이다. GPU별 배치·메모리·worker 비교는 해당하지 않는다.
- CPU 시간은 첫 200회 bootstrap 실측으로 예상 wall-clock을 갱신한다. 임의 시간 상한은 없다. 분석의 GPU 비용 0을 실제 두 모델 서비스 비용 0으로 표현하지 않는다.
- **대규모 GPU 필요 후보:** 공동 uncertainty 학습이나 대규모 grounding ensemble 학습은 가능한 후속 범주지만 현재 근거가 없다. 이번에는 구체적 개발 후보로 채택하거나 자원을 요청하지 않는다.

# 계획의 근거 (GPT 조사 노트)

- `agent/GOAL.md`, iter_112 리뷰 원문, iter_107·046 review.json과 관련 CODE_ASSETS/LIMITATIONS 항목을 확인했다. iter_112의 오류 포착 16 대 24 음성과 고정 경로 종료를 유지한다.
- iter_107 리뷰는 47개 실제 CURE 출력·36명 연결과 기하 재계산을 확인했다. 핵심 10명 모두 보존이라는 결과는 수용하며 이번 선정 조건으로 사용하지 않는다.
- `research/results/iter_107/data/cohort_summary.json`에는 47개·36명, 공식 box 수 2/3/4/6개, 대체 주석 수 0개인 소견 3개·1개인 소견 8개·2개인 소견 36개가 기록돼 있다. 주석 부재와 분할 차이를 보존해야 한다.
- `items.json`의 실제 행에서 ImageID/PatientID/StudyID/finding_index/sentence_sha256, 공식·대체 주석, MG request ID, 운영점별 boxes/scores와 영상 크기·pixel hash 필드를 확인했다. paired 순위 성능은 계산하지 않았다.
- 기존 MG 선택은 A_U_e5·threshold 0.8이다. 원 출력은 `results/iter_046/mg/V96_A_w2b4/raw_worker{0,1}.jsonl`, 선택 기록은 `results/iter_046/decisions/final_selection.json`이다. `nr107_data.py` 보관본에서 원 manifest·문장 hash·영상 pixel hash 연결 방식을 확인했다.
- threshold 0.4와 0.8의 저장 좌표·score가 서로 다르므로 한 목록에 threshold만 다시 적용한 것으로 취급하지 않는다. 이번에는 기존 선택 운영점 0.8만 사용한다.
- 현재 research 작업 트리의 status/diff 출력은 비어 있다. nr107 파일은 현재 브랜치에 없지만 보관 커밋에 존재한다. 승인된 geom/spec 두 파일만 선별 반입한다. 기존 nr107_eval/verify의 분기·검증 결함은 계승하지 않는다.

## 의미와 선행 관계

기존 iter_082 plan.json의 confidence/selective prediction/ensemble 조사와 iter_046의 MedGrounder 원 논문 검토를 재사용한다. 이번에는 새로운 문헌 성능·지원 범위 주장을 추가하지 않으므로 전수 재검색하지 않는다. 가까운 방식은 독립 재-grounding과 ensemble disagreement이며, 단순 불일치 순위의 성공도 신규 방법은 아니다.

자료가 반복 개발 집단이고 과거 점수를 이미 확인했으므로 이번 잠금은 새 분석의 사전 규칙 고정이지 미사용 test 사전등록이 아니다. confidence 대체 성능과 추가 포착의 상보성은 구분한다. 실제 paired 분석 성립과 양성 여부는 아직 미확인이다.
