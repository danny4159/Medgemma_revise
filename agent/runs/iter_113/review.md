# Key Findings

1. **연결:** 원 모집단 47개·36명을 모두 연결했고 제외는 0개다. 원 MG 운영점 0.8의 box·score, CURE 문장·출력, 원 annotation을 대조했다. 원 영상 36개 hash와 CURE 47개 최종 EOS token을 확인했다. CURE는 nonempty 45개·정상 종료한 좌표 없는 출력 2개다.
2. **주비교:** 공식 주석의 union IoU<0.3 오류는 15개다. 불일치와 confidence의 포착은 9 대 6, precision은 0.75 대 0.50, 차이/N은 0.06383이다.
3. **상보성:** 불일치 순위만 포착한 오류 7개·7명, confidence만 포착한 오류 4개·4명, 공통 2개, 양쪽 미포착 2개다. 합집합 포착을 12개 검토 성능으로 계산하지 않았다.
4. **강건성:** 실제 검토 경계에 동률은 없고 동률 범위는 [+3,+3]이다. 판독자 불일치 7개와 대체 주석 부재 3개를 미확정으로 둔 정확한 차이 범위는 [+2,+7]이다. 환자 제거 차이는 [+2,+3]이다.
5. **표본 불확실성:** 환자 재표집마다 N과 K를 다시 계산한 bootstrap 10,000회의 95% 구간은 [-2,6]개다. 양의 차이 비율 0.8211은 가설이 참일 확률이 아니다.

원시 CURE·MG 출력과 원 manifest에서 별도 좌표 grid 면적 계산을 작성해 선택 ID·오류 수·민감도 범위를 재계산했다. bootstrap 배열 전체와 환자 제거 결과도 일치했다. 구현자의 fixture 36/36 및 독립 검증 19/19는 저장 결과와 도구 로그에서 확인했으며, 쓰기를 수행하는 테스트 실행기를 리뷰에서 재실행하지 않았다.

# Problems / Concerns

현재 주결론을 무효화하는 문제는 발견하지 않았다. 다만 전체 스냅샷 재사용은 승인하지 않는다.

- `cmd_seal`은 verify의 all_pass만 확인한다. 현재 입력·소스·결과를 검증 당시 digest와 연결하지 않아 오래된 PASS로 새 결과를 봉인할 수 있다. 현재 결과는 리뷰에서 hash와 수치를 직접 확인했다.
- 분석 산출물을 순차 기록한 뒤 중단되면 기존 파일 거부로 재개할 수 없다. 계획한 안전한 재개는 미완료다. 실제 재사용 때 해당 경로만 보완한다.
- 첫 200회 시간 추정 및 전체 단계별 CPU 계측은 누락됐다. 기록된 분석 시간은 0.611초, bootstrap은 0.581초다. 구현 세션은 약 265.5초지만 이를 CPU 연산 시간으로 해석하지 않는다. 코드 작성·검증이 주 작업이었다는 로그는 있으나 단계별 지배 비용은 정량 분해되지 않았다.
- 보고서의 공유 누락 설명을 정정해야 한다. MG 빈 출력은 0개이고, 두 순위가 놓친 오류 2개는 두 모델의 공유 빈 출력 사건이 아니다.

# Interpretation

사전 최소 순이득은 3개였고 실제 차이는 정확히 3개다. 보수적 범위 하한에 요구한 조건은 3 이상이 아니라 **0 초과**였으므로 하한 2는 통과다. CI가 0을 포함한다는 이유로 사전 탐색 기준을 소급 변경하지 않는다. 따라서 양성 탐색의 success와 일반화 효과의 불확실성을 함께 기록한다.

주석 차이만으로 현재 선택 집합의 이득이 사라진다는 설명과 단일 환자가 전부 좌우한다는 설명은 약해졌다. 반면 낮은 confidence와 완전히 독립인 정보라는 주장, CURE 고유의 이점, 일반 ensemble 대비 우위는 검증하지 않았다. union IoU 오류는 공개 영역 표시와의 정합성 오류이며 임상 오진·소견 부재·자유 판독 오류가 아니다.

# Strategy Check / 연구 방향 판단

- **시험 설정:** 고정 MG 운영점·불일치 점수·검토량의 탐색은 성공했다. 같은 47개에서 점수 결합·threshold·검토율을 다시 탐색할 이유는 없다.
- **연구 관찰:** 같은 검토량에서 3개 순이득이 생겼고 주석 민감도와 환자 제거에도 양의 방향이 남았다. 이번에 새로 배운 사실이다. iter_107의 핵심 10명 보존 성공 및 iter_111/112의 음성은 각각 유지한다.
- **연구 질문:** 공간 불일치의 오류 검토 정보가 독립 환자에서도 남는지 확인할 가치가 생겼다. 일반 ensemble라는 강한 경쟁 설명이 남으므로 곧바로 새 방법을 개발하지 않는다.
- **실행·성능·가설·기여:** 실행은 유효하다. 검토 순위의 표본 내 포착은 개선됐다. 좁은 가설의 탐색 근거는 양성이다. 모델 출력 개선·실용 비용 이점·신규 기여는 미입증이다.

투자 후보는 두 가지다. **미사용 환자와 일반 grounder 대조의 한정 확인**은 표본 변동과 일반 ensemble 설명을 구분하지만 새 출력과 비교군 비용이 든다. **현재 투자 보류**는 비용을 피하지만 사전 기준을 통과한 관찰을 미확인으로 남긴다. 현재는 첫 번째를 권고한다. 대량 학습이나 일반 평가기 개발은 정보 가치에 비해 이르다. 추가 분석 GPU 비용 0과 실제 두 모델 서비스 비용 미측정은 구분한다.

# Recommended Next Experiment

사용자 승인 후, 같은 양성 다중 영역 grounding 과제에서 미사용 환자를 고정하고 현재 순위를 그대로 확인한다. confidence, CURE–MG 불일치, 사전에 고른 일반 grounder–MG 불일치를 같은 검토량·오류 정의로 비교한다. 평가 대상 MG 예측은 고정하며 대조군의 학습·정보·비용 차이를 명시한다. 새로운 모델 자체의 확보가 목적이 되어서는 안 된다.

표본과 종료 기준은 이번 변동 및 필요한 정밀도로 다음 계획에서 정한다. 독립 이득과 일반 대조 이후의 정확도 또는 비용 가치가 남으면 방법 pilot을 검토한다. 일반 대조로 충분하거나 음성·불확정이면 현재 묶음을 보류한다. 데이터 독립성이나 대조가 성립하지 않으면 생성 없이 중단 이유를 보고한다. 다음 실행은 사용자 승인 전 시작하지 않는다.

논문은 일반 ensemble 설명을 강한 대조로 다루기 위해 [Simple and Scalable Predictive Uncertainty Estimation using Deep Ensembles](https://papers.neurips.cc/paper/7219-simple-and-scalable-predictive-uncertainty-estimation-using-deep-ensembles.pdf)를 추천한다. §2.4의 ensemble 구성과 §3.1·Figure 2의 평가를 확인했다. 이 논문은 현재 bbox 불일치 방식의 직접 재현 근거는 아니다.
