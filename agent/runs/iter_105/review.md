## 실제 결과와 독립 계산

E32 전 shard의 completion·protocol·요청 집합을 검사해 모델별 448개, 합계 896개 출력을 확인했다. 신규 학습은 없었다.

환자별 두 순서 평균과 환자 bootstrap 10,000회·seed105017을 별도 코드로 재계산했다. lenient의 N−W는 CURE 0.328125, 95% CI [0.250000, 0.406250], M15 0.546875, [0.500000, 0.593750]였다. 그러나 N−Text N은 각각 0과 0.093750이며 M15 CI는 [−0.015625, 0.218750]다. 어느 모델도 N≥0.70을 충족하지 않는다. 큰 N−W만으로 원 양성 기준을 통과한 것이 아니다.

CURE PG의 연결 정확도 32/32와 문장 평균 IoU 0.655483을 원문 좌표에서 독립 재계산했다. IoU≥0.3은 56/64문장이며 4문장은 box가 없었다. 고정 permutation matching은 한 문장의 근거만으로도 연결 정답을 만들 수 있으므로 32/32는 두 문장 모두의 완전한 grounding이 아니다. M15 PG 연결 16/32도 별도 verifier 재계산과 일치했다.

## 입력·사용법·실행 무결성

- pinned 원 metadata를 읽어 D4/E32/R64 총 100명의 문장·box·환자·train split 연결을 확인했다. 100명은 서로 다르며 raw uint16→uint8 변환과 영상 hash가 일치했다.
- contact sheet 00의 rendering을 직접 확인했다. 이는 임상 정답 검증이 아니다.
- 공식 입력·생성 대조는 모델별 12/12 통과 기록이 있다. 신규 runner도 매 요청에서 공식 chat template tensor와 입력을 대조한다. text-only에는 image token과 pixel_values가 없다.
- CPU 1922/1922, mutation 18/18 기록을 확인했다. mutation 18건에는 정상 사본 승인 2건이 포함되므로 모두가 변조 거부 검사는 아니다.
- 리뷰에서 D4 worker 구성 간 suffix token 112/112 일치, CURE 부분 재개 56/56 일치를 확인했다. D4 이후 소스 변경은 PEAK_MIB 한 줄이므로 생성·재개 검사 전체를 다시 할 필요는 없다.

## 자원과 비용

D4 wall-clock은 2183.5→2063.1초였다. E32 CURE는 2 worker로 835.3초, M15는 4 worker로 8000.1초였다. 자원 로그의 GPU별 최대 점유는 D4 병렬 비교에서 18858/18787 MiB, E32 M15에서 17948/17879 MiB였다. 두 GPU를 사용했고 완료 코드는 모두 0이다.

E32 M15 text-only 생성시간 합은 22716.9초로 기록상 주요 생성 비용이다. 준비·검토의 사람/모델 시간은 별도 계측되지 않았다. 요청 runtime 합은 병렬 wall-clock이나 device-time과 동일하지 않다.

CURE PG는 **문장당 6.33초, 두 문장 연결당 12.67초**다. 직접 선택은 평균 2.98초다. 보고서의 '6.3초(문장 2개)'는 정정한다. PG의 정확도 이점을 같은 비용의 이점으로 읽을 수 없다.

# Problems / Concerns

1. **계획 변경:** 원 계획은 semantic parser 추가를 금지했다. 구현은 lenient_v1을 추가하고 어느 parser라도 통과하면 확대하도록 바꿨다. E32 소스 digest로 parser 고정은 확인되지만 이 변경이 원 계획의 승인을 대신하지 않는다. strict를 주판정으로, lenient를 미승인 보조 분석으로 제한한다. 두 분석 모두 확대하지 않으므로 이번 중단 결론은 유지된다.
2. **기록 시점:** `D4_decisions.md`는 실제 로그에서 E32 평가 후 작성됐다. 사전 기록으로 인용하지 않고 실행 protocol과 수정 로그를 근거로 삼는다.
3. **평가기 재사용:** valid-only 분석이 `valid_echo`와 `valid_statement`를 제외한다. 충분성 자동 판정도 점추정치만 본다. 향후 이 경로를 사용할 때 고쳐야 하며, 이번 불확정 판정을 뒤집지는 않는다.
4. **정밀도:** 32/32에 대한 경험적 bootstrap [1,1]은 모집단 정확도의 확정을 뜻하지 않는다. CURE의 PadChest-GR 학습 노출도 배제하지 못했다. 대안은 이 개발 표본의 연결 과제에서 유망하다고만 표현한다.
5. **검증 범위:** verifier 수정 후 수치 일치는 확인됐지만 production parser와 모든 입력에서 동등하다는 증명은 아니다. 원 실패 파일은 보존돼 있다.
6. **보고 범위:** reserve 영상은 이미 추출·검사됐다. 'R64 미개방'은 모델 평가 미실행으로 고쳐 읽는다. M15의 낮은 성능 역시 이 인터페이스의 관찰이며 모델에 기본 능력이 없다는 일반 명제가 아니다.

현재 제한된 결론을 무효화하는 blocking issue는 없다. 전체 스냅샷 재사용은 평가·판정 경로의 문제 때문에 승인하지 않는다.

# Interpretation

공개 정답은 두 소견 문장의 주석 영역 연결을 평가한다. 교환 제안이 모든 임상적 해석에서 거짓이라는 정답이나 자유 판독의 완전한 정답은 제공하지 않는다.

이번 결과는 선택 형식과 독립 grounding이 같은 능력 측정이 아님을 보여준다. CURE에서는 독립 재구성이 강했지만 직접 선택의 영상 기여는 확인되지 않았다. M15에서는 형식 실패와 낮은 PG 성능 때문에 충분한 인식 이후의 제안 손상을 주장할 수 없다. lenient 보조 결과의 제안 추종은 보존하되 일반적인 시각 근거 무시나 내부 원인의 증거로 승격하지 않는다.

기존 iter_017의 인터페이스 관찰과 iter_088의 영역 판독 결합 관찰은 별도 과제다. 이번 결과로 그 빈도나 원인을 재현·정정하지 않으며 limitation_updates는 비운다.

# Strategy Check / 연구 방향 판단

- **시험 설정:** 고정 A/B 선택 인터페이스의 추가 투자를 보류한다. E96·추가 prompt·LoRA·모델 교체를 자동 발주하지 않는다.
- **연구 관찰:** CURE의 독립 주석 연결 대안과 선택 인터페이스의 낮은 성능은 보존한다. 제안에 따른 답변 변화는 보조 관찰이며 기본 능력과 분리된 손상은 미확정이다.
- **연구 질문:** 외부 위치 근거가 판독·판단을 어떻게 바꾸는지는 이번 결과로 기각되지 않는다. 그러나 질문이 남는다는 사실만으로 현재 후보의 추가 투자 가치는 성립하지 않는다.

실행 유효성은 확보됐다. 새 방법의 성능 개선은 시험하지 않았다. 원 제안 손상 가설은 지지 기준에 미달했고, 신규 기여 가능성도 확인되지 않았다.

투자 선택은 두 가지로 좁힌다. 첫째, 같은 선택 형식을 보완하면 형식 설명을 줄일 수 있지만 원 계획의 종료점과 충돌하며 강한 PG 이후의 가치가 없다. 선택하지 않는다. 둘째, 실제 자동 제안 오류와 PG 이후의 잔여 오류를 근거로 재개하는 것은 실용적 질문에 가까우나 현재 그 증거가 없다. 따라서 **현재는 범위를 명시한 투자 보류**를 선택한다. 독립 grounding이 가능한 다른 모델을 찾는 것만으로는 이번 CURE 결과보다 정보 가치가 높다고 볼 수 없다.

iter_103의 자유 판독 경로 역시 새 정답 근거 없이 재채점·생성을 반복하지 않는 판단을 유지한다. 추가 전문의 자원 불가를 연구 전체의 기각으로 확대하지 않는다. 누적 체류 횟수가 아니라 이번에 남은 경쟁 설명과 생성 비용에 근거한 결정이다.

# Recommended Next Experiment

즉시 추가 실험은 권고하지 않는다. 현재 후보를 보류하고, 재개 시에는 실제 자동 제안의 오류 또는 독립 grounding이 놓치는 중요한 오류를 특정한 뒤 동일 정보·비용 조건에서 비교할 하나의 계획을 세운다. 그 근거 없이 R64 평가, 새 모델 순회, parser 정비만의 반복을 만들지 않는다.

연구 목표는 미완료이므로 CONTINUE를 유지하되 다음 반복 실행 승인은 별개다. `--confirm-each-iter`에 따라 결과·보류 이유·대안을 보고하고 사용자 승인 또는 피드백을 기다린다.

논문 추천은 보류한다. 현재 제안 손상 방향은 불확정이며, 제한된 대안 성과만으로 새 후속 방법의 유망성이 확인되지는 않았다.
