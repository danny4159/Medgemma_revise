# 이번 판단

자유 판독문 전체의 정답 확정 대신 **외부의 소견–영역 연결 제안이 시각적 연결 판단을 어떻게 바꾸는가**를 우선 질문으로 선택했다. 다만 실행 계획은 아직 확정하지 않는다. 공개 양성 box를 교환한 것만으로 임상적으로 틀린 소견을 만들었다고 볼 수 없으며, 기존 grounding+규칙 이후의 잔여 가치를 확인해야 한다. 다음 확인은 같은 iter_105의 설계를 끝내기 위한 작업이다.

- `agent/GOAL.md`, `agent/runs/iter_104/plan.md`, `iter_103/review.md`, `iter_102/plan.md`, `iter_101/review.md`, `iter_053/review.md`를 읽었다. iter_104는 전문가 자원 질문에서 중단됐으며 실험 실패가 아니다. 사용자 답변 '없음'을 반영해 P001/P002 자유 문장 확정 경로를 보류한다.
- iter_103은 P001의 추가 핵심 소견을 보존하지만 문장에 붙은 시간·원인까지 확정하지 않는다. P002의 핵심 정보는 넓은 폐 영역에도 있어 세부 영역 고유 이득의 근거가 아니다. 같은 사례의 추가 생성·재채점은 선택하지 않는다.
- iter_101은 초안 유지보다 교정이 유리하다는 근거를 확보하지 못했고, 텍스트 조건의 형식 실패와 양성 편중이 있었다. iter_102는 선택적 수정·불일치 시 무수정이 이미 선행 방법에 포함됨을 확인했다. 이를 새로운 방법으로 재제안하지 않는다.
- iter_053의 448개 출력 중 oracle 오류 9건은 정상 JSON의 내용 오류였다. 원래 192/192 gate와 E/F 미실행 판정은 유지한다. 이번 후보의 근거를 해당 실험의 성공으로 바꾸지 않는다.
- `agent/LIMITATIONS.md`의 두 관련 항목을 확인했다. iter_017의 좌표 전달 결과와 iter_088의 영역 출력 관찰은 연결점이지 이번 제안 의존 가설의 검증 근거가 아니다. 특히 후속 의미 평가 문제 때문에 iter_088의 충돌 빈도를 현재 확정 수치로 사용하지 않는다.

## 공개 자료와 평가의 연결

`research/results/datasets/padchest_gr/raw/grounded_reports_20240819.json`은 로컬에 존재하며 4,555개 report 항목을 가진다. 첫 실제 항목에서 `sentence_en`, `abnormal`, `boxes`, `extra_boxes`, `labels`, `locations`, `progression`을 확인했다. 양성 소견인데 box가 없는 항목도 있었다. 따라서 report 존재나 양성 label만으로 영역 연결 평가 적격성을 보장할 수 없다.

`research/pg39_data.py`는 공식 metadata 두 파일의 pinned hash, ImageID–PatientID–StudyID–split 연결, 중복과 split 충돌 검사를 포함한다. iter_039의 원 `review.json/code_assets`는 이 metadata 읽기·연결 검사와 분할 ZIP reader 범위를 승인했다. 기존 표본 선정 규칙을 새 과제에 그대로 적용하는 승인은 아니다.

중요한 해석 경계는 다음과 같다. 주석 문장 A와 box A의 연결은 평가할 수 있지만, A의 box가 아닌 곳에 A 소견이 전혀 없다는 뜻은 아니다. 두 양성 연결의 교환을 '틀린 임상 주장'으로 자동 지정하지 않는다. 후보가 성립하려면 주석 연결 선택이라는 제한된 과제를 명시하거나, 명시적인 부정·상호 배타적 관계가 있는 자료를 확보해야 한다. 자유 문장의 모든 속성을 assistant 판단으로 채우지 않는다.

## 가까운 선행과 반대 근거

[CURE 공식 논문](https://arxiv.org/html/2601.15408v1)과 [공식 저장소](https://github.com/PabloMessina/CURE)는 phrase grounding, grounded report generation, 영역 판독을 이미 다룬다. 후보 실험은 공식 phrase grounding 경로와 새로운 제안 제공 조건을 구분해야 한다. 확장 조건의 실패를 CURE 재현 실패라고 부르지 않는다.

[Phrase-grounded Fact-checking 원문](https://arxiv.org/html/2509.21356v1)의 §2.1–2.2를 확인했다. 이 연구는 소견의 polarity·위치·종류를 교란한 학습 자료와 위치·진위 예측을 사용한다. 따라서 잘못된 위치 연결 탐지 자체는 새로운 기여가 아니다. 이번 후보의 정보 가치는 기본 시각 연결 능력과 외부 제안에 대한 반응을 분리하고, 독립 grounding으로 다시 계산하는 단순 대안이 충분한지 판단하는 데 있다. 이 차별성은 아직 실험적 잔여 문제로 확인되지 않았다.

## Strategy Check / 연구 방향 판단

**시험 설정:** 기존 LoRA 확대, E32 자유 판독 교정, oracle 문구 재시험은 보류를 유지한다. 신규 학습을 선택하지 않았다.

**연구 관찰:** 영역 출력에서 추가 정보와 불일치가 나타났다는 제한된 관찰은 보존한다. 외부 제안 때문에 이미 가능한 시각 판단이 손상된다는 현상은 아직 확인되지 않았다. 같은 현상의 독립 재현이 아니라 기존 관찰에서 파생한 새 후보 탐색이다.

**연구 질문:** 기술 질문 → 잘못된 연결 제안에 따른 선택 손상과 올바른 연결 보존 → 공개 문장–box 연결 및 제안 없는 독립 grounding 대조 → 주석 연결 판단의 제한된 주장으로 좁힌다.

후보는 두 개만 비교했다.

1. **소견–영역 연결 제안의 영향:** 실제 사용 문제는 자동 근거의 연결 오류가 후속 판단으로 전파되는 조건이다. 기본 grounding 부족과 제안 의존을 분리할 수 있고, 독립 재구성 대안의 충분성이 다음 투자 결정을 바꾼다. 자료·추론 자산을 재사용할 가능성이 있다. 현재 우선 후보로 선택했다.
2. **자유 판독의 선택적 누락 회복:** CURE hybrid·넓은 영역 추가 이후의 오류를 판별할 정답 부족이 그대로다. 전문가 자원도 없으므로 현재 자료 기반 투자를 보류한다. 새로운 판별 가능한 정답이 재개 조건이다.

첫 후보도 단순 grounding으로 충분하면 방법 개발로 이어가지 않는다. 같은 모델의 답을 다시 묻는 절차 자체를 기여로 삼지 않는다. MRI·새 modality 순회는 발주하지 않는다.

## 재사용과 실제 상태

`research/`의 `git status --short`와 `git diff --stat`는 변경을 표시하지 않았다. `git ls-files`로 `pg39_data.py`, `pg39_spec.py`, `report101_gen.py`, `report101_cure.py`, `report86_common.py`, `pg43_run.py` 등의 존재를 확인했다. 현재 파일을 읽었지만 현재 blob과 승인 SHA의 동일성 검사는 아직 수행하지 않았다. 선별 반입이나 재사용 승인을 요청하지 않는다.

iter_101 원 code_assets에 따르면 생성 경로는 전 shard 요청 집합·중복 검사, 공식 transform 의존성 digest, 완료 행을 보존한 재개 검증이 필요하다. 해당 경로를 선택할 때만 수정한다. 기존 자유 문장 평가기는 새 제한 과제에 재사용하지 않으며, 사용하지 않을 의미 평가기를 정비하지 않는다.

이번에는 코드 수정·파일 생성·모델 실행·환경 구성을 하지 않았다. 자료 및 문헌 확인을 새 가설 검증으로 보고하지 않는다. 조사 시간과 후속 실험 비용은 아직 미측정이다.

## 다음 확인과 종료점

다음 라운드에서는 새 문헌 전수 조사 대신 원 metadata의 소수 연결 사례, 기존 적격성·노출 manifest, 공식 CURE phrase-grounding 입력·출력을 확인한다. 공개 정답의 판별 범위와 강한 단순 대조가 성립하면 표본·조건·요청량·GPU 배치·결정 기준을 고정해 implement한다. 성립하지 않으면 이 후보를 보류하며 또 다른 평가기 개발이나 임상 자원 질문으로 넘기지 않는다.

## 대규모 GPU 필요 후보

소견–영역 연결의 정확성과 잘못된 외부 제안에 대한 강건성을 함께 학습하는 post-training은 장기 후보로만 남긴다. 현재 현상·신규성·학습 필요성이 미확정이므로 발주하지 않는다. 큰 연산이 정답의 비배타성 문제를 해결한다고 가정하지 않는다.
