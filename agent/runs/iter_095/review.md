# Key Findings

1. **실행 완료:** E32 4개 shard의 completion hash, 256개 고유 ID, 전 출력 EOS를 독립 확인했다. 실행 소스 hash 24개도 현재 파일과 일치했다. 신규 학습과 E64 생성은 미실행이다.
2. **정상 사용 대조:** D8 기록에서 2/4 worker의 16개 token 출력이 같고, 기존 Locate 8건의 input_ids·pixel·token이 재현됐다. 동일 영상에서 공식 두 prompt를 비교한 실행 경로는 지지된다.
3. **산술 재현:** 저장 judgments와 조건 키를 별도로 파싱해 D8/L8/D2/L2 충돌 환자 수 14/10/0/0을 재현했다. D8−L8은 +12.5pp, 환자 bootstrap 95% CI [−3.125, 28.125]pp다. strict 회복 사실은 2/2/1/1, lenient는 7/7/1/1이다. 이는 저장 판정의 산술 검증이며 의미 검증과 다르다.
4. **자료 범위:** E96에서 현재 주 대상 양성은 9명·10사실, 명시적 음성은 8명이다. 모두 E32에 포함됐다. 나머지 E64에는 해당 reference 양성·명시적 음성이 없다. 다른 소견 미표기를 정상으로 바꾸어서는 안 된다.
5. **실제 잔여 불일치:** P006 등의 Describe 묶음에는 전체 폐의 clear 서술과 명시적 국소 opacity 서술이 함께 있다. 좌표 요구 제거가 모든 불일치를 해소하지는 않는다. 다만 두 형식 차이의 방향·크기나 좌표 요구의 기여 전체를 확정하지 않는다.

# Problems / Concerns

## 현재 정량 결론을 막는 평가 문제

- **급성 범위 소실:** P004와 P018의 'No acute pulmonary infiltrates'가 일반 infiltrate 부정으로 저장된다. 기존 소견의 급성 여부가 확인되지 않은 상태에서 확정 충돌로 계산할 수 없다.
- **명시적 정상문 누락:** P004의 'pulmonary parenchyma ... normal', P018의 'normal structure' 및 급성·만성 변화 부재가 '-'로 빠졌다. 이는 충돌을 반대 방향으로 누락할 수 있다.
- **불확실성 대상 혼합:** P005의 opacity 존재 진술 뒤 'may represent pneumonia'를 이유로 opacity 자체를 Pu로 처리한다. 영상 소견의 존재와 원인 진단의 불확실성은 별도로 판정해야 한다.
- **해부학 범위:** lobe를 U/M/L zone으로 바꾸고 집합 교집합으로 충돌을 판정한다. 회복에는 보수적 W를 적용하면서 충돌에는 같은 불확실성을 통제하지 않아 사전 계획의 lobe/zone 구분을 충분히 충족하지 않는다.
- **검토 범위 미완료:** 최종 judgments는 draft_v5와 byte 단위로 같다. 도구 로그에서도 초안 복사와 양성 목록·고유 부정 문구 확인이 보인다. 일부 원문 확인은 있었지만 모든 결정 사례와 고정 12명의 문맥 재점검은 완료되지 않았다.
- **회복과 오류 비용 분리 부족:** 동일 묶음에서 회복과 충돌이 공존하는 사례를 별도 표시하지 않았다. temporal_unsupported는 unmatched 주장만 세므로 P001의 'In comparison ... again' 같은 matched 회복의 미지원 시간 표현이 빠진다.

420개 quote가 실제 연결 원문에 존재함은 리뷰에서 별도 확인했다. 문자열 존재는 의미 판정의 정확성을 대신하지 않는다. verify 파일의 quote 검사는 상수 True이며, 독립 의미 평가로 볼 수 없다.

# Interpretation

현재 수치는 공식 Describe가 우월하다는 근거를 제공하지 않는다. 반대로 CI가 0을 포함하고 의미 판정이 미완결이므로 '좌표 요구가 충돌의 원인이라는 설명을 기각했다'는 보고서 문장은 과하다. 정당한 해석은 **좌표 요구 없이도 일부 영역 간 불일치가 존재한다**는 것이다.

strict 추가 회복 1명과 lenient 5명의 차이는 위치·시간·소견 확실성 판단에 의존한다. 현 단계에서 단순 두 영역 대안이 충분하다고 승인하거나 세부 영역 후보의 정보 가치가 작다고 확정할 수 없다. 사전 단순 대안 기준도 전체 E96의 운영 기준이므로 E32 숫자만으로 최종 충족이라 표현하지 않는다.

기존 iter_088의 observed 주장은 그대로 유지한다. 이번 평가에는 별도 결함이 있어 해당 한계를 승격·기각하거나 새로운 검증된 빈도를 덧붙이지 않는다. 공개 checkpoint의 개발 자료 노출과 assistant 평가 한계도 유지한다.

# Strategy Check / 연구 방향 판단

**시험 설정:** R/G 추가 epoch·seed·위치 loss 보류는 유지한다. 이번 CURE 인터페이스의 GPU 실행은 정상 완료됐으며 새 학습을 요구할 근거는 없다. 남은 E64에 주 대상 양성 기회가 없다는 사실은 확인됐지만, E32 기반 확대 분기 (a)/(b)는 올바른 의미 평가 후 판정해야 한다.

**연구 관찰:** iter_088의 영역별 소견 회복과 충돌 관찰을 이어받았다. 이번에는 Describe에서도 불일치가 남아 '좌표 요청을 제거하면 모두 해소된다'는 강한 설명은 약해졌다. 그러나 좌표 요구의 부분적 영향, 영역 범위 효과와 의미 평가 오류는 분리되지 않았다. 현재 14 대 10명을 확정 관찰로 축적하지 않는다.

**연구 질문:** 중요한 잔여 문제일 가능성은 남지만, 강한 단순 대안 이후의 정확한 회복 가치가 아직 미확정이다. 관찰의 존재만으로 새 일관성 방법을 정당화하지 않는다. CURE의 기존 영역 판독 방식과 구별되는 신규 contribution도 확인되지 않았다.

**실행 유효성 / 성능 / 가설 / 기여:** 실제 출력 비교는 유효하다. 성능 개선은 입증되지 않았다. Describe의 잔여 불일치 존재는 확인했으나 원인·효과 크기는 미확정이다. 방법 개발과 신규 기여를 승인하지 않는다.

**다음 투자:** 후보 교체나 추가 학습보다 결정에 영향을 주는 기존 출력의 한정 보완을 권고한다. 이번 오류는 원문이 남아 있어 새 GPU 실험 없이 확인할 수 있다. 보완 후에도 모호성이 결정을 좌우하면 이 후보를 보류한다. 단순히 의미 평가기를 범용화하거나 같은 E96의 새 prompt를 반복하는 투자는 권고하지 않는다.

**비용·운영:** 총4 worker는 D8 생성 구간에서 12.30 requests/min, 총2 worker는 10.41이었다. 전체 launch wall은 각각 155.84초와 160.69초로 차이가 작다. 본생성 wall은 약456.9초다. 두 GPU 최대 점유 20,048/19,977MiB는 이번 실행에 worker당 2GiB 여유를 남겼다. 다만 launcher 예약식은 일반적인 동시 worker별 여유 보장을 수정해야 한다. 도구 로그의 experiment_wait 사용과 기존 출력 보존도 확인했다. 의미 검토 비용 비율은 계측되지 않았다.
