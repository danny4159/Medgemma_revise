## 5. GPU·시간·재개

실행 직전 nvidia-smi로 허용 GPU 0,1의 실제 메모리와 논리/물리 대응을 확인한다. 다른 사용자 프로세스는 건드리지 않는다.

기존 실측은 총2 worker 9.442 requests/min, 총4 worker 14.656 requests/min, 최대 reserved 9.426GiB/worker다. 새 Describe의 D8에서 총2와 총4 worker를 같은 고정 요청으로 비교하는 것을 우선한다. 이미 측정한 Locate and describe 전체 처리량 탐색을 반복하지 않는다. 새 비교 비용이 절약보다 크면 기존 수치와 새 peak 확인을 재사용하고 이유를 남긴다.

동시 worker peak 합계+worker당2GiB+외부 점유가 실제 장치 용량 안에 있어야 한다. allocated뿐 아니라 reserved·장치 점유·긴 출력 peak를 확인한다. 기존 실행기의 예약 합산 결함을 먼저 수정한다. 처리량, p95 지연, token 정합성, OOM, CPU/RAM/I/O 경합으로 구성하고 평가 점수로 고르지 않는다.

기존 처리량을 적용한 본생성 추정은 256요청 약17–27분, 768요청 약52–81분이다. 적재·D8 검사·cap 재시도·의미 검토는 추가 비용이며 시간 상한이 아니다. 처음 완료한 평가 묶음의 검토 시간도 실측해 남은 비용을 갱신한다.

신규 요청은 환자·영역·형식·protocol의 고유 ID와 worker별 파일에 저장한다. 완료 행 digest·실행 코드·입력·모델 연결을 확인한 뒤에만 재사용한다. 원자적 claim과 누락/중복 검사를 둔다. supervisor가 완료·오류를 관리하고 구현 모델은 실제 PID의 experiment_wait 또는 동등한 background 완료 대기를 사용한다. 기존 claim을 지우거나 같은 결과 파일에 임의의 복수 writer를 붙이지 않는다.

# Evaluation (성공/실패 기준 포함)

## 평가 단위와 지표

독립 단위는 환자다. 8영역을 독립 환자8명처럼 세지 않는다.

1. **영역 간 명시적 충돌 환자 비율:** 같은 현재 소견에 대해 같은 해부학 범위를 포함하는 확정 양성과 명확한 부정이 함께 있는 환자 수/N이다. 좌우 폐와 해당 측 upper/mid/lower 영역의 관계를 사용하되 생성문이 실제로 기술한 위치를 우선한다. 서로 다른 zone 사이에 무조건 포함 관계를 가정하지 않는다.
2. **reference 지지 추가 회복:** C-G 또는 같은 형식의 좌우 폐2영역에 없고 세부6영역에 있는 현재 확정 소견이다. 소견 종류·명시 위치·속성을 각각 평가하고 환자 수와 환자 평균 strict recall을 보고한다. 양성 원문만 존재하고 같은 묶음에 부정도 있으면 `회복되었으나 충돌`로 분리한다.
3. **오류 비용:** reference가 명시적으로 반박하는 주장, 미지원/판단불가 주장, 근거 없는 시간·원인 표현, 위치 누락·오류를 나눈다. 미표기 소견을 임상 FP로 만들지 않는다.
4. **비용:** 동일2영역 및 동일8영역의 요청 수·출력 token·생성 시간·전체 wall-clock을 비교한다. C-G와 8영역의 단순 속도 차이를 방법 효율로 해석하지 않는다.

`clear lungs/no focal opacity`와 명시적 focal opacity는 범위가 겹칠 때 충돌 후보가 된다. `No significant findings`, `No acute findings`, `No other findings`는 중요도·급성·other 범위 근거 없이 자동 모순으로 처리하지 않는다. 질문이 lower zone이더라도 출력이 전체 폐를 명시하면 그 범위를 보존하고, 위치를 명시하지 않으면 질문 범위와 전역 해석 두 민감도를 보고한다. lobe와 radiographic zone은 자동 동치로 취급하지 않는다.

판정을 바꾸는 모든 회복·충돌 사례와 hash로 고정한 나머지12명의 음성/판단불가 사례를 원문으로 재점검한다. 조건명 제거는 독립 평가자 눈가림이 아니다. 전문의 검증으로 표현하지 않는다.

환자 paired bootstrap 10,000회·seed95017로 차이의95% CI를 보고한다. 확정 위치가 있는 표현만 인정하는 보수적 분석, 모호 대응 전부 제외, 시간 속성 불일치를 strict에서 제외하는 분석을 모두 제시한다. 유리한 분석만 선택하지 않는다.

## 종료 판단

**단순 대안 우선:** Describe 또는 넓은2영역이 비교 대상8영역의 reference 지지 회복을 환자 기준으로 거의 보존하고 충돌을 줄이면 이를 우선한다. 운영상 보존 기준은 잃는 회복 환자가 전체96명 중1명 이하, 충돌 감소가 최소5명이다. 이는 임상 허용 한도가 아니라 추가 방법 투자 전에 확인할 탐색 기준이다. 더 적은 요청으로 같은 관찰을 얻으면 비용 이점도 보존한다.

**최소 방법 pilot 검토:** 공식 Describe의 세부 영역에서도 C-G와 해당 Describe2영역이 놓친 명확한 현재 소견 회복이 최소3명에 남고, 명확한 영역 충돌도 최소5명에 남으며, 모호 표현 제외와 한 환자 제거 후 반복 관찰이 유지되어야 한다. 회복과 충돌 환자가 반드시 같을 필요는 없지만 각 사례를 분리한다. 이 기준은 중요 소견의 다환자 반복성과 오류 비용을 동시에 요구하기 위한 것이며 통계적 확증이 아니다. 충족 시 후속은 `영역별 회복을 보존하면서 넓은 부정의 적용 범위를 일치시키는 최소 개입` 하나로 좁히고, 단순 텍스트 충돌 처리·C-G를 대조로 요구한다. 이번에는 그 방법을 구현하지 않는다.

**음성:** 정확한 추가 회복이 없거나 소수 모호 사례만 남으면 현재 CURE 폐 영역 회복 후보를 종료한다. Describe만으로 해결되면 좌표 요구가 포함된 인터페이스의 문제로 범위를 좁힌다. 위치 학습 일반 가설이나 다른 의료 판독 과제는 기각하지 않는다.

**불확정:** 초기32명에서는 사전 분기에 따라 E96까지 확대할 수 있다. E96 이후에도 의미 범위·reference 불완전성·소수 사건이 판단을 좌우하면 투자 보류다. 같은 데이터의 새 prompt·다른 영역·추가 모델로 연장하지 않는다. 재개에는 구체적인 다른 근거가 필요하다.

- E96는 반복 개발 자료이며 CURE 학습·선택 노출이 완전히 배제되지 않았다.
