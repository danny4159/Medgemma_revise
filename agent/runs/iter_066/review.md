# Problems / Concerns

현재 수치와 E12 종료 판단을 무효화할 blocker는 발견하지 못했다. 다만 전체 코드 재사용은 승인하지 않는다.

첫째, 평가기는 최종 비EOS를 명시적으로 오답 처리하지 않는다. 이번에는 해당 parser-valid 응답이 없어 수치가 같지만 후속 입력에서는 달라질 수 있다.

둘째, prior의 원본 labels hash 확인만으로 prior 예측값 자체가 고정됐음을 보장하지 못한다. 평가 시 D 정답에서 prior를 재구성하거나 gate에 봉인된 prior와 대조해야 한다. labels·prior가 변경된 상태의 실제 report 진입점 검사도 빠졌다.

셋째, torn-tail 재개 7건과 정상 두 worker 실행은 확인됐지만 저장 직후 종료·복수 worker 강제 중단 재개는 검사하지 않았다. 다른 worker가 append하는 동안 전체 결과를 다시 읽는 경로도 검증 대상이다.

넷째, 보고서의 native 비교는 실제로 동일 hidden state에 native dtype의 lm_head를 적용한 대조다. 공식 model forward logits와 직접 대조했다는 뜻으로 쓰면 안 된다. 현재 causal 계산·설정·독립 token 검사는 batch1 결과를 뒷받침하지만 검증 범위는 구분해야 한다.

자원 운영은 허용 GPU 0/1에 worker를 하나씩 배정했고, 여유가 큰 GPU1부터 사용했다. D/E12 wall-clock은 각각 187.46/430.64초다. D 최대 reserved 10.88 GiB에 worker당 2 GiB 여유를 더하면 GPU당 두 worker는 용량을 넘으므로 현재 배치는 타당하다. 다만 D 기반 사전 시간 예측과 batch별 처리량 기록은 부족하다. 이는 정확도 결과의 무효 사유가 아니다.

# Interpretation

E12 확대 조건 첫째는 L_J≥0.65를 충족하지 못했다. 둘째는 위치 prior 초과와 null 대비 3 pp를 충족하지 못했다. 따라서 E48을 실행하지 않은 것은 자원 회피나 미완료가 아니라 사전 단계 규칙에 따른 종료다.

J scoring의 회복은 크지만, 거의 항상 ABSENT를 선택한 결과다. J sensitivity는 5/47, specificity는 25/25다. 모든 응답을 두 후보 중 하나로 선택하게 만든 효과와 영상별 판별 개선을 구분해야 한다. 순수 parser 효과나 내부 인식 회복으로 확정할 수 없다.

F scoring 역시 F 생성보다 낮다. 그러므로 이번 결과는 scoring이 일반적으로 더 좋은 답변 방식이라는 근거가 아니다. 현재 후보·평균 likelihood 조건에서 J의 극단적인 생성 저하가 완화됐다는 관찰이다.

12 case의 확대 기준 미달은 충분한 표본의 일반적 음성 확증이 아니다. 원 계획에 따라 현재 경로를 보류하며 MRI 전체·경량 적응·다른 모델을 기각하지 않는다. 기존 `mri-explicit-target-context-effect`는 별도 과제의 관찰이므로 상태를 변경하지 않는다.

# Strategy Check / 연구 방향 판단

- **실행 유효성:** 고정 입력의 생성/scoring 비교와 prior/null 대조는 해석 가능하다. 새 학습이나 독립 확인은 없다.
- **성능 개선:** J 생성 대비 회복은 확인됐지만 F와 위치 prior 이후의 이득은 확보되지 않았다.
- **가설 지지:** 생성 인터페이스에 따라 성능 해석이 크게 달라진다는 H1의 제한적 근거는 있다. 충분한 영상별 신호나 공동 입력의 추가 가치를 뒷받침하지는 못한다.
- **신규 기여 가능성:** 기존 likelihood baseline의 적용이며 새로운 방법이 아니다. 현재 관찰만으로 selector·형식 loss 투자를 재개할 근거는 부족하다.

해결된 질문은 '기존 scoring이 공동 입력의 큰 생성 오류를 실용적 영상 신호로 회복하는가'의 이번 조건이다. 점수는 회복했지만 투자 기준은 충족하지 못했다. 남은 설명은 후보 prior·시각적 충분성·기본 인식이며, 이를 내부 선택·결합 실패로 묶지 않는다.

현재 경로의 추가 보정, 같은 조건의 추가 진단, 다른 검증 조건으로의 이동을 비교하면 마지막 선택을 권고한다. 같은 자료의 문자열·prompt 탐색은 개발 집단 의존성을 더 키우며 현재 결정을 바꿀 근거가 약하다. 다음에는 접근 가능한 새 데이터라는 이유가 아니라 정답으로 관측의 역할을 구분할 수 있다는 이유로 비교를 선택해야 한다.

타 계열 scoring은 이번 계획에서 보류한 것이 타당하다. iter_062·064·065의 Qwen 비교를 유지하되, 이번 결과를 타 계열의 공통 실패로 일반화하지 않는다. 여러 기본 모델의 실패와 기존 해결책의 부족함은 별개다.

비용 측면에서는 최종 D 기술 검사 883초가 D/E12 본 scoring 합계 618초보다 길었고, 초기 기술 실행의 재작업도 있었다. 이는 이번 실행 구간의 비교이며 track 전체 비용 비율은 아니다. 이미 확인한 입력·계산을 다음 반복마다 전면 재검사하거나 미사용 실행기를 정비하는 데 별도 반복을 쓰지 않는다.

# Recommended Next Experiment

현재 frozen MedGemma의 mask 기반 공동 입력·답변 보정 투자를 보류한다. 같은 MRI 근거 사용 질문 안에서 기존 annotation으로 단일 관측의 충분성과 복수 관측의 필요성을 구분할 수 있는 조건을 한정 검토한다. 성립하면 강한 단순 대안과 최소 대조 하나로 실제 출력을 확인하고, 성립하지 않으면 그 세부 경로를 종료한다. 이 판단을 현재 E48의 자동 확대나 추가 학습으로 대체하지 않는다.

논문 추천은 보류한다. 점수 회복은 기존 baseline의 제한적 효과이며, 이번 결과는 해당 방법 방향을 더 투자할 긍정적 기준을 충족하지 못했다.
