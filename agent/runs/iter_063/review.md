GPU 0/1에 각각 Qwen/MedGemma를 배치했고 E10 wall-clock은 392.05초, peak GPU 점유는 16,397/9,161 MiB였다. D 실측을 근거로 예상 비용을 남겼으며 batch2 검증 비용과 작은 잔여 요청량을 이유로 batch1을 유지했다. 이번 규모에서 허용 가능한 판단이다.

# Problems / Concerns

현재 수치를 무효화하는 blocking issue는 발견하지 않았다. 그러나 보고서의 검증 범위는 일부 과장돼 있다.

- `repair_tail`은 첫 손상 줄 이후를 모두 제거할 수 있다. 중간 손상 거부 시험은 별도 `read_jsonl`에만 적용됐다.
- 실제 동시 worker 경합과 실행 중 강제 중단은 시험하지 않았다. 사본 절단·비용 행 삭제·순차 재시작을 검증했다.
- 실제 모델 파일 hash를 재확인하는 대신 기존 fetch 기록 또는 blob 이름을 사용한다.
- MedGemma 원문 verify에는 출력 hash seal이 없다. 평가기의 기존 protocol 검증 연결도 불완전하다.
- 계획한 strict 보조 보고가 빠졌고, lenient 분석을 이번 사전 정의 분석이라고 표현한 것은 부정확하다.

따라서 전체 코드 재사용은 승인하지 않는다. 현재 재계산과 자료 연결에 유용한 모듈은 제한적으로 승인한다.

# Interpretation

소견 삭제는 정답률뿐 아니라 답변 형식과 거절 행동도 바꿨다. L을 순수한 시각 인식 손실로, G를 영상 내용 인식의 순수 효과로 해석할 수 없다. 반대로 형식 문제가 있다는 이유로 관찰된 모든 변화가 형식만으로 설명됐다고 확정할 수도 없다.

R_J가 집단 최빈 class 비율 0.30보다 낮다는 것은 낮은 절대 성능의 기술적 근거다. 영상이 정보를 전혀 주지 않았다는 증명은 아니다. 삭제문 영상 충분성이 확인되지 않았으므로 모델 인식 부족과 입력 부족은 미분리다. 영상 수나 공동 답변만으로 결합 능력을 주장하지 않는다.

새로운 모델 한계는 등록하지 않는다. 이번 결과는 과제 적합성과 정보 삭제의 제한적 관찰이며 observed 모델 결함으로 자동 전환할 근거가 부족하다.

# Strategy Check / 연구 방향 판단

**실행 유효성:** 고정 사례·정답·영상·순열을 유지한 정보 삭제 대조가 완료됐다. **성능 개선:** 방법 실험이 아니며 개선을 입증하지 않았다. **가설 지지:** 소견 정보가 출력 행동과 정답률에 큰 영향을 준다는 설명은 지지된다. 텍스트가 가렸던 충분한 영상 신호라는 해석은 미확정이다. **신규 기여:** text-only ablation 자체의 신규성이나 기존 해결책의 부족함은 입증하지 않았다.

iter_061~063에서 타 계열 비교까지 수행했지만 두 모델의 공통 인식 결함을 확인한 것은 아니다. 해결된 질문은 현재 원문 점수를 영상 기여로 해석할 수 없다는 점이다. 남은 핵심 설명은 관측 충분성과 기본 인식이다. 현재 자료의 prompt·모델 확대보다 정답과 관측의 연결을 확인하는 한정 대조가 판단 가치가 높다.

이번에는 신규 모델 확보 없이 본생성 약 6.5분으로 대조를 완료했다. 구현 세션은 약 15.2분이지만 준비·검증·GPU 대기의 중첩을 분리한 기록이 없어 지배 비용이나 절감률을 정량 주장하지 않는다. 진단 반복 수만으로 track을 기각하지 않되, 같은 QA의 반복 확대는 중단한다.

논문 추천은 보류한다. 이번 결과는 방법 또는 영상 근거 사용 방향의 긍정적 유망성을 충분히 확인하지 못했다.

# Recommended Next Experiment

현재 key-image QA의 선택·결합 방법 투자를 보류한다. 다음 계획은 기존 MRI 자산에서 정답과 관측 충분성을 연결할 수 있는 최소 대조 하나를 선택한다. 연결이 성립하면 인식과 추가 관측 효과를 구분하는 출력까지 진행하고, 성립하지 않으면 그 자료 경로를 종료한다. 새로운 데이터 확보나 같은 2×2 반복 자체를 목표로 삼지 않는다. 원 결과와 사전 양성 판정은 보존하며, method pilot은 중요한 잔여 문제의 유효한 관찰이 확보된 뒤 별도로 판단한다.
