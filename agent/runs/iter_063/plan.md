# Strategy Check / 연구 방향 판단

상위 질문은 여러 관측의 필요한 근거를 선택하고 결합하는 능력이다. 현재 관찰은 인식·선택·결합의 실패를 아직 분리하지 못했다. 이번에는 그 전제인 **질문의 소견 서술이 영상 추가 효과를 가리는가**만 검사한다.

- 확인된 사실: 두 모델의 원문 QA 추가 영상 효과가 불확정이다. 타 계열 비교는 이미 수행됐다.
- 남은 설명: 텍스트 정보의 영향, 배포 영상의 충분성, 기본 인식이다.

## 1. 자료 연결과 삭제 규칙 잠금

대상은 QA 587, 658, 721, 740, 759, 782, 831, 1120, 1224, 1297이다. E21에서 BraTS2021-GLI 2개, BraTS2023-MEN 3개, BraTS2023-MET 2개, ISLES2022 3개의 동일 질문 틀 전부다. 선택 이유는 구조적 삭제 가능성이며 모델 정오답이 아니다.

기존 D의 QA 694와 1253에 같은 삭제 규칙을 적용한다. 모델별 T/J×두 순서 8건, 총 16건이다. 원 prompt 대비 변경이 삭제 부분뿐인지, T에 영상 token이 없는지, J의 영상 tensor와 순서가 그대로인지 확인한다. D는 평가 표본에 합치지 않는다.

greedy, 기존 모델별 generation_config, cap512 및 비EOS cap 도달 시 cap2048 한 번 재시도, 기존 parse_v2와 strict 보조 보고를 유지한다. 최종 attempt를 점수화하고 재시도 비용을 모두 기록한다. 모델 오답·invalid 응답은 관찰이며 parser를 유리하게 바꾸지 않는다.

## 3. 고정 가능성 탐색

각 모델에서 삭제문 T/J×10 cluster×두 순서=40건, 총 80건을 생성한다. 원문 T/J 80응답은 iter_061/062의 원 protocol·선택·출력 검증 후 재사용한다. 같은 조건을 새로 생성하지 않는다.

## 4. 확대와 독립 확인

이번 본실행은 구조적 조건을 만족하는 기존 10개 전부다. 확증용 power를 충족하는 표본이라고 부르지 않는다. 추가 seed·E64·reserve·학습은 실행하지 않는다. 후속 연구는 이번 효과와 영상 충분성 근거를 함께 리뷰한 별도 계획에서만 선택한다.

## 자원·비용·재개

실행 직전 nvidia-smi로 허용 GPU의 UUID·논리 대응·여유를 확인한다. 기본은 두 GPU에 모델 하나씩 배정한다. Qwen 직전 peak는 약16,987~17,025 MiB여서 같은 GPU의 Qwen 두 복제본은 사용하지 않는다. MedGemma도 현재 입력 peak를 확인하며 다른 프로세스 점유와 worker당 최소2GiB 여유를 포함한다.

D에서 batch1 대비 가능한 batch2를 같은 입력·생성 조건으로 짧게 비교한다. 2GiB 여유가 없거나 예상 절약보다 구현·측정 비용이 크면 수치와 이유를 기록하고 batch1을 유지한다. batch2 사용 시 padding·출력 대응·결정 정합성 검사를 통과해야 한다. 남은 독립 요청이 충분하고 메모리가 허용되면 MedGemma 복수 worker도 후보이나 유효 처리량이 늘어날 때만 적용한다.

기존 Qwen 232건/468.17초를 단순 환산하면 40건은 약81초지만 이는 두 GPU 구성의 과거 혼합 요청 환산이며 이번 예측값이 아니다. D의 모델별 실측 요청 시간·token 길이·loading으로 40건씩의 예상 wall-clock을 본실행 전에 기록한다. 임의 시간 상한은 두지 않는다.

요청별 고유 ID·worker별 출력·원자적 완료 상태를 사용한다. claim 획득 후 디스크의 최신 완료 상태를 다시 확인해 종료 worker의 요청을 중복 생성하지 않게 한다. 모든 원시 attempt를 보존하고 평가에서는 JSONL을 엄격하게 읽는다. 비용은 입력 읽기부터 답변 저장 완료까지 경계를 기록하고 답변·attempt·비용의 대응을 봉인한다. 누락 비용은 추정으로 채우지 않는다. 모델 간 비용 우위 비율은 이번 목적이 아니며 과거 서로 다른 경계의 비용을 혼합하지 않는다.

# Evaluation (성공/실패 기준 포함)

각 cluster에서 두 순서의 정답률을 평균한 뒤 cluster 평균을 계산한다. O/R은 원문/삭제문, T/J는 텍스트/공동 영상이다.

- 텍스트 삭제 효과 L = A(O,T) − A(R,T).
- 삭제문 영상 이득 G = A(R,J) − A(R,T).
- 정보 상호작용 I = G − [A(O,J) − A(O,T)].

각 모델에서 네 정확도, L/G/I, cluster별 paired 변화, 두 순서 각각의 결과, invalid·cap 비율을 보고한다. seed63, 10,000회 cluster paired bootstrap의 95% CI를 기술한다. source/class별 수치는 기술통계이며 작은 집단으로 새로운 결론을 만들지 않는다. 두 모델 차이는 범위 확인용 보조 결과다.

**탐색 양성:** 한 모델에서 L≥0.15, G≥0.15, I≥0.10이고 두 순서 각각에서 L과 G가 모두 양수이면 텍스트 정보에 가려진 영상 신호의 후보로 둔다. 10개에서 몇 응답 변화만으로 투자하지 않도록 정한 실용적 탐색 문턱이며 통계적 확증이 아니다. CI와 실제 사례 수를 반드시 병기한다. 해당 모델의 후속 관측 충분성 대조 가치를 검토하되 method gate 통과로 간주하지 않는다.

**텍스트 의존만 관찰:** L 기준은 충족하나 G 기준은 미달이면 소견 서술의 영향만 지지한다. 영상 충분성·인식은 미판정이고 현재 자료의 선택·결합 방법 투자를 종료한다.

**음성:** 두 모델에서 L이 작거나 방향이 일관되지 않으면 소견 서술이 주된 설명이라는 후보를 약화한다. CI 상한이 크면 효과 부재로 표현하지 않는다. 삭제 후 G도 작으면 현재 key-image 과제의 추가 방법 투자를 종료·보류한다.

**불확정:** 위 기준 미충족이나 순서 민감성·넓은 CI가 남으면 새 표본·prompt를 자동 추가하지 않는다. 현재 자료의 추가 투자를 보류하고, 재개 조건은 관측 충분성의 새로운 독립 근거로 한정한다. 두 모델 중 유리한 결과만 주결론으로 보고하지 않는다.

기술 유효성 성공과 가설 지지는 별도 판정한다. 삭제문 영상 정확도가 높아도 모든 영상이 필요하거나 정답 근거를 정확히 선택했다는 뜻은 아니다.

# Risks / Checks

- 삭제는 정답 label을 바꾸지 않지만 정보 충분성을 낮출 수 있다. 오답을 인식 결함으로 이름 붙이지 않는다.
- 소견 삭제에는 길이·서술 맥락 변화도 포함된다. 내부 attention이나 순수 의미 원인을 확정하지 않는다.
- BraTS/ISLES source와 class가 얽혀 있고 3장/4장 차이도 있다. 영상 이득을 병변 정보만의 효과로 해석하지 않는다.
- 소견 문단을 지운 뒤 sequence 이름도 일부 사라진다. 별도 metadata를 추가해 조건을 다시 바꾸지 않고 전체 삭제 개입의 한계로 남긴다.
- 반복 사용된 개발 사례이며 모델 학습 노출·환자 독립성의 미확인은 유지한다.
- 사용하지 않는 runner 전체를 고치거나 대규모 감사로 확대하지 않는다. 원 source·코드·결과는 보존한다.
