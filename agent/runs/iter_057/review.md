# Problems / Concerns

현재 수치를 무효화하는 문제는 발견하지 않았다. 다만 분석기의 자동 검증 범위는 보고서보다 좁다. protocol 파일 digest 대조가 protocol 내부 요청·코드 연결 검사까지 대신하지 않는다. cases.json/case_order.json도 저장 hash 외에 GT와 의미상 연결하지 않으며 GT 중복 key는 dict 구성에서 덮일 수 있다. 계획의 GT 변조 거부 검사는 실제 23개 검사에 포함되지 않았다. 이번에는 직접 확인과 기존 검증으로 현재 결론을 지지하지만 새 입력 재사용 전에 보완해야 한다.

기존 GPU runner·sanity·breakdown 결함은 그대로다. 현재 사용하지 않은 경로 때문에 이번 CPU 분석을 실패로 판정하지 않지만 전체 스냅샷을 승인하지 않는다.

희소 class를 포함한 고정 지원 집합에서 class가 사라진 bootstrap replicate를 제외했다. 이는 계획과 일치하지만 CI의 조건부 성격과 정밀도 한계를 유지해야 한다. D 규칙의 학습 표본 불확실성도 이 CI에 포함하지 않았다.

# Interpretation

동일 위치 안에서 양성·음성을 구별하는 연관이 남는다. 따라서 위치 index만으로 모든 결과를 설명하는 해석은 약화된다. 반면 위치 규칙 대비 전체 BA의 추가 이득은 아직 불확정이다. 서로 다른 estimand이므로 두 결과는 모순되지 않는다.

위치별 상수 규칙의 표준화 BA는 정의상 0.5다. 이를 별도의 독립 발견으로 세지 않는다. 위치 통제 후에도 해부학적 세부 위치, 영상 특성, 병변 부담 등 confound는 남는다. annotation 없는 구간의 FP를 정상 환자의 임상 오진으로 해석하지 않는다.

새 MRI 한계를 validated로 등록하거나 기존 SPIDER 한계를 승격하지 않는다. 현재 잔여 오류만으로 새 방법의 필요성까지 확정하지 않는다.

# Strategy Check / 연구 방향 판단

**실행 유효성:** 기존 D97/E766 고유 출력에 대한 고정 재분석을 완료했고 주요 수치와 CI를 독립 검증했다.

**성능 개선:** 새로운 모델·방법의 개선 실험은 없다. U8와 DENSE의 차이는 여전히 불확정이다.

**가설 지지:** 위치 index-only 설명을 제한하는 신호와 여러 case의 잔여 오류를 확인했다. 병변 자체의 인과적 사용은 미검증이다.

**신규 기여 가능성:** 전문 segmentation+OR로 풀 수 있는 과제다. 그 대안 대비 정확도·비용·언어 조건의 가치가 확인되지 않아 contribution은 미확정이다.

**관찰의 유지와 다음 결정:** iter_056의 저비용 U8 baseline과 복잡한 표집 투자 보류를 유지한다. 위치 신호 분석은 이번으로 종료한다. 현재 방법 개선보다 전문 모델 최소 대조가 남은 오류의 해결 가능성과 MedGemma 적응 필요성을 더 직접적으로 구분한다. 새 자료·모델로 즉시 이동하는 것보다 같은 질문의 비교를 우선한다.

이번 작업의 주된 비용은 분석 구현·검증이었다. 보고된 분석 CPU 시간은 약0.47초, 구현 세션은 약155.5초다. 새 GPU 요청은 필요하지 않았고 이는 자원 회피가 아니다. 다음 비교에서는 실제 GPU 입력·처리량·전체 비용을 측정해야 한다.

# Recommended Next Experiment

전문 segmentation+OR 대조의 공식 실행 경로와 checkpoint 학습 중복을 확인한다. FLAIR-only와 다중 sequence 접근은 공정성 차이를 명시하고 결과를 섞지 않는다. 중복이 확인된 checkpoint 결과는 독립 일반화 평가로 쓰지 않는다.
