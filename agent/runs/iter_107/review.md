# 요약

- **판정:** 유효한 음성 진단이다. 현재 자연 다중 영역 부분 누락 개입의 추가 투자는 보류한다.
- **핵심 근거:** 두 판독자 주석이 일치하는 핵심 10명에서 CURE는 두 근거를 모두 보존했다. 부분 누락은 0명이다.
- **의미·한계:** 정상 지원 경로에서도 부분 누락이 남는다는 이번 가설은 지지되지 않았다. 반복 개발 자료이며 자유 판독·독립 일반화는 검증하지 않았다.
- **다음:** 비핵심 사례 재채점이나 추가 학습을 자동 발주하지 않는다. 보류 범위와 재개 조건을 보고하고 사용자 승인을 기다린다.

## 알림 요약

- 결과: 흉부 X-ray의 자연 다중 영역 소견 47개를 평가했다. 핵심 10명에서 CURE는 두 위치를 모두 보존했고, MedGrounder는 두 운영점 모두 6명 보존·4명 판정 모호였다.
- 의미: 공식 단일 phrase에서도 같은 부분 누락이 남는다는 예상은 지지되지 않았다. iter_106 복합 입력 손실의 원인과 임상 판독 정확성은 여전히 미확정이다.
- 후속: 개입 대상이 확인되지 않아 현재 후보 투자를 보류할 것을 권고한다. 사용자 승인 없이 다음 반복을 시작하지 않는다.
- 대안: 비핵심 집단을 후속 대상으로 삼을 수 있으나, 주석 분할·대체 주석 부재 때문에 현재는 정보 가치가 낮다. 명확한 정답과 잔여 문제의 새 근거가 있을 때만 재검토한다.

# Assessment

`valid_experiment=true`, `approach_status=abandon`이다. 실행 실패가 아니라 계획의 음성 분기에 따른 현재 설계 투자 보류다. Claude 구현은 `engineer_backend.json`과 `claude_meta.json`에서 확인했으며 실제 모델 기록은 claude-sonnet-5-5, 설정은 sonnet/medium이다.

리뷰 대상은 `e2a66795876215937e1eda5b2c6e70d30474298d`다. commit.json의 22개 경로 모두 작업 파일과 해당 SHA 내용이 일치했고 unpreserved_paths는 없었다. 전체 snapshot의 재사용 승인은 별개로 보류한다.

# Key Findings

1. **원시 결과 재계산:** M47 원시 출력 47건의 고유 연결, 공식 문장 prompt, 최종 EOS를 확인했다. production 함수를 사용하지 않는 좌표 파싱·정확한 합집합 면적 계산으로 coverage와 union IoU를 재계산했다. 저장 수치와 최대 차이는 7.78e-16이었다.
2. **주판정:** 전체 47개에서 핵심 집단 포함·제외를 독립 계산해 10개를 확인했다. CURE는 both_retained 10, partial_omission 0이었다. MedGrounder 0.8/0.4는 각각 both_retained 6, ambiguous 4, partial_omission 0이었다. 모호함을 누락으로 바꾸지 않았다.
3. **기술통계:** 36명 환자 평균 공식 union IoU는 CURE 0.535074, MG0.8 0.416245, MG0.4 0.409331이었다. CURE−MG0.8은 0.118829다. 별도 환자 bootstrap 10,000회에서 95% 구간 [0.045643, 0.191307]로 보고서의 [약 0.045, 0.192]와 일관됐다. bootstrap 난수 소비 순서가 달라 끝자리 차이가 있다.
4. **실행 무결성:** M47 completion 연결 hash와 잠긴 실행 소스 digest의 불일치는 없었다. 두 worker는 모두 exit 0이며 wall-clock은 352.33초다. CPU fixture 42/42, 기술 검사 v2 19/19와 재개·변조 거부 기록을 확인했다. 고정 첫 4개의 overlay도 확인했다.
5. **자원:** 두 GPU에 각 1 worker를 사용했다. 보고된 peak reserved는 worker당 약 9.43 GiB이며 추가 worker admission 거부를 처리량 개선 증거로 사용하지 않았다. 저장된 실제 생성은 기술 재개 검사를 포함해 총 55건이다.

# Problems / Concerns

현재 음성 결론을 무효화할 blocker는 없다. 다만 다음 기록·재사용 문제는 구분해야 한다.

- `nr107_eval.py`는 실제 도구 로그에서 M47 launch 이후 작성됐다. 따라서 전체 평가 코드와 모든 분기가 생성 전에 잠겼다는 설명은 부정확하다. 핵심 사건 정의는 사전 계획과 nr107_spec.py에 있었고 현재 N=0 판정은 그대로 재현되므로 주결론은 유지한다.
- persist>=3 및 resolved*2>N은 원 계획에 없던 구체적인 분기다. 현재 결과에는 영향이 없지만 다른 결과의 승인된 기준으로 계승하면 안 된다.
- verifier의 비핵심 집단 누락 검사 주석과 실제 구현이 다르다. 이번 리뷰가 전체 집단을 독립 재계산해 현재 누락 우려는 해소했지만 모듈 자체의 검증 범위를 과장해서는 안 된다.
- verifier의 초기 래스터 실패는 보존됐고 수정 후 통과했다. 이번 정확한 면적 재계산으로 현재 수치가 근사 오차에 의해 뒤집힌 결과는 아님을 확인했다.
- 개발 V96 재사용, CURE 학습 노출 미확인, 시스템별 학습·양자화 차이는 남는다. 주석 밖 면적은 임상 FP가 아니며, box 수는 병변 수 정답이 아니다.

# Interpretation

공개 정답이 뒷받침하는 결론은 두 판독자가 일치한 공간 영역에 대한 coverage 보존이다. CURE가 이 조건에서 근거 두 개를 보존했다는 관찰은 받아들여야 한다. 모든 다중 영역 소견의 완전성이나 자유 판독 정확성을 증명하지 않는다.

iter_106과 이번 집단·입력이 다르므로 두 결과의 차이를 입력 형식의 인과 효과로 확정할 수 없다. 다만 미지원 복합 phrase의 손실을 정상 지원 단일 phrase의 일반 결함으로 확대할 근거는 약해졌다. 이전 limitation은 원 범위로 유지하며 이번 결과로 동일 id를 기각하거나 validated로 승격하지 않는다.

# Strategy Check / 연구 방향 판단

- **시험 설정:** 사전 음성 분기에 도달했다. 추가 prompt·threshold·seed·학습 투자는 보류한다.
- **연구 관찰:** 부분 누락 0/10과 두 근거 보존을 새로 배웠다. 비핵심 주석 차이, 학습 노출, 판독으로의 연결은 줄지 않은 불확실성이다.
- **연구 질문:** 강한 기존 방법 이후에도 남는 중요한 부분 누락 조건은 이번에 확보되지 않았다. 현재 질문 전체의 보편적 기각은 아니지만 최소 개입의 근거도 아니다.
- **실행 유효성:** 실제 생성·정답 연결·독립 계산이 성립한다.
- **성능 개선:** 시스템 간 union IoU 차이는 있으나 새 방법의 개선 실험이 아니다.
- **가설 지지:** 정상 지원 단일 phrase에 남는 주석 일치 부분 누락 가설은 현재 핵심 집단에서 지지되지 않았다.
- **신규 기여 가능성:** 미확인이다. 기존 CURE의 성공을 받아들이며 총점 차이를 contribution으로 삼지 않는다.

후속 선택은 두 가지 안에서 비교했다. 현재 후보를 보류하면 검증된 반대 근거를 수용하고 추가 구현 비용을 막을 수 있다. 비핵심 6건을 다시 조사하는 선택은 주석 분할·대체 주석 부재와 기본 위치 오차가 얽혀 있어, 현재 근거만으로 투자 결정을 바꿀 비교가 성립하지 않는다. 따라서 **현재 후보 보류**를 선택한다. 지원 공동 경로의 일회성 후보 점검도 새 지원·동일 정보 근거 없이 반복하지 않는다.

비용은 M47 wall 352.33초와 구현 세션 약 19.5분이 기록돼 있다. 구현·감사·대기별 시간은 분리 측정되지 않아 특정 비용의 지배 비율은 산출하지 않는다. 실행 복구만 완료한 반복은 아니며 실제 음성 관찰로 투자 범위를 좁혔다.

# Recommended Next Experiment

현재 근거에서는 추가 실험을 권고하지 않는다. 재개에는 공개 정답으로 분할 차이와 위치 오류를 구분할 조건, 강한 대안 이후의 중요한 잔여 문제, 양성·음성에 따라 투자가 달라지는 최소 비교가 필요하다. 같은 문장 재판정·범용 평가기 보수·새 모델 설치만으로 반복을 만들지 않는다.

연구 목표와 기존 자산은 유지한다. --confirm-each-iter에 따라 이번 결과·보류 이유·대안을 보고한 뒤 승인 또는 피드백을 기다린다. 추가 전문가 가용성을 다시 묻지 않는다.

논문 추천은 보류한다. 이번 결과는 현재 실패 조건에 대한 투자 근거를 약화했으며, 별도 방법 탐구의 유망성을 확인한 결과가 아니다.
