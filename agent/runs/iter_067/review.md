# Problems / Concerns

현재 제한된 정확도 및 확대 중단 결론을 무효화할 blocker는 발견하지 않았다. 다만 다음 문제 때문에 전체 스냅샷 재사용은 승인하지 않는다.

1. **기하 gate:** sequence 중심 비교가 물리좌표가 아닌 index×spacing이다. origin·direction 차이를 반영하지 않아 일반적인 정합성 검사로 사용할 수 없다. 환자 35의 제외 사유를 물리적 158 mm 불일치로 확정해서는 안 된다.
2. **재개 검사:** 실제 저장 직후 강제 종료나 동시 append 검사가 아니다. 정상 종료와 순차 worker 재개에서 8/8 보존을 확인한 범위로 보고해야 한다.
3. **provenance:** 평가 코드·D 선택 및 prior·실행 설정·출력 seal 연결이 부족하다. 코드 수정으로 기존 protocol이 실패하는 것 자체는 정상 보호 동작이며 결함이 아니다.
4. **비용:** R metadata 누락, LF 합산 부재, render·저장 완료 경계 누락이 있다. 현재 timing은 운영 참고값이다.
5. **공식 경로 대조:** forward/generate는 같은 vision patch 아래에서 일치했다. chunk8과 큰 chunk의 후보 확률 오차는 별도로 충분히 검증되지 않았다. 한 요청에서 argmax가 같았다는 결과를 전 조건의 완전한 동등성으로 확대하지 않는다.
6. **null 평가 범위:** donor 없는 1행을 제외한 null과 전체 81행 BA를 직접 비교한다. 이번 중단 결정에는 영향이 없지만 향후 gate에는 수정이 필요하다.

두 GPU에 모델 하나씩 배정한 실행과 실제 완료를 확인했다. 최대 stack 메모리 때문에 GPU당 두 worker를 배제한 설명은 이해할 수 있지만, batch 확대 실측과 사전 시간 예측은 부족하다. 이것만으로 현재 정확도를 기각하지 않는다.

# Interpretation

'사전 기본 신호 기준 미달'은 지지된다. '영상 신호가 없다'는 더 강한 표현은 지지되지 않는다. MedGemma는 후보 밖 서두 token을 선호하는 경우가 있었고 Qwen은 후보 안에서 0으로 퇴화했다. 인식·선택·결합 중 어느 단계가 주원인인지는 분리되지 않았다.

사후 p(C) AUROC는 별도의 탐색 관찰이다. 환자·ordinal·영상 수에 대한 통제 없이 이를 이용 가능한 시각 능력이나 방법 효과로 승인하지 않는다. 두 기본 모델의 낮은 정확도는 기존 전문 classifier 또는 직접 SFT의 부족함도 입증하지 않는다.

이번 결과로 기존 `mri-explicit-target-context-effect`를 정정하거나 승격하지 않는다. 새로운 정상 사용 한계의 등록 역시 인터페이스와 재현 범위를 더 분명히 하기 전에는 보류한다.

# Strategy Check / 연구 방향 판단

- **실행 유효성:** 고정 E12의 실제 후보 분류 비교와 확대 중단은 유효하다.
- **성능 개선:** 공동 입력의 실용적 추가 가치나 새로운 방법 효과는 확보하지 못했다.
- **가설 지지:** 현재 frozen 인터페이스의 기본 신호 기준 미달을 지지한다. 단일 입력·LF가 충분하다는 가설은 기본 신호 자체가 부족하므로 입증되지 않았다.
- **신규 기여 가능성:** 아직 근거가 없다. 후보 확률 순위와 argmax의 차이는 단순 보정·교란 설명을 먼저 검토해야 한다.

iter_056~066에서 남은 인식·인터페이스 불확실성은 이번 임상 등급 과제로도 해소되지 않았다. 타 계열 Qwen 비교는 수행됐지만 두 모델의 실패 양상은 같지 않다. 이를 공통 내부 원인으로 묶지 않는다. 자료 연결·기하 검증과 OOM 이후 실행 경로 수정이 주요 준비 작업이었으며, 누적 비용 비율은 산출하지 않았다.

새 모델·자료 확보나 즉시 학습보다 기존 출력의 한정 재분석이 싸고 현재 경쟁 설명에 직접 연결된다. 다만 이는 원 계획의 음성 판정을 뒤집기 위한 threshold 탐색이 아니다. 결과가 불확정이면 같은 자료의 보정 탐색을 더 붙이지 않는 종료점을 둔다.

# Recommended Next Experiment

새 GPU 실험에 앞서 기존 D/E12 점수를 한정 재분석한다. 분석 대상 점수와 대조를 사전에 고정하고 환자 cluster 불확실성, ordinal 및 영상 수 교란, 대응 text-only를 확인한다. 단순 보정은 D에서만 정하며 E12는 이미 관찰한 개발 자료로 명시한다.

판별 정보와 단순 보정 후의 중요한 잔여 문제가 함께 확인될 때만 별도 method pilot의 가치와 gate를 검토한다. 순위 신호만 남거나 불확정이면 Modic 경로를 보류한다. F139·새 prompt·세 번째 모델·적응은 이 한정 후속에 포함하지 않는다.

논문 추천은 보류한다. 이번에는 유망한 방법 효과나 재현된 진단 방향보다 기본 신호 기준 미달과 미분리된 사후 관찰이 남았다.
