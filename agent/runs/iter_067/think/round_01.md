# 사고 라운드 1

## 핵심

기존 MSD 답변 보정 경로는 보류한다. 다른 MRI 자료로 즉시 실행을 옮기기보다, 관측 필요성을 어떻게 검증할지에 관한 전략 판단이 남았다. 새 후보로 SPIDER의 Modic grading을 확인했지만, 이를 곧바로 복수 sequence 결합 진단으로 승인하지 않았다.

## 기존 기록에서 확인한 것

- `agent/GOAL.md`, `agent/GPT_USAGE_POLICY.md`, iter_061·062·066 리뷰, iter_065 계획, 관련 `LIMITATIONS.md`와 `CODE_ASSETS.md`를 읽었다.
- iter_066 E12에서 J scoring BA는 0.55319, 위치 prior는 0.76553이었다. 생성 대비 회복은 있지만 영상별 신호의 실용적 회복은 확인되지 않았다. E48 미실행은 원 확대 조건에 맞는 종료다.
- iter_061·062의 OmniBrainBench 비교는 단일 영상의 충분성이나 복수 영상의 필요성을 주석으로 구분하지 못했다. 타 계열 Qwen 비교도 이미 수행됐다. 추가 모델 하나를 넣는 것만으로 현재 식별 문제가 해결된다고 볼 근거가 없다.
- `mri-explicit-target-context-effect`는 observed다. target tensor와 정답 연결은 검증됐지만, 단독 기본 신호가 원 기준을 충족하지 못했다. 명시적 index routing으로 피할 수 있는 손실 이후의 실용적 잔여 문제도 확보되지 않았다.
- MSD의 W/E mask는 병변 annotation의 위치·유형을 제공한다. 특정 sequence에서 그 병변을 판별할 수 있는지, 부분 영상이 임상적으로 충분한지를 제공하지 않는다. 이 점은 iter_065 원 계획에도 명시돼 있다.

## 한정해서 검토한 새 대조: SPIDER Modic

가설은 데이터 이름보다 먼저 정했다. T1과 T2의 신호 조합으로 정의되는 소견이면, 단일 관측과 복수 관측의 역할을 더 명료하게 비교할 가능성이 있다.

[SPIDER 공식 v4 배포](https://zenodo.org/records/10159290)는 환자별 MRI와 IVD 수준의 Modic I/II/III grading을 제공한다. [최종 저자 논문](https://www.nature.com/articles/s41597-024-03090-w)의 Radiological gradings 절은 전문 근골격 영상의학과 의사가 수준별로 평가했다고 설명한다. 이전에 확인했던 arXiv v2에서는 해당 절을 찾지 못했으므로, grading 근거는 최종 출판본으로 구분했다.

자료는 새로 받을 필요가 없었다. `research/results/iter_019/source/`에 images.zip, masks.zip, overview.csv, radiological_gradings.csv가 보존돼 있다. 이번에 grading CSV를 직접 읽고 MD5 `a5b7a6ad7fb4daa0bfa650b716f026f6`를 계산했으며 공식 v4 표시와 일치했다. 영상 archive의 전체 checksum이나 실제 T1/T2 영상 연결은 이번에 재검증하지 않았다.

실제 CSV는 218명·1,520 IVD 행이다. Modic 값별 분포는 0=1,006행, 1=4행/3명, 2=503행/146명, 3=7행/6명이다. 이들은 독립 환자 수와 구분해야 한다. 극단적인 분포가 단순 파싱 오류인지 확인하기 위해 [저자 논문의 Table 3](https://pmc.ncbi.nlm.nih.gov/articles/10908819/)도 확인했다. 표의 train/validation 합계는 I=4, II=503, III=7로 로컬 집계와 맞는다.

`research/results/iter_021/data/split.json`에 보존된 D8에는 I/III가 없고, E48에는 각각 한 행만 있다. F139에는 I 3행·III 6행이 있다. 이 확인은 기존 split과 CSV를 읽은 것이며 F 영상이나 모델 출력은 새로 평가하지 않았다. F를 새 개발 집단으로 자동 소비해서는 안 된다.

## 의미와 한계

[Modic 자동 판별 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC10782244/)는 T1/T2의 신호를 각각 판별한 뒤 유형을 결정하는 전문 파이프라인을 다룬다. 따라서 sequence별 신호 인식과 규칙 결합을 분리하는 대조에는 근거가 있다. 그러나 SPIDER의 최종 유형 label을 각 영상의 실제 신호 판독 정답으로 역변환하면 순환적인 pseudo-label이 될 수 있다. 사례별 필요성이나 부분 영상의 충분성을 자동 보장하지 않는다.

희귀 유형이 적다는 이유로 모든 소규모 출력 탐색을 금지하는 것은 아니다. 다만 기존 D/E의 두 희귀 행을 중심으로 새 영상 처리·실행기를 만들면, 현재 투자 결정을 바꾸기보다 사례 설명에 머물 가능성이 크다. 보존 F를 사용해도 전체 I형 환자는 3명이다. 이 한계를 숨기고 유형별 일반화나 결합 실패를 주장할 수 없다.

가까운 기존 방법도 강하다. [Voxel-wise Modic mapping 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC9238279/)는 segmentation과 T1/T2 신호 기반 분류를 사용한다. [검출+3D CNN 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC10951698/)도 paired T1/T2 분류를 다룬다. 따라서 Modic 분류나 두 sequence 사용 자체는 contribution이 아니며, VLM의 언어 조건과 근거 연결에서 무엇이 추가로 필요한지 먼저 정해야 한다. 해당 모델의 가중치 접근성·SPIDER 중복 여부는 아직 확인하지 않았다.

## 재사용과 과거 실패 범위

SPIDER 재사용 가능성을 판단하려고 `iter_021/review.md`와 iter_019~021 CODE_ASSETS 항목을 읽었다. 이전 결과는 reference 좌표 복사와 점→bbox 인터페이스 문제이며 Modic 판독의 실패가 아니다. F139는 보존 대상이다.

과거 MHA 경로에는 독립 물리좌표 검증, 비유한 입력 거부, 검증 결과의 실행 연결 문제가 남아 있다. 현재 브랜치의 `git status --short`는 비어 있었고 `git ls-files`에는 mi19 자료 모듈이 없다. archive에 코드가 있으므로 새로 재구현할 이유는 없지만, 사용할 경로를 정하기 전에는 선별 반입 manifest를 확정하지 않는다. 이번에는 소스 재사용을 승인하지 않았다.

## Strategy Check / 연구 방향 판단

- 관찰: MedGemma의 context 손실과 답변 인터페이스 효과는 유효하지만, 충분한 인식 이후의 근거 사용 실패는 미확정이다.
- 남은 설명: 기본 인식, 부분 영상 충분성, 답변 prior, 실제 선택·결합 실패가 얽혀 있다.
- 현재 방법 개선: 같은 MSD prompt·문자열·threshold 탐색은 종료 판단을 바꿀 근거가 약하다.
- 원인 진단: SPIDER Modic은 임상적 sequence 역할이 명확한 후보지만, 실제 주석과 표본 구조가 중요한 제한이다. 단순한 데이터 교체로 이전 문제가 사라지지 않는다.
- 다른 투자: 기본 MRI 인식을 직접 적응으로 확보한 뒤 근거 사용을 검증하는 선택이 있다. 그러나 전문 대안 이후의 가치와 method 진입 근거를 먼저 정해야 하며 새 학습을 지금 승인하지 않는다.
- 비용: iter_066에서 최종 D 기술 검사 883초가 본 scoring 합계 618초보다 길었다. 새 경로에서도 작은 출력보다 자료·검증 구현이 지배할 수 있으므로, 결정 가치가 없는 대조를 발주하지 않는 것이 중요하다. track 전체 비용 비율은 측정하지 않았다.

다음 라운드는 이 충돌을 다루는 전략 판단이다. 같은 source를 전수 재검색하거나 MRI benchmark 목록을 늘리지 않는다. 제한된 주장으로도 중요한 의사결정을 할 수 있는지와 기본 인식 적응의 비교 가치를 선택한다.

## 대규모 GPU 필요 후보

다중 sequence의 국소 시각 표현과 언어 답변을 함께 적응하는 대규모 volume–text 학습은 장기 후보로 남긴다. 현재는 충분한 인식 뒤의 실패와 전문 대안 대비 가치가 확인되지 않아 투자 근거가 없다. 이를 두 RTX 3090에서 가능한 LoRA·adapter 검토의 금지로 해석하지 않는다.

이번 문헌은 설계 검토용이며 사용자 논문 추천으로 등록하지 않는다. 신규 방법 효과나 긍정적 실험 근거는 이번에 얻지 않았다.

## 다음에 파고들 질문
- 관측 필요성이 직접 주석되지 않아도 임상 정의와 제한된 대조로 중요한 근거 사용 주장을 검증할 수 있는가? SPIDER 원 grading과 가까운 Modic 신호 판별+규칙 방법을 기준으로 가능한 주장과 불가능한 주장을 확정한다.
