# Assessment

실제 구현 담당은 Claude이며 engineer_backend.json과 claude_meta.json에서 sonnet/medium, 실제 모델 claude-sonnet-5-5를 확인했다. 리뷰 대상은 f86dccf19f2f5bfe7f17b0031acb45649dc38527이며, 변경은 report98_data.py와 report98_lock.py 추가다. unpreserved_paths는 없고 reuse_manifest는 요청 파일이 없는 상태다.

계획·보고서·changes.patch·소스·결정 JSON·실제 도구 호출을 확인했다. 도구 로그에는 48명 원문 모음의 분할 읽기, 대표 reference 조회와 잠금 실행이 있다. 신규 생성·학습·생성기 검사는 없었다. 조회 명령 한 건의 권한 거부 뒤 다른 읽기 명령이 성공했으므로 권한 문제가 이번 중단 원인은 아니다.

N=0이면 생성하지 않는 분기 자체는 원 계획에 있다. 그러나 그 전제가 신뢰할 만하게 확정되지 않았다. SELF_CHECK: FAIL이나 GPU 미사용 자체가 아니라, 의사결정을 좌우하는 적격성 평가의 결함 때문에 실행 실패로 판정한다.

# Key Findings

1. 리뷰에서 48명·29개씩 총 1,392개 영역 segment의 추출을 실제 실행했다. 두 신규 소스의 작업 파일·commit blob·기록 SHA256이 일치했고, readings와 amended reference의 hash도 일치했다.
2. 저장된 수동 라벨을 독립 집계하면 P 14명, clear Q는 P085·P090 두 명, 교집합은 0명이다. 이는 저장 라벨의 산술 검증이며 의미적 적격성의 독립 확인은 아니다.
3. P008 reference에는 persistent atelectasis-condensation이 있고, 영역 출력에는 large left lower lobe consolidation with volume loss가 있다. 초안에는 density와 volume loss가 있다. 현재 소견 동일성과 시간 지속성을 따로 판단해야 하는데, 구현은 이를 합친 사유로 제외했다.
4. P033의 'opacity, which may represent pneumonia'는 소견 존재와 추정 원인을 구별해야 한다. 양측 apical·우하엽 reference와 영역 출력의 위치 대응은 여전히 불확실하다. 잘못된 hedge 설명을 고친다고 자동 적격이 되는 것은 아니다. P053도 같은 구분이 필요하다.
5. 보고서의 '모호 사례를 clear로 바꿔도 P가 비어 있다'는 설명은 틀렸다. P008·P033·P053은 P_CLEAR에 들어 있어 바로 생성 여부를 바꾸는 사례다.

# Problems / Concerns

원 계획은 P를 reference-supported 사실 집합으로, Q를 명확한 양성 추가 사실 집합으로 정의했다. 구현은 기존 문장 단위 fact를 유지하고 P를 양성 사실 위주로 좁혔다. P033의 marked 속성, P053의 small·metapneumonic 속성, P069의 suggestive 표현처럼 원자 분해가 필요한 항목도 전체 fact와 단일 인용으로 기록했다. 이런 자료 구조는 후속 'P 모두 보존' 평가에도 부적합하다.

quote_check는 인용의 존재를 확인하지만 함의·범위·확실성을 검사하지 않는다. P 인용 검사도 fact ID 존재만 확인한다. 자동 Q 색인 후보 9명을 모두 다뤘다는 검사는 원 계획이 요구한 새로운 원자 사실 후보의 완전성을 보장하지 않는다.

새 소스는 고정 저장 자료 읽기 도구로 일부 재사용할 수 있다. 다만 중복 키 덮어쓰기, 입력 manifest와 원 reference의 provenance 누락, 검사 실패 후에도 결정 파일을 먼저 생성하는 경로는 재사용 전에 보완해야 한다. 기존 생성기 결함은 이번 반복에서 해제되지 않았다.

# Interpretation

새 모델 출력이 없으므로 성능 개선·교정 실패·출처 정보 무용성 중 어느 것도 관찰하지 않았다. 현재 확인한 것은 저장 자료와 수동 라벨에 따른 준비 결과다. 이를 '영역 설명이 소견을 거의 새로 제공하지 않는다'는 확정 관찰로 확대하면 안 된다.

iter_088과 이번 결과는 평가 단위가 다르다. 이전 회복 지표와 이번의 동일 환자 내 P/Q 동시 존재 조건은 같은 질문이 아니며, 서로 반박하거나 독립 재현으로 합칠 수 없다. 이번 결과로 기존 limitation 상태를 바꾸지 않는다.

GPU를 사용하지 않은 것은 잘못된 자원 절약의 증거가 아니다. 자료 진입 조건이 미확정인 동안 생성을 멈춘 점은 타당하다. 다만 자료 적합성이 확보됐다고 보고할 근거도 없다. 준비·의미 검토가 이번 작업의 중심이고 순수 검토 시간은 미측정이다. 세션 전체 시간 약 204.7초만 기록돼 있다.

# Strategy Check / 연구 방향 판단

**이어받는 관찰:** iter_097에서 선택한 질문은 저장 영역 정보로 누락을 회복하면서 기존 정답을 보존할 수 있는가이다. 이번에는 그 질문의 자료 진입 판단에 도달했으나 내용 효과·단순 추가의 충분성·출처 효과 중 어떤 경쟁 설명도 줄이지 못했다.

**시험 설정:** 현재 LoRA 설정의 보류를 유지한다. 고정 교정 인터페이스는 유효한 음성 결과로 보류된 것이 아니라 적격성 구현 오류로 미실행이다.

**연구 관찰:** P085·P090의 추가 소견 후보와 세 결정 민감 사례를 보존한다. 정확한 회복 빈도나 안전한 교정 효과는 미확정이다.

**연구 질문:** 모델 생성 근거를 활용한 회복·보존 문제의 중요성은 남지만, 이번 준비 작업은 강한 단순 대안 이후의 잔여 문제나 신규 기여를 입증하지 못했다. 가까운 선행 검토는 원 계획의 범위를 유지하며 재조사하지 않았다.

다음 투자 두 가지를 비교한다.

- **한정 보완 후 원 비교:** 저장된 세 대표 사례에서 시간·원인·현재 소견을 분리하면 생성 진입 결정이 달라질 수 있다. 새 자료·학습 없이 해결할 수 있고 지배 비용은 한정 의미 검토다. 적격자가 확인되면 원래의 무근거 교정·문장 제공·출처 제공 및 단순 추가 비교가 경쟁 설명을 구분한다.
- **현재 설계 즉시 보류:** 반복 평가 정비 비용은 줄지만, 지금은 잘못된 민감도 주장에 기대어 연구 기회를 버릴 위험이 있다. 올바른 원 규약 적용 뒤에도 적격자가 없거나 의미 불확실성만 남을 때 선택한다.

첫 번째를 권고한다. 범용 평가기 개발이나 새로운 의미 규칙 탐색으로 확대하지 않는다. 새로운 학습·모델 교체는 현재 진입 오류를 해결하지 않아 선택하지 않는다. 실행 유효성·성능 개선·가설 지지·신규 기여 모두 이번에는 확보되지 않았다.

# Recommended Next Experiment
