# Key Findings

CURE는 D4 12건과 S24 72건을 완료했다. S24의 자연 충돌은 3/24명이며 모두 reference 양성이다. 충돌 3명과 보존 대조 3명에 T/V/W 18건을 생성했다. 현재 표본은 개발 자료이며 S24 중 22명이 과거 결과 파일에 등장한다.

T는 plain 1건·bbox JSON 5건이다. 형식 정상 조건의 안전 정답은 T 1명·V 3명으로 V−T 방향이 바뀐다. 따라서 원 집계의 V−T 음성을 일반적인 영상 무효의 근거로 사용하지 않는다. 모든 조건에서 양방향 개선 기준을 충족할 음성 환자가 없으며, V는 초안 유지보다 보존·오류 측면에서 불리하다.

기술 파일은 공식 chat template과 입력 tensor 일치, text-only의 image token·pixel_values 부재, adapter 부재와 4건의 공식 생성 token 일치를 기록한다. 실제 도구 로그에서도 해당 검사를 확인했다. 형식 실패 자체는 올바른 입력에서 발생한 모델 출력 관찰이지 자동으로 실행 무효 사유가 아니다.

# Problems / Concerns

`report101_eval.py`는 한 상태 편중을 계산하면서도 음성 분기보다 우선하는 불확정 조건으로 사용하지 않는다. 계획은 한 상태 편중과 의미 판단에 따른 방향 변화의 해석을 보류하도록 명시한다. 따라서 자동 라벨 `negative_V_no_gain_hold_frozen_interface`를 그대로 최종 과학적 판정으로 승인하지 않는다. 설정 보류 결정은 유지한다.

P 보존 판정에도 범위 문제가 있다. index16의 reference와 초안에는 'The right basal consolidation persists slightly'가 있지만 V에는 시간 표현이 없다. 이를 복합 atom 전체 kept로 처리했다. index12에서는 정상 cardiomediastinal silhouette의 전체 의미와 mediastinal contours만의 보존이 구분되지 않았다. 이 문제는 정확한 안전 정답 총수의 재사용을 제한한다. 그러나 양성 투자 기준 미달과 현재 설정 보류를 뒤집지는 않으므로 전 실험을 무효화하거나 새 전수 의미 감사를 발주하지 않는다.

보고서에는 노출 24/24 대 실제 요약 22/24, 본 교정 non-EOS 4건 대 원시 요약 3건, 양성 요건 모두 미달 대 V−W 요건 충족이라는 불일치가 있다. 안전 정답과 실제 판독문 형식 성공도 구분해야 한다.

GPU 재개 검사의 수동 마무리는 숨겨지지 않았다. 다만 완료 행 0건에서 재개한 교정 검사는 기존 완료 행을 보존하고 잔여 요청만 실행하는 검증을 대체하지 못한다. CURE 완료 경로의 전 shard 요청 집합 검사와 공식 transform digest도 재사용 전에 보완할 사항이다. 현재 완료된 출력의 비교를 무효화하는 근거는 아니다.

# Interpretation

초안 K는 평가 범위의 정답 사실을 이미 보존했다. 따라서 현재 자료에서 교정의 실용 이득을 주장할 근거가 없으며, 잘못된 영역 설명을 무조건 추가하는 접근의 비용을 보여준다. 다만 전체 보고서의 모든 사실이 정확하다는 의미는 아니다.

V−W 차이는 영상 연결이 출력에 영향을 준다는 제한된 근거다. 이는 T 대비 순수 영상 기여, 충돌을 실제로 추론해 해결하는 능력, 또는 새 방법의 필요성을 입증하지 않는다. T의 bbox 출력은 현재 frozen 인터페이스의 부적합을 드러내지만 그 내부 원인은 미확인이다.

# Strategy Check / 연구 방향 판단

**시험 설정:** 추가 prompt·표본·학습 투자는 보류한다. 현재 6명에서 K보다 개선되지 않았고 T의 형식 실패로 핵심 비교의 판별력이 낮다.

**연구 관찰:** 영상 교환에 따른 출력 변화, 올바른 영상에서도 발생한 기구 누락·새 명시 오류는 보존한다. iter_100의 정보 회복과 충돌 전달 사례와 연결되지만 같은 현상의 독립 재현으로 합치지 않는다. 위치 supervision 자체의 효과는 이번에 시험하지 않았다.

**연구 질문:** 올바른 초안을 보존하면서 잘못된 자동 근거를 배제하는 문제는 남는다. 그러나 현재 방법을 계속 실행할 근거와 이 문제의 중요성은 별개다. 가까운 기존 fact-checking 방법이 이미 해결한 범위부터 받아들여야 한다.

실제 선택은 두 가지다. 첫째, 현재 인터페이스를 짧게 바꾸어 재시험하는 선택은 형식 개선 가능성이 있지만 같은 불확실성을 연장하고 원 종료 조건과 충돌하므로 선택하지 않는다. 둘째, 기존 fact-checking 방법의 입력·보존 평가를 명확한 저장 사례와 대조하는 한정 확인을 선택한다. 기존 방법의 잔여 문제가 확인되지 않으면 이 교정 묶음의 보류를 유지한다. MRI나 과거 공동 grounding을 새 이름으로 재개하지 않는다.

실행 유효성은 확보됐지만 성능 개선은 확인되지 않았다. H_visual과 H_text는 불확정이며 신규 기여 가능성도 미확인이다. 이번에 줄어든 설명은 현재 영상이 출력에 전혀 영향을 주지 않는다는 주장 정도이고, 유용한 교정과 단순 영상 조건 반응은 분리되지 않았다.

기록된 생성 단계에서는 교정의 반복·긴 출력이 비용을 지배한다. 본 교정 generation time 합계 약 1,890초 중 T 약 643초, W 약 1,189초, V 약 58초다. D4의 2→4 worker 비교는 wall 1,168→614초였고 12요청 token이 같아 본실행 4 worker 선택은 타당하다. 본실행 wall은 약 664초다. 감사·의미 검토 시간은 미측정이므로 전체 지배 비용은 단정하지 않는다.

# Recommended Next Experiment

현재 자료의 교정 생성은 종료한다. 다음에는 공식 기존 fact-checking 방법이 잘못된 영역 설명으로부터 올바른 초안을 보존하는 조건을 실제로 다루는지, index12·15 같은 명확한 저장 사례와 연결해 한정 확인한다. 기존 방법이 충분하면 이 연구 묶음을 보류한다. 구체적인 중요한 잔여 조건과 강한 대조의 실행 가능성이 확인될 때만 별도 최소 비교를 계획한다. 단순 미검증이나 CI 폭을 재개 근거로 삼지 않는다.

이번에는 긍정적인 후속 탐구 근거가 충분하지 않아 논문 추천을 보류한다.
