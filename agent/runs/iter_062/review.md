- **다음:** 같은 MRI 근거 사용 질문에서 관측 충분성을 판별할 최소 대조를 정한다. 현재 자료의 자동 확대는 하지 않는다.

# Problems / Concerns

현재 정확도 결론을 무효화하는 blocker는 발견하지 않았다. 재사용 승인은 별개다.

- 완료 claim의 소유 PID가 종료되면 다른 worker가 이를 stale로 인수할 수 있다. worker 시작 때의 done 집합만으로는 종료 시점이 엇갈리는 중복을 막지 못한다. 현재 E21에는 중복이 없었다.
- JSONL reader의 조용한 prefix 반환, 비용 sidecar의 미봉인·중복 미검사, 답변과 비용 기록 사이 중단 경로가 남아 있다.
- CPU 검사는 요청·labels·영상·코드 복사본 변조를 확인했지만 source·protocol 변조 fixture까지 수행한 것은 아니다. SIGKILL 복구 시험은 실제 수행됐고 34개 출력이 기준과 일치했다.
- MedGemma provenance 회귀는 별도 검사에서 성공했지만 평가 진입점 자체의 검증 연결은 보완할 필요가 있다.
- Qwen 모델 파일 hash는 fetch 시 기록되며 protocol 검사 때 실제 파일을 다시 확인하지 않는다. 환경 기록의 설치 버전 문자열에도 오기가 있다.

GPU 두 장을 각각 한 worker로 사용했다. E21 wall-clock은 468.17초, 관측 GPU peak는 16,987/17,025 MiB다. 같은 GPU의 두 모델 복제본은 메모리상 부적절하다. 다만 계획한 batch2 비교와 실행 전 비용 예측은 수행 기록이 부족하다. 이는 자원 운영 보완 사항이며 유효한 정확도 결과의 기각 사유는 아니다.

# Interpretation

Qwen의 텍스트와 영상 조건 점수가 함께 높다는 점만으로 영상 활용이 개선됐다고 할 수 없다. 모델 간 paired 효과 차이도 불확정이다. 보고서의 '영상 추가 효과 없음'은 '큰 추가 효과를 지지하지 못함'으로 읽어야 한다.

두 모델에서 공동 손실 후보 기준은 충족되지 않았다. 그러나 단일 영상이 충분하다는 정답 근거가 없어 인식 실패와 선택 실패를 구분하지 못하며, 복수 영상이 필수라는 주석도 없어 결합 능력을 판정하지 못한다. 여러 기본 모델의 불확정 결과는 기존 해결책의 부족함이나 VLM 전체의 한계가 아니다.

E21은 기존 MedGemma 결과를 본 뒤 적격성을 정정한 개발 집단이다. 독립 확인이나 외부 일반화 근거가 아니다. 새 limitation 등록·승격은 하지 않는다.

# Strategy Check / 연구 방향 판단

**실행 유효성:** 동일 사례의 타 계열 비교를 완료했다. **성능 개선:** Qwen의 절대 점추정은 높지만 영상 추가 효과의 개선은 입증하지 못했다. **가설 지지:** 모델 특이성과 공동 손실 모두 미확정이다. **신규 기여 가능성:** 현재 결과는 모델 선택 진단이며 새 방법의 필요성·효과를 보여주지 않는다.

iter_061의 MedGemma 관찰은 적격 E21에서도 유지되지만, Qwen을 추가해도 경쟁 설명을 결정적으로 나누지 못했다. 추가 모델 확보만으로 문제가 해결된다는 경로는 근거가 약해졌다. 반면 질문의 정보 충분성, 배포 영상의 충분성, 기본 인식은 여전히 미검증이다.

현재 방법 개선은 개입할 중요한 잔여 손실이 확인되지 않아 우선하지 않는다. 같은 E21의 자동 확대도 사전 종료 조건과 맞지 않는다. 상위 질문을 유지하면서 관측과 정답의 연결이 더 명확한 최소 대조를 선택하는 한정 보완이 다음 투자다. 새 데이터 이름 자체를 진전으로 보지 않는다.

준비 비용에는 새 checkpoint 확보와 D 재실행이 포함된다. 본평가는 약 8분이지만 전체 준비·감사 비용의 통합 실측이 없어 지배 비용이나 절감률을 정량 주장하지 않는다. 다음에는 기존 자산을 재사용하고 판단을 바꾸는 자료 확인에 범위를 제한한다.

논문 추천은 보류한다. 이번 비교는 불확정이며 특정 방법 방향의 긍정적 효과나 재현되는 결함을 확인하지 못했다.

# Recommended Next Experiment

현재 key-image 과제의 방법·모델 교체 투자를 보류한다. 다음 계획은 같은 MRI 근거 사용 질문에서 어떤 경쟁 설명 하나를 구분할지 먼저 고른다. 정답과 관측의 연결을 소수 실제 사례로 확인하고, 통과하면 같은 계획에서 최소 실제 출력을 실행한다.
