실제 구현 담당은 `engineer_backend.json`과 `claude_meta.json`에 기록된 Codex/gpt-6-astra, low effort다. 리뷰 대상은 `faee416633f87d281656c00982b973757c36817b`이며 이전 checkpoint `056e9fb8eac779a557d2aed23fb001d6d3beefa0`에서 추가된 9개 소스를 검토했다. `unpreserved_paths`는 없다.

iter_088 및 기준 iter_087 계획에 따라 기존 76명 부분 평가를 인계하고 남은 20명을 완료했다. 신규 생성·학습·모델 적재는 없으며, 원 결과는 별도 경로에 보존됐다. 저장 출력의 실제 가설 재평가이므로 valid_experiment=true다. 보고서의 SELF_CHECK: FAIL을 실행 실패로 자동 변환하지 않는다. 보고된 불확실성은 현재 제한된 관찰 전체를 무효화하지 않는다.

# Key Findings

비정상 층 48명의 환자별 평균 차이를 사용했다. 아래 구간은 paired bootstrap 10,000회·seed84017의 95% CI다.

| 비교 | 확정 recall 차이 | 명시 모순 차이 |
|---|---:|---:|
| B0-R − M15-R | +3.13pp [−2.08, 10.42] | −2.08pp [−10.42, 4.17] |
| M15-S − M15-R | −3.65pp [−11.46, 3.65] | 0.00pp [−10.42, 10.42] |
| B0-S − M15-S | +5.21pp [−2.08, 13.54] | +4.17pp [−6.25, 14.58] |
| C-G − M1-G | +15.28pp [2.08, 28.82] | −20.83pp [−33.33, −8.33] |
| C-H − C-G | +6.08pp [1.04, 11.98] | +47.92pp [33.33, 62.50] |

C-G의 strict recall 차이는 +10.07pp [2.78, 18.75]다. 모호 대응을 모든 조건에서 U로 처리하면 확정 recall 차이는 +11.11pp [−1.04, 23.26]로 바뀐다. 점추정치의 회복 신호와 효과 확증을 구분해야 한다. C-G는 주분석의 원 점기준을 충족하지만 C-H는 recall +10pp와 모순 증가 5pp 이내 기준을 모두 충족하지 못한다. 평가기에 추가된 `ci_supports_both`는 원 성공 기준을 대체하는 새 gate로 사용하지 않는다.

C-H의 확정 내부 모순은 전체 76/96명이며 비정상 층에서는 41/48명이다. C-G는 0/96명이다. 이는 저장 규약으로 판정한 내부 충돌이며 임상 오진율이 아니다. C-H는 C-G 출력을 포함하므로 recall 증분을 결합 능력의 증거로 읽을 수 없다.

리뷰에서 별도 DSL 파서로 출력별 주지표 3,072개를 대조하고 다섯 비교의 recall·strict·모순·내부 모순 및 CI를 재현했다. 모호 대응 민감도의 recall과 CI도 별도로 재계산했다. 원문 anchor offset 9,174개는 모두 일치했다. 코드·인계 원본·완료 산출물 hash 92개와 상속 의존 소스의 리뷰 SHA 일치도 확인했다.

`codex_engineer_stream.jsonl`에서 초기 인계 JSON 처리 오류, 독립 검증의 원본/보완본 연결 오류, protocol 이력 재구성 오류와 fixture 실패를 확인했다. 후속 수정과 성공 로그가 존재하며 실패 기록은 보존됐다. 기존 fixture 41/41, 경로 검사 14/14와 `verify/independent.json`, `verify/sensitivity.json`의 결과를 대조했다.

# Problems / Concerns

P062의 intense 대 mild scoliosis는 이제 속성 충돌로 저장돼 strict에서 제외된다. P000의 폐외 소견을 clear lungs로 부정한 문제와 P076의 no effusion을 blunting 부재로 확장한 문제도 수정됐다. 이 사례들의 reference·원문·최종 판정을 직접 확인했다. 과거 blocking 기록은 보존하며, 이번의 제한된 recall·명시 충돌 해석은 승인한다.

접속 목록의 C>S>U 단순화는 여전히 완전한 원자 주장 분할이 아니다. pooled 주장 coverage는 M1-G 19.05%, C-G 34.48%, C-H 11.46%이며, 서로 다른 길이·영역 반복·주장 단위의 영향도 받는다. 이를 임상 precision이나 미표기 소견의 오류율로 해석하지 않는다. 해당 강한 해석을 제외한 현재 결론에는 blocking_issues를 추가하지 않는다.

24명 점검은 원 판정을 보며 수행한 혼합 판정자 재검토다. 독립 눈가림 평가나 전문의 검증이 아니다. `C-H_explicit_region_only`는 실제 범위 재판정이 아니라 충돌을 인위적으로 제거한 stress bound이므로 긍정적 투자 근거로 사용할 수 없다.

공개 CURE config의 validation 평가·curriculum 경로는 확인됐지만 해당 가중치의 환자별 노출은 미확정이다. E96은 개발 자료다. 수동 회귀도 base/SFT 각각 6/8 일치로 정정됐지만 과거 tensor 부재로 원인은 남는다. 이를 이번 E96 전체 무효나 재생성 이유로 확대하지 않는다.

전체 snapshot에는 iter_086의 미수정 생성기·메모리 예약 문제가 남아 reusable_code=false다. 이번 고정 평가 경로는 모듈 단위로 승인한다.

# Interpretation

RSNA 위치 SFT의 기존 grounding 개선은 유지된다. 이번 자유 판독에서 B0의 개선은 불확정이며 strict 개선도 확인되지 않았다. grounding 개선과 판독 개선이 자동으로 연결된다는 주장은 지지되지 않는다.

CURE의 해당 base 대비 회복 신호는 보존할 가치가 있다. 그러나 서로 다른 학습 자료·학습량·목적을 가진 시스템 차이이므로 위치 supervision만의 효과가 아니다. 현재 PadChest 확장 결과를 CURE 공식 benchmark의 재현 실패로 표현해서도 안 된다.

현재 C-H는 추가 요청 29개와 큰 충돌 증가에 비해 원 기준을 충족하는 회복을 얻지 못했다. C-G 선택으로 이 충돌의 상당 부분을 피할 수 있다는 사실은 새 결합 방법의 필요성을 약화한다. 그렇다고 C-G가 모든 임상 과제에 충분하다는 뜻은 아니다.

# Strategy Check / 연구 방향 판단

**이어받는 관찰 → 남은 설명:** iter_086의 CURE 회복·hybrid 충돌은 평가 수정 후에도 남았다. 따라서 기존 평가 오류만으로 두 현상을 모두 설명하기는 어려워졌다. 다만 의미 대응, reference coverage, checkpoint 노출 및 학습 조건 차이는 남는다. 인식·선택·결합의 내부 원인은 이번에 분리하지 않았다.

**실행 유효성:** 저장된 실제 출력의 재평가와 독립 산술 검증은 완료됐다. **성능 개선:** C-G 개선 신호가 있으나 의미 민감도와 개발 평가 한계가 있다. **가설 지지:** 무조건 영역 결합의 회복–충돌 관계는 현재 조건에서 관찰됐다. **신규 기여 가능성:** 강한 C-G 선택 이후의 중요한 잔여 가치가 아직 특정되지 않았다.

지배 비용은 의미 판정·전사·출처 및 산술 검증이었다. 이번 GPU 사용 0은 계획된 평가 blocker에 맞는 선택이다. 추가 GPU 생성으로 의미 불확실성이 해결되지는 않는다. iter_087의 사용 한도 중단과 담당 전환을 유효 실험 실패로 세지 않는다.

투자 선택은 현재 C-H·E192 확대 보류다. 같은 E96의 재채점이나 새 frozen 모델 순회를 자동 후속으로 붙이지 않는다. 다음 전략 계획은 같은 연구 묶음 안에서 동일 자료·예산의 통제 학습 비교가 위치 학습과 판독의 연결을 실제로 밝힐 수 있는지, 그렇지 않으면 해당 방법 투자를 보류할지를 판단해야 한다. 관찰 보존과 방법 개발 승인은 별개다.

# Recommended Next Experiment

즉시 실행할 추가 생성·학습 실험은 권고하지 않는다. 다음 계획에서 C-G를 강한 기존 비교군으로 유지하며 report-only 대비 위치 supervision 추가의 통제 비교를 검토한다. 자료·정답·노출 통제가 가능하고 결과에 따라 방법 투자 결정이 달라지는 최소 범위가 성립할 때 별도 pilot을 설계한다. 성립하지 않으면 현재 후보의 투자 보류 범위와 재개에 필요한 새 근거를 명시한다.

논문 추천은 보류한다. 이번 회복 신호의 의미 민감도가 남고, 다음 방법 방향도 아직 선택되지 않아 새 사용자 추천의 근거가 충분하지 않다.
