# Strategy Check / 연구 방향 판단

**기술 질문 → 실패 조건 → 공개 정답 비교 → 주장 범위:** 오류가 섞인 정보 중 유용한 답을 보존할 필요가 있는가 → 자연 초안과 자동 근거가 충돌하거나 한쪽이 unresolved일 때 → 공개 opacity 존재 정답에 대한 기존 답의 정오·미해결 교차표와 일치 대조 → 고정 모델·단일 소견·반복 개발 선택 집단의 정보 가치에 한정한다.

이어받는 관찰은 합성 초안 내용 손상과 자연 교정의 불확정이다. 남은 설명은 기본 인식 부족, 응답 평가의 영향, 일반 ensemble 상보성, 기존 단순 정책의 충분성이다. 이번 판단은 새 방법이 필요한지를 구체화하는 것이며 공간적 원인이나 내부 anchoring을 증명하는 것이 아니다.

두 선택을 비교한다. 승인된 저장 분석은 추가 생성 없이 재개 조건을 확인할 수 있다. 즉시 보류는 비용이 작지만 자연 초안의 정보 가치를 합성 결과로 대체할 위험이 있다. 사용자가 전자를 승인했으므로 이번 한 번을 선택한다. 다른 후보를 전수 탐색하거나 과거 CURE·MRI 설정을 재개하지 않는다.

**시험 설정:** 기존 frozen R과 합성 초안 설정은 종료·보류를 유지한다.

**연구 관찰:** 자연 출력의 상보성이 내용 정오인지 unresolved 차이인지 구분해 보존한다.

**연구 질문:** 기존 단순 대안 이후에도 중요한 잔여 조건과 시험 가능한 개입이 남을 때만 최소 pilot을 제안한다. 완전한 원인·신규성·타 모델 재현을 pilot의 선행조건으로 요구하지 않는다.

기존 기록은 GPU 생성 비용과 일부 운영 시간을 제공하지만 이번 CPU 분석 시간과 서비스 전체 비용은 미측정이다. 실제 비용을 기록하며 비용 절감률을 만들지 않는다.

# Contribution Path / Baselines / Reuse

가까운 선행은 다음 세 편으로 제한한다.

구현에서는 이 원문의 실제 입력·평가·대조·자동 근거 오류 취급을 관련 절에서 확인해 범위표로 남긴다. 기존 시스템은 우리 자료에서 미재현이며 우위를 주장하지 않는다. 원문에 없는 대조를 수행했다고 추정하지 않는다.

## 1. 동작 확인과 분석 규약 고정

`results/iter_117/eval/{per_patient,report,observations,verify}.json`, MAIN completion·worker 출력·요청·평가 잠금, `results/iter_116/provenance/{ledger_nogt,gt}.json`, selection과 원 출처 manifest를 연결한다. 174명 ID의 유일성, 두 집단87명, 원 정답과 category, request ID, 저장 답과 source/reason 및 raw 대응을 확인한다. 전체 과거 manifest·모델·영상 전수 감사는 하지 않는다.

실제로 읽은 파일은 전체 경로를 키로 SHA256과 기록한다. 과거 review의 불변 검증은 재사용하고 변경 또는 불일치가 발견된 연결만 확인한다. 원출력과 저장값이 모순이면 임의 재채점하지 말고 영향받는 비교를 미확정으로 표시한다.

## 2. 가능성 탐색: 원 평가의 상보성

불일치와 일치를 합산한 대표 정확도를 만들지 않는다. 각87명에서 K/B/G/E/M/S의 correct/wrong/unresolved 전체 분모를 제시한다. K 대 E/B/G/M/S의3×3 상태 교차표를 만들고 각 셀의 ID를 보존한다. 정답 수 차이는 추가 정답·잃은 정답·unresolved 이동으로 분해한다.

K정답/E명시오답2명, 반대8명, K정답/Eunresolved24명을 모두 연결한다. 나머지 셀도 전체 표에 남긴다. 각 사례에 G/M/S가 이미 해결하는지, R/N의 원 상태가 무엇인지 표시한다. 일치 대조에서는 K/B 모두 정답76명과 모두 오답11명을 분리해 같은 표를 만든다.

핵심 사례표는 위34명 전원과 일치 대조에서 K와 E/G/M/S의 정오·미해결 상태가 달라지는 사례 전원을 포함한다. 나머지 일치 사례도174행 기계 판독 표에 포함한다. 원문은 출처 확인에만 쓰며 새로운 임상 의미 분류·내용 답 재추출을 하지 않는다.

각 대안 A에 대해 K정답/A명시오답과 그 반대, K정답/Aunresolved를 분리한다. E/B/G 모두 명시 오답인 K정답 사례와, 일부 unresolved라 독점성을 판단 못 하는 사례를 구분한다. 이 교집합은 정보 존재의 진단일 뿐 사용 가능한 selector가 아니다. 명시 사례가 없다고 다른 조건의 추가 정보가 없다고 단정하지 않는다.

## 3. 단순 대안 이후 잔여 가치

M/S가 이미 보존하거나 교정한 부분부터 설명한다. G/B/E 단독과 M/S 조합의 정보 출처·추론 구성·학습 노출 차이를 나란히 기록한다. 전체 정확도 동률과 환자별 오류 동일성을 구분한다.

unresolved 범위는 기존 이진 답 변수의 가능한 배정으로 계산하되 동일 G가 M에, 동일 E가 S에 미치는 의존성을 유지한다. 지표별 최선값을 동시에 가능한 성능으로 합치지 않는다. 기존 CI를 인용할 수 있으나 새 유의성 탐색·threshold 선택은 하지 않는다.

공간적 관련성은 저장 detector packet과 기존 joint03·n_det/n_gt 등에서 확인 가능한 범위만 기술한다. 고정 detector box를 유지·제거하는 지표를 새로운 위치 교정으로 부르지 않는다. 공간 정보 제거 대조가 없으므로 일반 조합 효과와 공간적 필요성의 인과적 분리는 미검증이다.

## 4. 규모 확대·독립 확인·자원

이번 최대 범위는 기존174명과 저장 출력이다. 학습량·seed·신규 요청·GPU 사용은0이며 batch/worker 비교는 해당하지 않는다. CPU만 쓰는 이유는 사용자 승인 범위와 아직 해소되지 않은 방법 필요성 판단이다. GPU 실험 진입은 본 분석의 잔여 문제·최소 개입 제안, full 리뷰, 다음 사용자 승인 이후다.

CPU 시간은 첫 연결 및 전체 집계에서 실제 측정한다. 사전 wall-clock은 미측정이며 임의 시간 상한을 두지 않는다. 중간 산출물은 `research/results/iter_119/`에 입력 digest와 함께 보존하고, 재개 시 일치하는 완료 단계만 재사용한다. 입력이 바뀌면 덮어쓰지 않고 중단 사유를 남긴다.

6. 관찰/해결 필요성/시험할 개입을 연결한 투자 판단 한 개를 작성한다. 최소 pilot을 제안한다면 변경 요인 하나·강한 단순 대조·GT 없는 선택·교정과 보존 지표·비용 항목·종료 조건을 명시하되 실행하지 않는다.
7. CPU 실측 시간·재사용 범위·미확정 항목·SELF_CHECK와 원본 보존을 보고한다. full 리뷰 후 사용자 승인을 기다린다.

# Evaluation (성공/실패 기준 포함)

분석 완료는 방법 성능 성공이 아니다. 기존117의 불확정,118의 양성 진단과 limitation 상태를 그대로 유지한다. 새 효과 문턱을 사후 사례 수에 맞춰 만들지 않는다.

**양성 투자 근거:** 명시 답에서 유용한 자연 초안 정보와 반대 오류 위험이 확인되고, G/B/E 및 M/S 이후의 중요한 잔여 조건을 설명할 수 있으며, 정답을 보지 않고 시험할 개입과 공정한 대조가 구체화되는 경우다. 단순 사례 존재나 oracle 합집합만으로 통과시키지 않는다. 다음 행동은 최소 method pilot 하나의 승인 요청 제안이다. pilot의 최소 가치 있는 개선 폭은 관찰된 교정 기회·정답 보존 손실·추가 추론 비용과 연결해 제안하고, 실제 실행 전 별도 계획에서 고정한다.

**음성 투자 근거:** 현 자료에서 확인한 상보성이 기존 단일 대안 또는 M/S로 처리되고, 이후의 구체적인 정확도·보존·비용 문제가 제시되지 않으면 현재 설정의 추가 투자를 가치 부족으로 보류한다. 자연 초안 전체나 의료 교정 전체를 기각하지 않는다.

**불확정:** 잔여 가치가 unresolved 재해석, 확인되지 않은 출처, 선택 집단 외 일반화 또는 GT 기반 선택에 의존하면 근거 부족으로 보류한다. 원 규약으로 답하지 못한 부분을 명시하고 같은 자료의 의미 판정·준비 분석을 반복하지 않는다.

최종 보고는 위 분기 중 하나를 실제 선택한다. 세 결과를 모두 추가 진단으로 연결하지 않는다. 제안이 필요한 경우에도 새 실험은 다음 사용자 승인 대상이다.

# Risks / Checks

- 불일치 선정은 이진 K/B 중 하나가 맞는 구조다. 그 oracle 합집합은 방법 가능성의 증명이 아니다.
- M/S는 K를 사용하므로 초안 제거 baseline이라고 쓰지 않는다.
- K는 자연 생성 이진 답이며 자유 판독문의 임상 정보 보존으로 일반화하지 않는다.
- unresolved는 명시 오답·거부와 다르다.117을118 parser로 재채점하지 않는다.
-117과118은 표본·지시·평가가 달라 효과를 합산하지 않는다.
- 공간적 일치의 관찰과 공간 근거를 인과적으로 사용하는 능력을 구분한다.
- 추가 CPU 비용0 GPU와 실제 서비스의 초안·detector·grounder 생성 및 과거 학습 비용을 구분한다. 미측정 latency를 추정 사실로 쓰지 않는다.
- 현재 결과를 근거로 새 모델·환자·학습·다운로드·범용 평가기 개발을 자동 시작하지 않는다.
- **대규모 GPU 필요 후보:** 다기관 자연 오류를 이용한 verifier/editor 공동 post-training은 장기 후보로만 보존한다. 현재 필요성과 단순 대안 이후 가치가 미확인이라 투자하지 않는다.

# 계획의 근거 (GPT 조사 노트)

원문으로 agent/GOAL.md, iter_117 plan/review, iter_118 review, 관련 LIMITATIONS와 CODE_ASSETS, 두 review.json의 code_assets를 확인했다. 현재 research HEAD는 87b672866ae9be7b4d8c261b30f755f7fcaa97cf이며 작업 변경은 없었다. ed117_analyze.py, ed116_eval.py, ed116_spec.py 및 저장 per_patient 구조를 확인했다. per_patient는 174행이며 mismatch/control 두 집단이다.

중요한 구분은 M=K/B/G 다수결, S=E가 resolved이고 B와 같으면 E·그 외 K라는 점이다. 따라서 M/S의 좋은 점수는 초안을 버려도 된다는 직접 근거가 아니다. 반대로 불일치 집단에서는 G가 resolved일 때 M과 같은 답을 내는 구조이므로 M의 정답54명을 새로운 결합 능력으로 해석할 수 없다. K는 자연 생성된 원본 영상의 이진 답이며 추가 임상 문맥을 담은 자유 보고서가 아니다.

iter_117 원 리뷰의 K/B/G/M/N/E/R/S 정답47/40/54/54/34/29/26/53과 unresolved 한계를 유지한다. 사용자 점검의 K정답/E명시오답2명, 반대8명, K정답/Eunresolved24명은 구현에서 원 ID·출처와 대조할 고정 확인 대상이다. 이번 계획 단계에서 새 효과 추정이나 재채점을 수행하지 않았다.

문헌 원문 확인: [To Agree or To Be Right?](https://arxiv.org/html/2603.22623v1)는 의료 VQA의 권위·합의 압박에 따른 답 변경을 평가한다. [Anatomically-Grounded Fact Checking](https://arxiv.org/html/2412.02177v1)는 구조화한 소견·위치와 영상으로 사실성 및 위치를 검증한다. [Automatic Correction of Generative AI Reports using Fact-Checking Model-guided LLMs](https://razi-mahmood.github.io/reports/NeurIPSHealthcareWorkshop.pdf)의 §3은 검증 결과로 문장을 선택 수정하고 유효 문장과 다시 결합한다. 따라서 조언 손상·검증·선택적 보존 자체는 신규 주장이 아니다. 이 시스템들은 우리 자료에서 미재현이며 자연 이진 초안과 오류 혼합 detector 조건의 대안 충분성은 별도 판단해야 한다.
