# Problems / Concerns

1. **해석의 과장:** 보고서의 ‘초안 고유 정보 10명’은 확정적 표현으로 쓰면 안 된다. 9명은 상대 응답이 unresolved인 사례다. 명시 답 기준으로 모든 B/G/E가 틀린 K 정답은 1명이다. 반대로 이 1명이 있으므로 초안 정보가 완전히 불필요하다고도 할 수 없다.
2. **신호 부재의 단정:** E가 9명에서만 resolved라는 사실은 ‘검토한 E의 중재 가치가 확립되지 않았다’를 뒷받침한다. 저장 자료의 모든 GT 없는 특징에 정보가 없거나 학습 가능한 selector가 불가능함을 증명하지 않는다. 이를 확인하려고 이번 자료에서 새 selector를 탐색하지도 않는다.
3. **보조 필드 결함:** `Kc_E_notcorrect_G_unres_or_wrong_by_S_M`은 G 조건을 누락해 S/M 24/16명을 담는다. 이름대로 필터링하면 9/0명이다. 주보고의 9/0은 별도 extra 표에서 정확히 계산되어 핵심 결론을 무효화하지 않는다. 해당 필드는 그대로 인용하면 안 된다.
4. **재사용 검증의 한계:** 분석기는 기존 봉인을 읽지만 그 hash와 완료 상태를 강제 검증하지 않는다. 중복 fixture는 실제 연결 함수를 호출하지 않고, verifier의 독립 범위 검사는 불일치 S만 다룬다. 이번 리뷰가 현재 자료를 확인한 사실과 코드의 자동 보장 범위를 구분한다.
5. **계획 이행 범위:** 문헌 범위표는 구현에서 미완료였다. 추가 기술표는 잠금 이후 작성됐음을 명시했으며 사후 보조 분석으로만 인정한다. 분석 전에도 일부 답 분포를 확인했으므로 눈가림·사전등록으로 표현하지 않는다.

현재 제한된 결론을 무효화하는 blocker는 없다. 코드 결함은 실제 재사용 전에 필요한 수정으로 분리하며, 이를 위한 별도 연구 반복은 권고하지 않는다.

# Interpretation

이번 분석은 합성 초안 손상을 자연 초안의 무가치로 확장하는 해석을 막았다. 자연 답 사이의 제한된 상보성은 실제로 남는다. 동시에 unresolved 사례와 이미 S가 보존하는 부분을 제외하면 새 개입 필요성을 뒷받침하는 근거는 좁다.

G 54명과 S 53명은 이 선택 집단의 기술 통계다. G의 보편적 충분성·비열등성이나 초안 제거의 우위를 증명하지 않는다. M/S는 K를 쓰며, 불일치 집단에서 G가 resolved이면 M=G가 되는 구조다. 이 동률을 독립적인 결합 성과로 세지 않는다.

K는 동일 영상에서 나온 이진 답으로 추가 임상 문맥을 담은 자연 보고서가 아니다. 공개 opacity 정답은 지정 소견 판단을 평가하지만 자유 판독문 전체의 임상 정확성이나 공간 근거의 인과적 사용을 판정하지 않는다. iter_117과 118의 효과는 합산하지 않는다.

## 가까운 선행의 범위

- [To Agree or To Be Right?](https://arxiv.org/html/2603.22623v1)의 §3.2는 처음 맞힌 의료 VQA에 권위·합의 압박을 가하는 평가다. 자연 이진 초안과 오류 혼합 detector를 선택적으로 결합하는 방법 비교는 아니다.
- [Anatomically-Grounded Fact Checking](https://arxiv.org/html/2412.02177v1)의 §3–5는 영상과 구조화한 소견을 이용해 진위·위치를 예측하고 보고서를 교정한다. 합성 소견·위치 변형과 여러 자료의 검증, 분류·grounding 대조를 제시하지만 우리의 RSNA 선택 집단에서 재현한 결과는 아니다.
- [FC-guided report correction](https://razi-mahmood.github.io/reports/NeurIPSHealthcareWorkshop.pdf)의 §3.4와 Table 2는 정상 문장 보존뿐 아니라 verifier의 진위·위치 출력이 모순되면 교정을 하지 않는 규칙도 다룬다. §4는 분류·위치·보고서 지표를 평가한다. 따라서 ‘오류가 있는 근거를 경계하면서 선택적으로 보존한다’는 구성 자체를 새로운 기여로 주장할 수 없다. 이 논문도 현재 K/G 중재와 동일 정보의 M/S 대조를 대신하지 않는다.

세 방법은 이번에 실행·재현하지 않았다. 문헌이 현재 문제를 모두 해결했다고 단정하지도 않는다. 현재 후속 방향의 유망성이 불확정이고 조언 민감성 논문은 이미 추천했으므로 새 논문 추천은 하지 않는다.

# Strategy Check / 연구 방향 판단

**이어받은 관찰 → 줄인 설명 → 남은 질문:** iter_118의 합성 손상은 유지한다. 이번에는 자연 초안의 추가 정답을 모두 내용상 독점 정보로 읽는 해석이 약해졌고, 기존 S가 상당 부분 보존함을 확인했다. 그러나 K/G와 S/G의 상보성은 남아 단순 대안의 완전한 충분성도 입증되지 않았다. GT 없는 유용한 중재와 공간적 필요성은 미확정이다.

- **시험 설정:** frozen R 확대·합성 초안 반복·학습은 보류한다.
- **연구 관찰:** 자연 답의 제한적 상보성과 명시적 잔여 1명은 보존한다. ‘중재 신호가 전혀 없다’는 주장은 채택하지 않는다.
- **연구 질문:** 선택적 교정 전체를 기각하지 않는다. 다만 현재 자료에서 바로 시험할 중요한 최소 개입을 구체화하지 못했으므로 근거 부족으로 투자 보류한다.
- **실행 유효성:** 저장 실제 출력의 사후 분석은 유효하다.
- **성능 개선:** 새 방법·새 출력의 개선은 없다.
- **가설 지지:** 자연 답의 상보성은 일부 지지되지만 새 보존 방법의 필요성은 불확정이다.
- **신규 기여:** 선행이 선택 수정과 verifier 불일치 시 보존을 이미 다루므로 미검증이다.

실제 선택은 **현재 교정 묶음의 투자 보류**다. 대안인 K≠G 오류 검토 전환은 기존 출력을 쓸 수 있지만 선택 집단의 불일치율 33/87 대 5/87만으로 confidence 이후 검토 가치를 판단할 수 없다. 일반 ensemble·선정 효과와 공간적 역할을 구분하지 못해 이번에는 권고하지 않는다. 과거 검토 과제를 이름만 바꿔 재개하지 않는다.

비용은 새 GPU 사용 0, 집계 약 0.13초, 구현 세션 약 262초다. 기록상 짧은 집계보다 코드 작성·검증·보고가 세션을 차지했지만 세부 작업 시간은 미측정이다. 서비스 전체 비용도 미측정이다. 또 하나의 준비 분석을 발주할 근거는 없다.
