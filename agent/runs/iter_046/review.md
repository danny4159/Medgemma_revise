# 요약

- **판정:** 유효한 실험이며 원 복합 기준상 `inconclusive`다. 전체 코드 재사용은 미승인이다.
- **핵심 근거:** V96 96명에서 고정 threshold의 MG 적응 효과는 F1@0.3 +0.18333 [0.11337, 0.25486]이다. 선택된 A−C는 +0.01649 [-0.07170, 0.10938]로 비열등성을 확정하지 못했다.
- **의미·한계:** 적응 여부가 기존 정확도 격차의 중요한 경쟁 설명임을 확인했다. 모듈형 대안의 충분성·신규 기여·공동 요청 해법은 미확정이다.
- **다음:** 현재 양성 문장별 비교의 추가 투자는 보류한다. 공동 요청 관찰은 보존하되 다른 질문 전환과 한정 직접 대조의 가치를 다음 deep 계획에서 비교한다.

# Assessment

계획·구조화 계획·보고서·구현 diff·원시 학습 및 평가 자료를 검토했다. 리뷰 대상은 `bab147379dde1bcd68550e298cc596ee15091e99`이며 변경 소스 11개 모두 현재 파일과 일치했다. `unpreserved_paths`와 선별 반입 요청은 없다. 공식 snapshot 44개 파일도 기록된 hash와 일치했다.

이번은 실험 미실행이나 가설 기각이 아니다. S/U 학습, D24 선택, 최종 V96 추론과 6 paired timing block이 실제 완료됐다. 원시 출력의 독립 재계산으로 현재 관찰을 해석할 수 있다. 미완료된 실패·재개 fixture는 전체 코드 재사용을 막지만 확인된 현재 출력 비교를 무효화하지 않는다.

# Key Findings

## 학습과 선택

- S는 100 updates·3,050문장, U는 300 updates·9,150문장을 학습했다. 총 400 updates·12,200문장 노출로 계획과 일치한다. 각 trajectory의 step은 연속·고유하며 loss와 gradient norm은 유한했다.
- 공식 weighted CE와 box normalization을 전체 logical batch 분모로 맞춘 구현을 확인했다. 데이터·matcher·parameter update·overfit·학습 중간 재개 검사가 보존돼 있다.
- D24에서 U e5, threshold 0.8을 선택했다. e10/e15 F1@0.3은 모두 0.68403이고 e10→e15 train loss 감소는 2.53%였다. 보완 조건 두 가지가 모두 거짓이므로 30 epoch를 실행하지 않은 것은 원 계획에 맞다.
- 6개 학습 checkpoint와 최종 선택 checkpoint의 실제 파일 digest를 확인했다. 평가 사전 잠금은 V96의 최초 dispatch보다 앞섰다.

## 정확도와 사전 판정

| 시스템 | F1@0.3 | F1@0.5 | FP/문장 |
|---|---:|---:|---:|
| C | 0.577951 | 0.291146 | 0.552083 |
| 비적응 P | 0.395313 | 0.233507 | 0.604167 |

근거는 `research/results/iter_046/eval/report.json`과 연결된 원시 출력이다. 리뷰에서 별도 parser·좌표 변환·augmenting-path matching으로 네 시스템의 768개 문장 점수를 계산했다. F1@0.3/0.5·FP·recall의 저장 점수와 최대 차이는 0이었다. C의 label·EOS·유한 좌표·양의 크기도 현재 출력에서 확인했다.

환자 paired bootstrap 10,000회·seed4401의 주요 두 비교를 네 지표 모두 재계산했다.

- **적응 설명 지지:** A@0.4−P F1@0.3은 +0.183333, 97.5% CI [0.113366, 0.254863]으로 두 사전 조건을 충족한다.
- **모듈형 대안 충분성 미달:** A@sel−C F1@0.3 CI 하한 −0.071704는 −0.03보다 낮다. FP 차이 CI 상한 0.130208은 0.10보다 높다. F1@0.5와 세 비용 조건은 충족한다.
- **C 잔여 이점 미달:** C−A@sel F1@0.3 점차는 −0.016493으로 +0.05 기준을 충족하지 않는다. 다만 CI 상한은 +0.071704여서 의미 있는 C 이점의 가능성까지 배제한 것은 아니다.
- **유효한 보조 관찰:** A@sel−C F1@0.5는 +0.102951 [0.027424, 0.181081]이다. 이것으로 복합 기준 통과나 전반적 우위를 선언하지 않는다.

## 비용·출처·자원

12개 timing 실행의 정상 exit와 raw digest를 확인하고 원시 시각에서 비용을 재계산했다. A/P 비율과 95% CI는 device-seconds 1.009338 [0.984285, 1.035029], throughput 0.991834 [0.952651, 1.032628], p95 latency 0.996789 [0.962744, 1.032038]로 보고서와 일치한다. 이번 종료 시각은 원본 좌표 변환 후이며 과거 C 비용과 측정 경계가 완전히 같다고 주장할 수 없다.

두 LR 설정은 두 GPU에서 병렬 실행했다. fp32 microbatch4→8의 기록된 step 중앙값은 약 1.927→1.350초였다. 추론 구성도 w2b4/w2b8/w4b4를 비교했으며 출력 정합성을 확인했다. 두 GPU를 사용했고 필요한 본학습까지 완료했으므로 GPU 회피나 pilot만의 종료가 아니다.

T305/D24/V96 환자·study·영상 ID 교집합은 모두 0이다. 현재 D24/V96 영상 hash 120/120과 평가 잠금·completion의 결과 digest가 일치했다. train pixel 검증은 `gate_data_v2.json`에 보존돼 있다. V96은 반복 사용한 개발 자료이며 독립 확인으로 해석하지 않는다.

# Problems / Concerns

현재 수치를 무효화하는 blocker는 발견하지 않았다. 다만 다음 문제로 전체 스냅샷은 재사용 승인하지 않는다.

1. launcher의 config 재개 대조·동시 배타성·barrier 전 child 실패 처리가 미완료다. 계획한 변조·중복·누락·wrong config fixture와 validation 경계 재개 검사도 수행하지 않았다.
2. `mg46_eval.py`는 존재하지 않는 e10 완료 파일을 읽다가 실패했다. stream의 FileNotFoundError, 수정 후 코드와 amendment를 확인했다. e15 파일의 epoch loss를 읽도록 수정했고 판정 규칙과 최종 분기 값은 유지됐지만 원 protocol lock의 hash 불일치는 남아 있다. 최신 eval lock에는 현재 파일이 잠겨 있으므로 이번 비교는 재현 가능하나 일반 재개 경로는 보완해야 한다.
3. verifier는 `mg45_verify.py`의 parser를 사용하지만 해당 의존성을 평가 source 목록에 잠그지 않는다. 이 parser는 C label과 양의 box 크기를 강제하지 않는다. 이번 출력에서는 리뷰가 별도로 확인했으며 일반 입력에는 그대로 승인하지 않는다.
4. 최종 completion은 report·per_item·verify·decision digest를 보존하지만 verify PASS가 바로 그 report와 모든 의존 결과를 검사했다는 연결을 충분히 강제하지 않는다. 현재 파일들은 독립 확인했지만 향후 자동 승인 경로는 강화해야 한다.
5. 누적 기울기 검사 통과 설명이 부정확하다. v3 최대 상대차는 2.97e-4이며 허용 기준도 1e-4에서 1e-3으로 완화됐다. TF32 해제만으로 기존 기준을 통과한 것이 아니다. fp64 보조 비교는 작은 차이를 보였지만 trainer 내부 일부 float32 변환 때문에 완전한 fp64 검증으로 부르면 안 된다. 산식 검토와 실제 학습·출력 개선 근거를 고려하면 현재 가설 검증 전체를 무효화할 사유는 아니다.

보고서의 전체 학습량 표현도 정정한다. 300 updates는 U만의 값이고 전체는 400이다. 학습 로그 step+data 시간 합 약 835.4초는 loading·checkpoint·검사 비용을 포함한 총 GPU 비용이 아니다.

# Interpretation

고정 threshold에서도 큰 개선이 나타났으므로 이번 변화는 threshold 선택만으로 설명되지 않는다. 동일 annotation 적응이 기존 비적응 MG 대비 C 우위의 중요한 경쟁 설명이라는 판단은 지지된다. 다만 서로 다른 사전학습·구조·학습 비용은 통제하지 않았으며, 격차의 전부를 적응 예산의 인과 효과로 분해했다고 표현해서는 안 된다.

'점추정치에서 격차가 남지 않았다'와 '동등성이 입증됐다'는 다르다. 사전 복합 기준 미달의 직접 원인은 F1@0.3과 FP의 정밀도 부족이다. 대안이 충분하다는 확증도 없지만, 높은 비용의 내부 VLM 위치 출력에 새 방법을 투자할 잔여 이점 역시 확보하지 못했다. 이 두 사실을 함께 보고한다.

# Strategy Check / 연구 방향 판단

- **실행 유효성:** 실제 적응과 출력 비교를 완료했고 독립 재계산으로 확인했다. 코드 안전성 검사의 미완료는 별도로 남는다.
- **성능 개선:** 기존 MG-P 대비 직접 적응의 개선은 명확하다. C 대비 F1@0.3 비열등성은 미확정이다.
- **가설 지지:** target 적응 차이라는 경쟁 설명은 지지된다. 내부 VLM이 문장별 grounding에 필수라는 해석은 약화된다.
- **신규 기여 가능성:** 기존 MedGrounder 직접 적응은 강한 baseline 확보다. 새로운 방법이나 학습 원리를 제안·입증한 것이 아니다.

관찰별 후속 판단은 다음과 같다.

- **iter_045 문장별 C 우위:** 적응 개입이 상당 부분 설명한다. 현재 T305 양성 문장별 방법 투자는 보류한다. 비열등성 문턱만 넘기려는 추가 표본·seed는 권고하지 않는다.
- **iter_041 공동 요청 손실:** 이번 비교로 설명하거나 반박하지 않았다. 관찰과 원 비용 blocker를 유지한다. 직접 joint SFT가 해결할 수 있다는 추측만으로 자동 투자하지 않는다.
- **iter_042 부재 거부:** 이번에는 미검증이다. gate 이후 중요한 잔여 문제 미확정이라는 원 판단을 유지한다.
- **iter_043 영상 구별:** 동일 문장 쌍의 불확정 결과는 그대로 남는다. 강한 적응 모듈형 대안을 확보한 것이 영상 구별 원인의 해명은 아니다.
- **iter_040 문장 대조 loss:** 추가 이득 불확정과 수렴 한계를 유지하며 새 loss 탐색을 재개하지 않는다.

iter_038 이후 준비·진단, iter_044 실행 실패, iter_045~046 모듈형 비교까지 같은 track의 투자로 이어서 본다. 이번 적응 개입은 실제 판단을 바꿀 정보를 제공했지만 남은 CI 폭만 줄이는 반복의 가치는 낮다. 현재 설계의 개선보다 다른 중요한 질문으로의 전환을 우선한다. 공동 요청의 한정 직접 대조는 실용 과제와 강한 대안 대비 필요한 이득을 구체화할 수 있을 때만 경쟁 후보로 남긴다. 반복 횟수 자체를 포기 근거로 삼지 않는다.

논문은 적응 효과라는 확실한 양성 근거에 연결해 [Generalised Medical Phrase Grounding](https://arxiv.org/html/2512.01085v1)을 추천한다. 전체 복합 판정을 성공으로 바꾸는 추천은 아니다. 사전학습·적응 및 후처리 ablation을 읽으면 확보한 baseline의 의미와 다음 비교의 범위를 판단하는 데 도움이 된다.

# Recommended Next Experiment

현재 문장별 비교에 추가 실험을 붙이지 않는다. 다음 deep 계획에서 다른 중요한 질문 전환을 우선안으로 두고, 공동 형식 직접 SFT라는 한정 대조의 정보 가치·실제 효용·비용과 비교해 하나를 선택한다.

공동 요청 대조를 선택하려면 형식 미학습과 잔여 결합 문제를 구분할 최소 개입, 적응 MedGrounder를 포함한 공정한 대안, 원 비용 blocker 처리 범위, 결과별 투자 행동과 종료점을 고정해야 한다. 이를 구체화하지 못하면 해당 관찰은 보존하되 투자 보류로 남기고 다른 질문을 선택한다. 새로운 기여를 가정하거나 주변 진단을 계속 추가하지 않는다. VinDr 승인 대기와 기존 RSNA·보호 reserve는 유지한다.
