# Problems / Concerns

현재 과학적 결론을 막는 것은 자료 적격성·선정 기록 미완료와 모델 비교 미실행이다. 공식 SynthSeg 2.0 복구를 이번에 시도하지 않았으므로 복구 불가능하다고 결론낼 수 없다. ZIP 예산은 계획에서 조정됐지만 남은 다운로드도 수행하지 않았다.

새 감사 코드는 세 사례를 하드코딩한다. 나머지57명을 미인증으로 표시한 점은 정직하지만, 이 코드를 자동 적격성 인증기로 재사용하면 안 된다. 또한 baseline_head가 구현 전 SHA와 현재 HEAD의 동일성을 요구하므로 체크포인트 이후 재실행은 정상 상태에서도 실패한다. 전체 스냅샷과 이 모듈의 재사용을 승인하지 않는다.

GPU 미사용은 실제 자료 blocker에 따른 것이므로 자원 정책 위반이 아니다. 처리량 비교와 GPU당 병렬 구성 선택은 실제 모델 실행으로 진입할 때 완료해야 한다. 기존 runtime·캐시·공식 전문 점수 문제도 해결된 것으로 간주하지 않는다.

# Strategy Check / 연구 방향 판단

research_track은 mri-volume-evidence-use이며 iter_123/124/125와 연결한다. 질문 카드는 iter_126 계획을 기준으로 다음처럼 갱신한다.

1. 중요한 문제: 제한된 MRI 관측에서 관련 해부학 선택이 판별을 회복하는지는 여전히 중요하지만 미검증이다.
2. 현재 근거: 모델 증거는 추가되지 않았다. 새 근거는 명시적 정답 기준과 선정 결과 사이의 불일치다. 이를 모델 한계로 전환하지 않는다.
3. 쉬운 해결책: 공식 SynthSeg 부피와 calibration threshold는 여전히 필요한 강한 대조다. 이번 미실행은 대안의 불충분성을 뜻하지 않는다.
4. 남은 설명: 자료 적격성·segmentation 실패·native slice 부족·기본 인식·sampling 효과가 모두 남는다. 우선 자료를 확정한 뒤 고정 U/A/S 비교로 판별해야 한다.
5. 다음 결정: 출력 전 자료 선정 결함의 한정 수정 가능성을 확인한다. 성립하면 기존 실제 비교로 진행하고, 실패하면 현재 설계를 자료 근거 부족으로 보류한다. 일반 normal의 임상 해석 논쟁이나 감사 코드 개선만 반복하지 않는다.

이번 준비는 의미 있는 모델 관찰을 만들지 못했다. 지배적인 준비·재작업 비용은 미계측이므로 반복 횟수나 검사 수로 비용·진전을 주장하지 않는다. 한정 후속의 정보 가치는 아직 미실행인 동일 비교를 가능하게 한다는 데 있으며, 무조건적인 연구 연장은 아니다.

# Recommended Next Experiment

현재 반복은 종료된 실행 실패로 보존한다. 다음 별도 계획에서 원 의미 기준·hash 순서를 유지한 표본 수정 규칙과 새 manifest를 모델 출력 전에 고정한다. 일반 정상 기술을 소급 승인하지 말고, 기존 제외 사유의 복원과 새로운 검토 판단을 구분한다. 원본 자료·선정·판정은 덮어쓰지 않는다.

자료가 성립하면 공식 SynthSeg 2.0 ICV·QC 기술 검증부터 기존 U/A/S 비교까지 조건부로 묶는다. 표본 수정에 따른 ZIP·추출 비용만 다시 산정하고 prompt·selector·metric·성공 기준은 유지한다. 자료 또는 공식 비교군이 성립하지 않으면 현재 설계를 보류하는 것으로 끝낸다.

논문 추천은 보류한다. 이번에는 실제 모델 비교나 유망한 방법 효과가 없고, 단순 자료 감사 통과는 추천 근거가 아니다.
