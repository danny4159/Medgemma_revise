# Assessment

계획의 전체 허용 범위인 V8 24개와 E24 47개 분석을 완료했다. 실제 담당은 engineer_backend.json과 claude_meta.json상 Codex, gpt-6-astra/low다. iter_080 인계는 iter_081에서 끝났으며 이번은 별도 오류 순위 질문이다. 신규 모델 호출·학습·GPU 사용은 0이다. 저장된 출력으로 답할 수 있는 가설이므로 CPU 분석 선택은 타당하다.

검토한 기준점은 commit.json의 `ee8078ab0acba94f0d84d3ab2997e76eeb117bb9`다. before_sha 대비 추가된 분석기·검증기·fixture·반입 metric을 확인했고 네 파일은 실제 검증 대상과 동일하다. unpreserved_paths는 없다. 최종 결과는 `research/results/iter_082/verified/`이며 루트와 `final/` 산출물은 이전 시도로 구분한다.

# Key Findings

1. V8 선택 규칙은 `one_minus_max`를 선택했다. 상위 6개에서 포착 통계는 [두 등급 이상 오류 1, 일반 오답 5, 절대오차 합 6]이며 margin과 완전 동률이라 사전 순서가 적용됐다.
2. E24 주 검토량 12개에서 confidence와 불일치의 큰 오류 포착은 각각 5/7과 3/7, precision은 41.7%와 25.0%, 일반 오답 포착은 8/23과 7/23이다.
3. C-only 다섯 점수의 큰 오류 포착은 posterior_ge2 2개, expected_abs 3개, entropy 4개, one_minus_max 5개, one_minus_margin 5개다. 불일치는 가장 약한 대조보다 낫지만 강한 단순 대조를 넘지 못했다.
4. 불일치만 포착한 큰 오류는 `16_k02` 1개다. confidence만 포착한 것은 `134_k02`, `234_k02`, `234_k04` 3개다. 추가 포착이 두 환자에 걸친다는 양성 조건도 미충족이다.
5. 환자 제거 24개 비교에서 차이는 모두 −3~−1개다. 주 경계 동률로 포착 수가 달라지지 않는다. 환자 bootstrap 10,000회 차이 CI는 [−5, 2]개, recall 차이 CI는 [−1.0, 0.22222]이며 사건 없는 31회는 recall 계산에서 제외됐다.
6. 큰 오류 AUROC는 confidence 0.77143, 불일치 0.71429다. 반면 AP는 각각 0.44990과 0.49169로 방향이 다르다. 보조 지표로 사전 주 운영점과 종료 기준을 바꾸지 않는다.

근거는 verified/selection.json, report.json, ranks.json, bootstrap.json과 원 baseline·Q 생성·C 확률 파일이다. 리뷰에서 원시 Q의 답변, manifest 정답, C 확률을 71행에 걸쳐 대조했다. production 함수를 호출하지 않는 별도 계산으로 주 포착 수와 bootstrap 10,000회의 사건 수·포착 차이를 재현했다. 입력·코드 20개 hash 및 completion의 산출물 hash도 일치했다.

# Problems / Concerns

현재 결론을 무효화하는 문제는 발견하지 않았다. 구현 로그에서 초기 fixture 문법 오류와 verification의 PosixPath JSON 직렬화 오류를 확인했다. 수정 후 최종 경로에서 19/19 검사와 독립 검증이 통과했으며 이전 시도는 보존됐다. 이번 리뷰에서는 파일을 쓰는 테스트 CLI를 재실행하지 않고 실제 로그·봉인된 검사 결과·독립 읽기 전용 계산을 사용했다.

반복 개발 자료에서의 고정 규칙 비교이며 독립 확인이 아니다. V8과 E24의 ordinal 분포도 다르다. 두 등급 이상 오류는 연구용 사건 정의로 임상 위해가 검증된 것은 아니다. 12개 부위의 검토량을 동일 환자 수나 동일 임상 시간으로 해석할 수 없다.

구현·출처 감사 시간의 별도 기록은 빠졌다. 통계 분석 시간 약 3.41초와 bootstrap 약 0.68초는 확인되지만 전체 비용 절감률은 산출할 수 없다. 이 누락은 정확도 비교의 blocker가 아니다.

# Interpretation

원 계획은 D의 주 포착 수가 B* 이하이면 현재 후보 투자를 종료하도록 정했다. 3≤5이므로 음성 종료가 맞다. CI가 0을 포함한다는 이유로 이 투자 판정을 불확정으로 바꾸지 않으며, 반대로 모집단에서 효과가 없다고 확정하지도 않는다.

불일치만 찾은 오류 1개와 AP의 개선은 남아 있다. 따라서 모든 불일치 정보가 confidence의 재표현이라는 H0나 Q의 오류만으로 모든 경보가 설명된다는 H2를 확정할 수 없다. 이번에 줄어든 것은 '현재 고정 불일치 우선순위가 같은 주 검토량에서 유용한 추가 오류를 제공한다'는 설명의 지지다. 자동 교정·새 방법 효과·VLM 고유성은 검증하지 않았다.

기존 limitation의 적용 범위나 상태를 바꿀 근거는 없어 limitation_updates는 비운다. 음성 후보의 문헌을 사용자 추천으로 승격할 긍정적 근거가 없어 논문 추천도 보류한다.

# Strategy Check / 연구 방향 판단

**실제 투자 선택은 현재 SPIDER 활용 후보 묶음의 투자 보류다.** 오류 순위로 질문을 옮긴 이번 진단도 강한 단순 대조 이후의 가치를 확보하지 못했다. 같은 출력에 새로운 점수 이름만 붙여 연장하지 않는다.

- iter_064 원 리뷰의 모델별 context 차이는 유지한다. 이번 순위 분석은 인식·선택·결합의 원인을 설명하지 않았다.
- iter_077의 전체/영역 입력 차이와 영역 입력의 영상 대응 신호는 유지한다. 분류기 대비 이점과 해상도·context·별도 적응의 기여는 여전히 미검증이다.
- iter_078의 참고영상 추가 가치 불확정과 투자 보류는 유지한다.
- iter_079는 정답·비교 검사 연결 실패이며 모델 반증으로 사용하지 않는다.
- iter_080/081의 영상에 따른 답변 변화는 유지하지만 유용한 자동 교정은 미확보다. 이번 오류 식별 결과가 그 원인을 해결하지 않는다.
- iter_029의 강한 confidence 대조라는 교훈을 적용했고, 이번에도 단순 대안보다 나은 주 운영점 효용을 확보하지 못했다.

실행 유효성은 확인됐다. 성능 개선은 주 검토 지표에서 없었다. 가설 지지는 제한적 상보성을 넘어가지 못했다. 신규 기여 가능성은 입증되지 않았다. 타 계열 VLM이나 두 번째 분류기의 신규 실행은 양성 이후의 조건부 투자였으므로 이번 음성에서 생략한 것이 타당하다.

현재 방식의 개선은 중요한 잔여 가치와 개입 연결이 약하다. 입력 차이에 집중하려면 단순 분류기 이후에도 필요한 정확도·비용·전이상의 사용 가치를 먼저 구체화해야 한다. 새 MRI 질문으로 전환할 경우에는 데이터 확보 가능성보다 정답으로 필요한 근거를 구분할 수 있는지를 우선해야 한다. 이번 결과만으로 어느 새 방법이 유망하다고 선언하지 않는다.

분석 연산은 수초였고 구현·출처 검증 및 수정이 주요 작업이었다. 비용 비율은 측정되지 않았다. 이후에도 같은 소규모 재분석만 반복하는 대신 다음 계획에서 투자 대상 하나와 종료 조건을 결정해야 한다.

# Recommended Next Experiment

현재 불일치 순위의 가중치·검토율·prompt·seed 탐색은 종료한다. ensemble 대조와 독립 환자 확인도 원 계획의 양성 조건을 충족하지 못했으므로 자동 발주하지 않는다.

다음 계획은 남은 전체/영역 입력 차이를 다루는 최소 개입과 다른 MRI 질문으로의 전환을 비교해 하나를 선택한다. 전자를 선택하려면 해상도·context·적응 중 통제할 요인, 강한 분류기 이후의 잔여 가치, 결과별 투자 변화가 필요하다. 후자를 선택하려면 질문에 따라 영상 근거가 달라지는 구체적 과제, 공식 정답의 의미, 소수 실제 입력 연결, 분류·검출+규칙 대조의 충분성을 먼저 확인한다. 광범위한 자료 다운로드나 새 모델 순회부터 시작하지 않는다. 기존 결과·코드는 보존하고 독립 reserve 사용은 선택한 별도 계획에서 정한다.
