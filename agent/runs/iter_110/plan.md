## 직전 질문 1: 생성 문장과 공개 주석의 직접 연결

원문 `agent/runs/iter_110/think/round_01.json`을 읽고, `research/results/iter_086/E96/readings.jsonl`의 C-G 96개와 `research/results/iter_086/E/enumeration.json`의 같은 ImageID별 findings를 대조했다. 생성 문장의 의미를 바꾸지 않고 대소문자·공백·끝 마침표만 정규화하는 점검에서 직접 연결은 두 사례였다.

- `243024467796735410478883704051233659830-2_i9fyac.png`: 생성 `Left pleural effusion`, reference `Left pleural effusion.`. 원 GRG에는 `[0.76,0.61,0.33,0.61]`가 있으며 reference에는 주 box 1개와 다른 판독자의 extra box 1개가 있다. `E96/C/shard0/outputs.jsonl`에서도 원 생성 문장과 좌표를 직접 확인했다.
- `197949282606240035821492527998628232069_vkoay7.png`: 생성 `Bilateral interstitial pattern`, reference `Bilateral interstitial pattern.`. reference에는 주 box 2개, extra box는 없다.

간단한 구문 추출상 96개 중 36개 판독문에 65개 좌표 묶음이 있었다. 이 수치는 생산 평가기의 승인 결과가 아니며, 문구 불일치를 임상 오류로 계산하지 않았다. 직접 대응 두 사례는 실제 모델의 성공·실패 여부를 기준으로 고르지 않았다.

대표적인 제외 이유도 원문에서 확인했다. `Cardiomegaly`와 `Cardiomegaly at the expense of the left cavities.`는 속성 범위가 다르다. `Left basal laminar atelectasis`와 `Laminar atelectasis in the lingula and middle lobe.`는 대상 범위가 다르다. 다른 생성 소견은 해당 reference에 명시되지 않았다. 이를 곧바로 음성 또는 환각으로 판정할 수 없다. 문자열 완전 일치만이 유일하게 타당한 평가라는 뜻은 아니지만, 더 넓은 대응을 승인할 별도 근거를 이번에 확보하지 못했다.

## 직전 질문 2: 비교의 판단 가치

동일 문장의 GRG/PG/MedGrounder 대조는 입력 문구 차이를 통제할 수 있지만, 정답 연결 없이 얻는 위치 일치는 정확성의 증거가 아니다. 직접 대응 두 사례로는 동작 여부나 사례 수준의 위치 변동은 볼 수 있어도, 오류 선택 성능·중요한 잔여 실패 조건·단순 재-grounding의 충분성을 구분하기 어렵다. 표본 수 자체를 보편적인 gate로 삼은 것이 아니라 이번 투자 질문에 대한 정보 가치로 판단했다.

reference 문장으로 치환하면 평가 가능한 grounding 비교는 만들 수 있다. 그러나 소견을 스스로 생성하는 판독의 근거 검증이라는 질문이 달라지고, 기존 문장 grounding 비교 이후의 새 잔여 가치를 아직 특정하지 못했다. 따라서 이를 편의상 대체 실험으로 발주하지 않는다.
