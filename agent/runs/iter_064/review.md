# Interpretation

R 대비 C는 영상 수를 같게 유지하며 다른 내용의 영향을 비교한다. target tensor가 같으므로 target의 전처리 정보량 변화 설명은 약화된다. 그러나 내용·해부학 위치·지시 해석·모델의 답변 편향은 여전히 얽혀 있다. '영상 묶음 전체를 판정한다'는 설명은 출력 패턴과 양립하는 가설이지 입증된 내부 규칙이 아니다.

routing은 target 영상 선택과 단독 입력 질문으로 S를 공유하는 단순 대안이다. MedGemma의 C 손실을 피하는 참고 경로로 보존할 수 있지만 S 자체의 기본 기준이 미달했으므로 검증된 실용 판독기로 채택했다고 보고해서는 안 된다. Qwen에는 routing의 정확도 우위도 관찰되지 않았다.

- **실행 유효성:** 입력·정답·순서·출력 연결을 확인했고 고정 대조를 완료했다.

- **신규 기여 가능성:** 명시적 index는 routing으로 처리 가능하다. 현재 관찰만으로 새로운 학습·attention 방법에 투자할 이유는 부족하다.

현재 과제 개선은 기본 신호 미달과 단순 routing 대안 때문에 보류한다. 같은 자료의 추가 원인 진단도 결과가 투자 결정을 바꾸지 못하면 실행하지 않는다. 새 데이터 탐색보다 기존 자산으로 성립 가능한 과제의 한정 검토를 우선하되, 성립하지 않으면 이 세부 경로를 종료한다. 준비·검증·재작업 비용이 발생했으나 비용 비율은 측정되지 않았다. E 생성 자체는 약 3.3분이었으므로 주변 검증을 무한 확대할 이유도 없다.

논문 추천은 보류한다. 제한된 현상은 확인됐지만 이번 접근법의 사전 유망성 기준과 새로운 방법의 필요성이 확보되지 않았다.
