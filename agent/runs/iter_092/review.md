# 요약

- **판정:** 유효한 실제 비교지만 `inconclusive`다. 사전 양성 기준은 미달했다.
- **핵심 근거:** 비정상 96명 중 recall 적격 94명에서 G−R은 +0.532pp, 95% CI [0, 1.630]pp이며 추가 회복은 1명이다.
- **의미·한계:** 위치 출력은 학습됐지만 선택된 R/G의 판독 성능은 매우 낮다. 충분히 작동하는 판독 baseline 이후의 위치 학습 효과는 미확인이다.
- **다음:** 저장 train/validation 자료로 정상문 편중과 선택 영향을 한정 점검한다. 추가 seed나 E의 다른 epoch 평가를 바로 실행하지 않는다.

## 알림 요약

- 결과: 흉부 X-ray R/G 학습과 E128 생성은 완료됐다. 위치 보조 학습의 판독 recall 이득 +0.53pp·회복 1명은 원 기준에 미달했다.
- 의미: 보조 grounding F1@0.3은 0→0.25였지만 판독 개선으로 이어지지 않았다. R/G 모두 base보다 낮아 위치 학습 자체의 무효과로 일반화할 수 없다.
- 후속: 기존 validation 출력과 학습 target을 한정 점검해 baseline 보완의 근거가 있는지 판단할 것을 권고한다. 새 학습 전에 원인을 좁힐 수 있기 때문이다.
- 대안: 현재 recipe의 투자를 즉시 보류할 수 있다. 추가 비용은 줄지만 이미 확보한 학습 궤적이 설명할 수 있는 baseline 부적합 여부가 남는다.

# Assessment

원 계획의 재개·epoch6 종료·조건부 연장 판단·선택 잠금·E128 생성이 완료됐다. `claude_meta.json`과 `engineer_backend.json`상 구현 담당은 Claude이며 실제 모델은 claude-sonnet-5-5, 설정은 sonnet/medium이다. 보고서 파일명으로 담당을 추정하지 않았다.

리뷰 SHA는 `93193abc4d04c44cf40b2695376d520209fa1745`다. 구현 전후 diff는 신규 소스 9개이며 기존 trainer 수정은 없다. 신규 파일과 해당 SHA의 blob이 모두 일치하고 unpreserved_paths는 없다. 전체 스냅샷은 의미 평가 재사용 문제 때문에 승인하지 않는다.

`SELF_CHECK: FAIL`을 실행 실패와 동일시하지 않는다. 실제 학습·생성 결과가 있으며, 전문의 평가가 없다는 점 자체는 assistant 평가를 허용한 원 계획의 신규 blocker가 아니다.

# Key Findings

1. **실행 복구 완료.** 네 trajectory는 각각 384 updates에 도달했다. 이번 추가량은 79+99+256+256=690 updates이며 유효 recovery 누적은 1,536 updates다. 초기 제외 266 updates는 효과 판단에 포함하지 않는다. 학습 supervisor 기록은 약 14,496초, 최종 생성은 3,713초이며 pending은 없다. 도구 로그에서 nvidia-smi 조회와 experiment_wait 호출 36건을 확인했다. 두 GPU의 독립 작업 배정과 기존 메모리 근거를 재사용한 GPU당 1 worker는 이번 복구 범위에서 타당하다.

2. **사전 선택 규칙 준수.** epoch4→6 NLL은 네 조건 모두 증가해 epoch12를 실행하지 않았다. epoch6 기준 LR2e-4를 고른 뒤 두 조건의 NLL 합이 최소인 공통 epoch1을 선택했다. 이 규칙은 최저 NLL checkpoint를 모든 LR에 걸쳐 고르는 규칙과 다르다. 예를 들어 LR1e-4 epoch2의 NLL은 R 1.4602/G 1.4625로 선택된 LR2e-4 epoch1의 1.5230/1.5258보다 낮다. 이는 구현 위반이 아니라 사전 선택 설계의 해석상 제약이다.

3. **판독 기준 미달 재현.** `effects_E128.json`과 연결된 `E_adjudicated/eval/per_output.json`을 별도 집계했다. strict recall은 R 0.011525, G 0.016844, base 0.078369, CURE 0.164716이다. 비정상 층 96명 중 확정 양성 reference가 없는 2명은 원 규약에 따라 recall에서 제외된다. G−R 평균 0.005319와 층화 bootstrap 10,000회·seed89017의 CI [0, 0.016304]를 독립 재현했다. 차이는 한 환자의 0.5 recall 증가뿐이며 그 환자를 제외하면 차이는 0이다. 5pp·5명·leave-one-out 양의 방향 기준에 미달한다.

4. **원출력의 편중 확인.** R의 128개 출력 중 정확히 'No significant radiological findings.'인 출력이 70개, 'No significant findings.'가 32개다. G는 첫 문구가 105개다. 저장 판정만의 현상이 아니라 실제 생성문에서 확인되는 편중이다. 다만 이를 학습 내부의 특정 원인으로 확정하지 않는다.

5. **grounding과 판독 분리.** E32 저장 GT·예측 box에서 별도 IoU matching으로 F1@0.3 R 0/G 0.25를 재계산했다. G invalid는 2/32, R은 32/32다. 이 과제는 정답 문장을 제공하는 보조 위치 평가이므로 자유 판독 개선의 증거와 구분한다.

6. **출처 확인.** handoff_manifest의 연결 파일 hash 불일치 0, 생성 match·claim anchor 1,598개의 원문 offset 불일치 0을 확인했다. 저장된 E 준비 검사는 환자·study·영상·raw/u8 중복 0과 교체 0을 기록한다. 이 검사가 foundation/CURE 사전학습 노출까지 배제하지는 않는다.

# Problems / Concerns

주요 recall 차이와 사전 양성 기준 미달을 무효화하는 blocker는 확인하지 못했다. 다만 모순 지표와 참고 시스템의 복합 우위는 더 좁게 해석해야 한다.

`report92_autojudge.py`는 일반적인 'No significant findings'를 대응 음성 atom이 없으면 unknown으로 둔다. 반면 'Normal chest X-ray'나 구체적인 부정문은 reference 소견에 따라 contradicted로 처리한다. 범위가 실제로 다를 수 있으므로 이를 무조건 같은 문장으로 취급해서도 안 되지만, 현재 규칙만으로 R/G의 모순 0을 안전한 판독의 증거로 삼을 수 없다. 'no acute' 처리 역시 급성 여부와 단순 소견 존재를 충분히 구분하지 않는다. base 모순 44/128과 CURE 3/128의 차이 및 CURE 복합 통과는 이 평가 규칙에 민감하다.

자동 평가 사용 자체가 결함은 아니다. 그러나 평가기 코드의 '사전 고정'이라는 설명은 E 생성 이전에 규칙 전체가 잠겼다는 증거를 대신하지 않는다. 문자열 기반 위치·속성 대응과 일괄 retain 재점검 기록도 범용 평가기 승인에는 부족하다. 현재 R/G의 드문 strict 회복 사례는 reference와 생성 인용을 직접 대조했으며, 추가 회복 1명이라는 제한된 결론은 유지한다.

보고서의 '비정상 96명 recall'은 층 크기와 실제 분모 94명을 구분해야 한다. 자동 판정 430/512는 84.0%다. 이러한 보고 보완은 실험 전체를 실행 실패로 바꿀 사유가 아니다.

# Interpretation

현재 고정 recipe와 선택 결과에서 위치 보조 CE가 유용한 판독 회복을 제공했다는 근거는 없다. 그러나 원 음성 분기의 'R이 작동해도 G 이득이 없음'을 충분히 충족했다고 보기 어렵다. R은 base보다 낮고 대부분 일반 정상문을 출력한다. 따라서 효과 기준 미달은 확정하되, 충분한 판독 적응 이후 위치 보조 학습의 가치 부족은 불확정으로 남긴다.

CURE−base의 저장 recall 차이 +8.635pp는 참고 시스템 차이다. 다른 base·학습 자료·학습량이 얽혀 있으며 현재 의미 평가의 모순 처리도 영향을 준다. 위치 supervision의 인과 효과나 CURE 공식 benchmark 재현으로 해석하지 않는다.

이번에 갱신할 기존 limitation은 없다. iter_012의 grounding 학습 가능성과 iter_088의 단순 영역 결합 충돌 관찰은 유지되며 이번 결과로 설명되거나 반박되지 않았다. 논문 추천은 하지 않는다. 현재 R/G 방법의 유망성이 확인되지 않았고 참고 시스템 차이만으로 새 추천을 정당화하지 않는다.

# Strategy Check / 연구 방향 판단

**이어받는 관찰 → 남은 경쟁 설명 → 다음 결정:** 위치 출력 학습과 시스템별 판독 변화는 관찰됐다 → 이번 통제 비교에서는 위치 출력 개선에 비해 판독 이득이 작았지만 판독 baseline 부적합·선택 설계·실제 보조 CE 무효과를 분리하지 못했다 → 저장된 train/validation 근거로 baseline 보완 하나의 타당성을 판단한다.

- **실행 유효성:** 사용자 인계 상태를 이어 학습·생성을 완료했다. 직전 대기 수명 문제는 이번 완료를 막지 않았다.
- **성능 개선:** 보조 grounding 개선은 있다. 원 판독 개선 기준은 미달이다.
- **가설 지지:** 선택된 checkpoint에서 위치 출력 학습만으로 판독 회복이 보장되지 않는다는 제한된 관찰을 지지한다. 일반적인 인식·선택·결합의 원인은 미분리다.
- **신규 기여 가능성:** 표준 공동 CE의 결과이며 신규 방법 기여는 확인하지 못했다. 강한 report-only baseline 이후 중요한 잔여 문제도 아직 확보하지 못했다.

지배 비용은 이번 약 4시간의 학습 재개, 약 1시간의 최종 생성과 의미 평가였다. 이미 확보한 궤적을 활용한 한정 보완은 새 seed·loss·모델 탐색보다 비용 대비 정보 가치가 높다. 직접적인 방법 확대는 보류한다. 관련 track의 이름이나 자료를 바꾸어 이 미해결 질문을 초기화하지 않는다.

# Recommended Next Experiment

기존 train/validation 자료의 한정 점검으로 끝나는 후속을 권고한다. target 구성과 정상문 빈도, 소견별 노출, epoch별 NLL 및 저장 V32 실제 생성의 관계를 확인한다. 의미 평가에서는 일반 정상문·구체적 부정·급성 부정에 대한 대조 사례와 현재 판정의 민감도만 점검한다.

결과가 구체적인 baseline 보완을 지지하면 별도 사전 계획에서 최소 비교를 제안한다. 그렇지 않으면 현재 recipe의 추가 학습·seed·위치 loss 투자를 보류한다. 이미 본 E128에서 epoch를 고르거나 동일 E를 독립 확인으로 재사용하는 후속은 권고하지 않는다. 기존 계획·선택·원 판정과 산출물은 보존한다.
