# Problems / Concerns

현재 불확정 결론을 무효화할 blocker는 발견하지 않았다. 다만 다음 해석 제한을 유지해야 한다.

- 항목 recall은 공개 텍스트 대응이다. 일반적인 abnormal signal·high signal 항목의 일치를 같은 실제 병변의 인식으로 인증할 수 없다.
- 미언급 추가 소견은 임상 허위가 아니다. 따라서 이 실험은 완전한 누락·허위 판독 평가를 제공하지 않는다.
- 모순 차이 [0,0]은 관측 텍스트의 제한된 대응 결과다. 잘린 내용까지 포함한 모순 상한이나 임상 안전성 증거가 아니다.
- 같은 assistant의 사후 판정이며 조건명 제거만으로 독립 맹검이 성립하지 않는다. 코드의 고정 판정표는 새 출력에 재사용할 수 없다.
- 공개 텍스트 작성자가 사용한 영상과의 byte 동일성, 모델의 환자별 학습 노출, 독립 일반화는 미확인이다.
- 전체 end-to-end 비용은 미계측이다. 과거 실행 시간을 추정해 채우거나 비용 복구만을 위해 같은 실험을 반복하지 않는다.

# Interpretation

관측 범위를 맞춘 실제 비교라는 점은 진전이다. 그러나 인접 입력의 점수가 낮다는 사실과 공간 정보를 활용하지 못한다는 주장은 다르다. 현재 조건에는 반복·절단, 출력 기회 차이, 기본 인식·적응 부족, 텍스트 대응 불확실성이 함께 남아 있다. 음의 bootstrap 구간도 이러한 의미·절단 불확실성을 제거하지 못한다.

이번 결과로 과거 FLAIR 고정 범주 관찰이나 지정 target 문맥 관찰을 정정하지 않는다. DWI의 별도 제한적 관찰을 추가한다. 논문 추천은 유망한 개선 또는 재현 진단의 긍정적 근거가 이번에 확보되지 않아 보류한다.

# Strategy Check / 연구 방향 판단

`mri-volume-evidence-use`, 관련 iter_064/070/133/136/139/140을 잇는다. 직전 iter_140의 자료 연결 미성립에서 이번 실제 판독 비교로 바뀌었지만, 적응 후 공간 정보 활용이라는 주 질문은 그대로다.

1. 중요한 문제: 같은 MRI 관측을 묶어 처리·학습하는 것이 소견 누락과 오류를 줄이는가? 아직 해결되지 않았다.
2. 현재 근거: 동일 관측 6명의 실제 비교와 인접 조건의 높은 절단률을 확보했다. 인접 처리의 성능 개선은 입증하지 못했다.
3. 쉬운 해결책: 개별 처리의 충분성도 확인되지 않았다. 직접 SFT와 AutoRG 예측 영역 판독의 실제 해결 범위가 남아 있다.
4. 남은 설명: 생성 반복·절단, 과제 적응 부족, 위치·속성 인식 부족, 공간 결합 효과가 미분리다. 전문 모델의 성공은 실용 대안 근거이며 구조의 인과 효과는 아니다.
5. 다음 결정: 같은 frozen 출력 감사는 끝낸다. 전문 3D 비교를 먼저 한정 실행하고 그 결과와 supervision 범위로 입력별 SFT pilot을 구체화한다.

실행 유효성은 확보했다. 성능 개선과 가설 지지는 불확정이며 신규 기여 가능성은 미검증이다. 본생성 비용은 실측됐지만 자료 준비·의미 판정까지 포함한 누적 지배 비용은 계측되지 않았다. 긴 로그나 반복 횟수를 비용 수치로 대신하지 않는다.

# Recommended Next Experiment

AutoRG의 기존 환경·가중치를 필요한 경로에 한해 재사용하고 DWI 입력·예측 mask·출력 의미를 소수 사례에서 확인한다. 성립하면 같은 global DWI 항목으로 실제 판독을 비교하고 종료한다. checkpoint의 DWI target과 ISLES/RadGenome 노출을 기록하며 GT mask oracle과 실용 경로를 섞지 않는다.
