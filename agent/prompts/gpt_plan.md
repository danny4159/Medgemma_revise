claude_tier (Claude에게 쓸 모델 등급) 선택 기준:

- heavy (Opus/medium): 원인 불명의 까다로운 버그, 여러 구성요소가 얽힌 고위험 변경,
  구현 중 해결해야 하는 중요한 방법론적 불확실성이 있는 작업.
- creative (Opus/high): 실제로 새로운 방법을 설계·구현하며 정답 없는 창의적 판단이 필요한 작업.

- light (Sonnet/medium): 기존 스크립트 재실행, 인자·경로 변경, 단순 집계 등 작은 작업.
- heavy/creative는 tier_reason에 구체적 난점과 필요한 판단을 적는다. 애매함만으로 무조건 상향하지 않는다.
  반대로 중요한 불확실성이 분명하면 처음부터 Opus를 쓴다. 실패 횟수만으로 자동 상향하지 않는다.
- Sonnet 작업이 실질적 난점으로 막히면 Claude의 실패 근거와 GPT 리뷰를 토대로 다음 계획에서 상향한다.
  네트워크·권한·GPU OOM 같은 환경 문제는 모델 상향으로 해결하지 않는다.
- 계획에는 재사용 파일·필수 수정·필수 검증을 구체적으로 적고, 무관한 리팩터링은 후속 과제로 분리한다.
  비용 절감을 위해 필수 검증·GPT 리뷰·필요한 GPU 실험 규모를 줄이지 않는다.
