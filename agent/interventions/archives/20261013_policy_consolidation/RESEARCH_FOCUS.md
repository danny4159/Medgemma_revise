# 현재 연구 우선순위 — 위치 학습과 판독 정확성의 연결

## 현재 적용 범위 — iter_110 이후 사용자 승인

### iter_119 이후 연구 후보 재선택 — 사용자 점검·보완·재개 승인

iter_119의 한정 정보 가치 분석은 끝났다. 자연 초안 교정 묶음은 근거 부족으로 투자 보류한다.
iter_118의 합성 초안 손상 양성 관찰과 119의 제한된 상보성은 보존하되, 연구 질문 전체의 기각이나
새 방법의 유망성으로 바꾸지 않는다. 아래가 과거의 일회성 후속 지시보다 우선한다.

- 다음에는 같은 RSNA K/G/E/S 표를 더 나누거나 parser·초안 무시 prompt·selector 학습을
  발주하지 않는다. iter_115의 CURE 특화 오류 검토도 보류 상태다. K–G 불일치 순위를 새 이름으로
  실행하는 등 종료한 검토 과제를 반복하지 않는다. 보조 필드·봉인 검증 결함은 재사용할 때만
  필요한 경로를 고치며, 이것만을 위해 다음 반복을 쓰지 않는다.
- GOAL과 '위치·영역 등 영상 근거를 활용하는 의료 VLM의 판단 능력'이라는 큰 범위는 유지한다.
  고정 RSNA 이진 초안 교정에 다음 질문을 가두지 않는다. 자유 판독문 전체의 임상 의미 평가,
  전문가 추가 검토, discovery·TOF 수동 실험을 다시 시작하는 승인은 아니다. 모델·데이터 교체는
  연구 질문의 판별력과 실제 접근 가능성으로 선택하며 MedGemma·RSNA·X-ray를 강제하지 않는다.
- 다음 GPT 계획에서 근거 있는 다른 기술 질문을 최대 2개만 비교하고 하나를 선택한다. 현재
  LIMITATIONS/INDEX와 관련 원 리뷰, 가까운 최신 선행의 공식 원문·코드·공개 정답을 필요한
  범위로 확인한다. 전체 과거 실험 재감사나 논문 목록 수집을 반복하지 않는다. 후보마다
  (1) 해결하면 무엇이 중요한가 (2) 관찰 또는 선행의 어떤 근거가 있는가 (3) 강한 기존 방법과
  단순 대안이 다룬/다루지 않은 조건 (4) 공개 자료로 구분할 경쟁 설명 (5) 최소 비교·예상 비용을
  짧게 연결한다. 데이터셋 이름만 바꾼 기존 과제는 새 후보가 아니다.
- 기존 방법의 실패를 미리 가정하지 않는다. 공식 지원 조건의 재현 확인과 새로운 조건의 확장
  검증을 구분한다. 단일 모델의 기본 수행 부족이나 학습하지 않은 출력 형식의 실패를 일반 한계로
  해석하지 않는다. 단순 해법을 빼서 어려운 문제를 만들거나, 현재 골라 둔 방법을 정당화하려고
  task를 바꾸지 않는다. 반대로 모든 모델의 실패·최종 신규성 증명을 작은 탐색의 진입 조건으로
  요구하지 않는다. 문헌의 미평가 조건은 검증할 가설이지 이미 확인한 한계가 아니다.
- 선택한 질문은 같은 계획에서 한정 자료/입출력 적합성 확인과 성립 시 작은 실제 비교로 연결한다.
  두 후보를 모두 실행하지 않는다. 공개 정답이 구분하는 오류, 비교군의 정보·계산량, 표본·최대
  실행량·예산·종료 조건을 결과 전에 정한다. GPU 추론은 RESOURCE_POLICY에 따라 허용하며 이전
  iter_119의 CPU-only 제한을 계승하지 않는다. 새 대규모 학습·전문가 평가·범용 평가기 개발은
  기본 작업으로 삼지 않는다. 유효한 관찰에 근거한 최소 개입은 기존 method pilot 규칙을 따른다.
- 진전 기준은 '현상 확인 / 해결 필요성 / 시험할 개입 가설'을 연결하는 것이다. 양성·음성·불확정이
  어느 설명과 다음 투자 결정을 바꾸는지 정하고, 모두 추가 정비로 끝나는 계획은 선택하지 않는다.
  원인·여러 도메인 일반화·논문급 신규성의 최종 증명을 작은 pilot 전에 모두 요구하지 않는다.
  그렇다고 오답 하나나 선행과 다른 설정만으로 방법 개발에 들어가지 않는다.
- 근거 있는 후보가 없거나 두 후보 모두 성립하지 않으면 억지 실험을 만들지 않는다. 어느 제한
  때문에 선택이 막혔는지와 범위 조정이 필요한 이유를 구체적으로 보고하고 다음 사용자 결정을
  요청한다. 단순히 '새 전략 검토 필요'를 다음 반복으로 넘기거나 목적 없는 자율 순회를 하지 않는다.

현재 구현은 Claude, GOAL·사용량 등급과 --confirm-each-iter는 유지한다. 다음 반복의 계획·한정 실행·
리뷰를 승인하며 이후에는 다시 사용자 확인을 받는다. Telegram에는 '초안 교정 보류 → 새 질문 선택'의
이유와 선택한 질문·배제한 대안을 연결해 보고한다. 아직 선택 전이면 새 연구가 시작됐다고 말하지 않는다.

### iter_118 이후 정보 보존 필요성의 한정 점검 — 사용자 점검·보완·재개 승인

iter_118은 합성 초안의 내용 손상 관찰을 확인했다. 원 양성 진단·출력·한계를 보존하고 같은
초안 민감성 실험, 초안 무시 prompt, frozen R 확대·학습은 발주하지 않는다. 다음 한 번은
저장된 자연 발생 초안·자동 근거에서 **무시하면 잃는 유용한 정보와 오류 위험이 함께 있는지,
강한 단순 대안 이후 중요한 잔여 문제가 있는지**를 점검한다. 이 절이 과거 후속보다 우선한다.

- 합성 W보다 초안 없는 E가 낫다는 결과는 현재 합성 설정의 타당한 단순 대안 근거다. 그러나
  자연 초안이 언제나 불필요하거나 교정 질문 전체가 무가치하다는 증거는 아니다. 반대로 정답을
  사용해 만든 C의 이득도 자연 초안의 추가 정보 가치를 증명하지 않는다. 이 둘을 구분한다.
- 우선 iter_117의 저장된 자연 K, detector B, grounding G, E/M/S와 원 정답·분모를 연결한다.
  불일치 87명만 보면 단순 대안은 G/M=54, S=53, K=47, E=29명 정답이다. K가 맞고 E가 명시
  오답인 2명, 반대로 E가 맞고 K가 틀린 8명과 K 정답/E unresolved 24명은 서로 다른 증거다.
  이 수치는 저장 per_patient의 원 분류에 따른 점검이며 내용 재채점이 아니다. 원 출력 출처를
  확인하고 일치 대조도 별도로 포함해 유리한 사례만 고르지 않는다. 반복 개발·불일치 선택 집단의
  한계를 유지하고 이를 자연 모집단의 오류 빈도나 독립 확인으로 부르지 않는다.
- 새 parser로 iter_117을 재채점하거나 iter_118 평가기로 치환하지 않는다. 기존 resolved/unknown
  의미와 보수적 범위 안에서 상보성을 보고한다. 원 규약이 답하지 못하는 부분은 미확정으로 남긴다.
  GT로 매번 정답 모델을 선택한 oracle 합집합은 진단 상한일 뿐 실제 사용 가능한 개선이나
  추가 정보의 원인을 증명하지 않는다. 다수결·합의·가장 강한 단일 대안으로 설명되는 부분을 먼저 뺀다.
- 이번은 저장 자료의 한정 CPU 분석과 필요한 문헌 대조다. 새 모델·환자 추론·학습·다운로드,
  전체 과거 감사·평가기 정비는 하지 않는다. 자연 초안과 자동 근거의 정보 출처·상보적 실패·
  비용을 구분하고 '공간적 근거 때문에 필요한가, 일반 모델 조합인가'를 명시한다. 기존 117/118의
  실험 조건이 다르므로 효과를 합산하지 않는다. 118의 미사용 범위·hedge 증가 정정도 유지한다.
- 가까운 기존 교정/조언 민감성/선택적 결합 방법 중 실제로 이 질문과 맞닿는 소수만 원문으로
  확인한다. 제목·논문 주장만으로 해결됐다고 가정하지 않고, 공개된 입력·평가·대조가 다룬 범위를
  나눈다. 새 문헌 목록을 늘리는 것이 산출물이 아니다. 직접 실행하지 않은 기존 방법은 미재현으로
  표시하고 그것을 이겼다고 주장하지 않는다.
- 종료 시 '확인한 현상 / 해결할 필요 / 검증할 개입'을 짧게 연결해 다음 행동 하나를 선택한다.
  단순 대안 뒤에도 중요한 잔여 조건과 경쟁 설명이 있으면 원인·신규성·타 모델 일반화의 최종
  증명을 선행 조건으로 삼지 말고 최소 개입 pilot을 다음 승인에 구체적으로 제안한다. 기회가
  없거나 이 자료로 판별 불가이면 각각 가치 부족/근거 부족으로 구분해 현재 묶음을 보류한다.
  준비 분석을 한 번 더 하자는 반복으로 넘기지 않는다. 다른 방향이 필요하면 기존 근거의 후보
  최대 2개를 비교해 우선순위 하나를 제안하되 억지 후보나 자동 전환 실험은 만들지 않는다.

GOAL과 과거 판정·사용량 등급은 유지한다. 구현은 Claude, --confirm-each-iter 유지. 이번 결과 뒤
다음 실험은 다시 사용자 승인을 받는다. Telegram에는 관찰 확인과 새 방법의 필요성 판단을 구분한다.

### iter_117 이후 초안 영향의 한정 대조 — 사용자 점검·보완·재개 승인

iter_117 본비교는 완료됐다. 원 출력·불확정 판정과 운영 위반 기록을 보존하고 696요청을 다시
생성하거나 사후 parser 변경으로 재채점하지 않는다. 이전 본비교 복구 지시보다 아래 한 번의 후속을 우선한다.

- 남은 질문은 '같은 영상·자동 근거에서도 초안 내용이 틀리면 올바른 판단이 흔들리는가'다.
  초안 없는 E가 교정한 8건에서 R의 답 방향이 잘못된 초안을 따른 관찰은 출발점이지 확증이 아니다.
  현재 frozen R의 확대·LoRA·새 방법 개발·prompt 순회는 하지 않는다.
- 공개 정답이 연결되는 미사용 환자를 우선해 영상·자동 근거·공통 지시를 고정하고 초안 없음/
  맞는 초안/틀린 초안만 바꾸는 paired 비교를 설계한다. 선택·평가에 쓴 환자와의 중복을 확인한다.
  같은 RSNA의 미사용 환자는 새 개발 표본이지 독립 도메인·사전학습 미노출이 아니다. 자료 이름만
  바꾸거나 새 데이터 승인을 기다리는 일을 목표로 삼지 않는다. 합성 초안 개입임을 명시하고
  자연 발생 오류의 빈도·효용으로 외삽하지 않는다. 초안 생성에는 정답을 쓰되 그 정오 표시는
  모델에 제공하지 않으며 일반 자동 근거와 평가 정답을 혼합하지 않는다.
- 출력 전 평가를 고정한다. 명시적 최종 답 방향, 유보/조건 표현, 답변 거부·파싱 불가를 구분해
  내용 판단 변화와 확정 답변률 저하를 분리한다. 모든 유보를 오답 또는 성공으로 바꾸지 않는다.
  명시 답·모순·조건부·거부 fixture로 한정 검증하고 자유 판독문 평가기 정비로 확대하지 않는다.
  기초 수행은 초안 없는 전체 집단에서 함께 보고하며 잘 맞힌 환자만 본표본으로 선택하지 않는다.
  조건부 하위집단 분석은 사전 정의하고 전체 분모·반대 사례·불확실성을 함께 보고한다.
- 표본·최대 요청량·작은 기술 검사·종료 조건을 사전에 정하고 적합성 확인과 실제 비교를 같은
  계획에 담는다. 보조 조건의 100% 성공 등 불필요한 진입 gate를 추가하지 않는다. 단순 초안 무시,
  기존 M/S와 같은 강한 단순 대안으로 충분한지와 추가 추론 비용을 구분한다. 새 자료에서 대조가
  성립하지 않으면 옛 M/S 수치를 직접 비교하지 말고 가능한 비교와 한계를 명시한다.
- 생성 worker의 GT/labels hash 접근을 제거하고 평가 전용 무결성 검사는 부모에서 수행하도록
  재사용 경로를 보완한다. 합성 초안이 포함된 잠금 요청만 생성에 전달하고 정답 파일 접근을
  시험한다. 실제 재사용 실행 경로의 재개 안전성도 필요한 범위에서 확인한다. 전체 코드 정비나
  이미 끝난 실험 재생성을 하지 않는다.
- 양성이어도 제한된 초안 민감성 관찰일 뿐이다. 가까운 기존 교정·초안 편향 연구가 해결한 범위와
  구별할 기술 질문이 있는지 확인하고 기본 인식 부족·평가 영향·단순 대안으로 설명되는 부분을
  제외한다. 일반 VLM 한계나 신규성을 선언하지 않는다. 음성 또는 다시 판별 불가이면 현재 후보를
  보류하고 같은 자료의 문구/점수 탐색으로 연장하지 않는다. 중요한 잔여 현상이 있어도 후속은

한 번만 해소하려는 사용자 승인 보완이다. 구현은 Claude, 종료 후 다음 반복은 사용자 승인을 기다린다.
GOAL과 이전 관찰은 유지하며 가설·신규성·최종 방법을 이번 분석만으로 확정하지 않는다.

## 초기 질문과 경쟁 설명

첫 전략 계획에서 아래 후보를 비교하고 우선할 질문 하나와 선택 이유를 적는다. 모두를 전수 실행하거나
아래 현상이 이미 확인됐다고 가정하지 않는다. 조사 중 더 중요한 연결 질문이 나오면 근거를 남겨 구체화한다.

1. **누락 감소 vs 언급 성향:** 위치 SFT가 영상 인식을 개선하는가, 아니면 이상을 더 쉽게 언급하게 하는가?
2. **위치–문장 연결:** 올바른 영역을 찾는 능력과 소견·속성·부정 표현을 정확히 기술하는 능력이 어디에서 갈리는가?
3. **전이와 보존:** 학습한 소견 밖으로 효과가 이어지는가? 다른 소견·정상 판독에 손상이 생기는가?

새 loss나 대규모 학습부터 시작하지 않는다. 그렇다고 모든 원인·신규성·타 모델 재현의 최종 증명을
기다리며 진단만 반복하지도 않는다. 중요한 유효 관찰이 있으면 기존 policy의 최소 method pilot을 허용한다.

## 문헌 → 재현 확인 → 확장 검증

- 첫 회차는 기존 근거 인계와 가까운 연구 비교, 첫 실제 모델 비교 설계로 시작한다. 실행 가능한
  한정 검사가 결정되면 같은 계획에서 진행해도 된다. 문헌만 무기한 반복하거나 즉시 전체 재학습하지 않는다.
- CURE(https://arxiv.org/abs/2601.15408, https://github.com/PabloMessina/CURE),
  MAIRA-2(https://arxiv.org/abs/2406.04449), 영역 기반 판독 방식과 선택 질문에 가까운 최신 연구를 확인한다.
  논문 주장 / 실제 학습·평가 조건 / 가까운 대조군 / 미검증 조건 / 반대 근거를 구분한다.
- 공개 checkpoint의 공식 입력·prompt·processor·좌표·라이선스·revision을 확인한다. 공식 조건의 재현 확인과
  새로운 조건의 확장 검증을 별도 표시한다. 우리의 확장 조건 실패를 논문의 재현 실패라 하지 않는다.
- CURE 공개 adapter는 `google/medgemma-4b-it` 기반이며 현재 RSNA adapter는 `google/medgemma-1.5-4b-it`
  기반이다. 채택 시 공식 카드/config를 재확인한다. CURE를 임의로 1.5에 로드하지 않으며, 각자의 정확한
  base→adapter 비교와 시스템 간 비교를 구분한다. 서로 다른 학습량·데이터·모델의 순위를 방법 효과로 해석하지 않는다.
- CURE가 해결했다면 해당 성공을 받아들이고 주장을 좁히거나 다른 잔여 질문을 선택한다. 선행의 실패를
  반드시 찾아내는 임무가 아니다. 논문이 평가하지 않은 조건은 실험 후보이지 이미 입증된 한계가 아니다.

## 데이터·평가·비교군

- RSNA는 출발 진단 자산이다. 문장·위치·판독문 정답이 필요한 질문에는 PadChest-GR 등 기존 승인 자산을
  우선 점검하고 필요한 자료만 확대한다. 실제 라벨 의미·환자/원천 분리·모델 학습 노출을 기록한다.
  미표기 소견을 정상으로 간주하지 않는다. 공개 모델의 학습 자료를 독립 test라 부르지 않는다.
- 문장 언급률만으로 영상 인식 개선을 주장하지 않는다. 누락·잘못된 언급·불확실 표현·형식 실패·모순을
  구분하고, 같은 FP 수준의 누락 또는 precision–recall 관계를 가능한 평가에서 함께 본다.
  bbox 일치, 판독 사실성, 언어 유창성을 별도 평가한다. 정답 문서도 완전한 임상 gold라고 가정하지 않는다.
- 자동/LLM 문장 평가는 근거 문구와 모호성을 보존하고 표본 수동 점검·민감도 분석으로 평가 오류를 확인한다.
  assistant 검토를 전문의 검토로 부르지 않는다. 평가자 합의만으로 임상 사실을 확정하지 않는다.
- 이미지 교환·crop 등 대조는 질문에 적합할 때만 쓴다. bbox를 가렸다고 임상 정답이 정상으로 바뀐다고
  가정하지 않는다. 잘못된 입력·정보량 차이·prompt 차이·출력 cap을 모델의 근본 한계와 구분한다.
- 단계적으로 base/box-only SFT, report-only SFT, 강한 공동 학습, detector/grounder+reporter를 검토한다.
  모든 대조군을 첫 pilot의 선행 조건으로 만들지 않는다. 방법 효과 주장 시 데이터·노출·학습 예산을 통제한다.
- 판독 개선 연구에 detector보다 높은 bbox 점수를 필수 통과 조건으로 두지 않는다. 최종 판독의
  정확도·누락·근거 일치·효율 중 주장에 맞는 이점과 강한 모듈형 판독 대조를 평가한다.

## 수렴과 실행

- 안정된 research_track(예: grounding-report-transfer), related_iterations로 위 기록과 연결한다.
  같은 관찰의 구체화인지 다른 질문 전환인지 명시한다. 새 데이터·모델·branch로 이력을 초기화하지 않는다.
- 각 계획: 이어받는 관찰 → 경쟁 설명 → 이번에 구분할 비교 → 양성/음성/불확정별 다음 판단을 적는다.
  작은 표본의 불확정에는 판별력을 높일 근거 있는 확대를 허용한다. 일률적인 시간/iteration 상한은 추가하지 않는다.
- 큰 학습 투자 전에 핵심 현상·가까운 선행 이후의 잔여 문제·최소 개입의 목적을 기존 Strategy Check에
  정리한다. 단순 오답 발견·새 모델 순위·추가 loss 이름을 contribution으로 삼지 않는다.
- 관찰만 보존하며 끝없이 후보를 옮기지 않는다. 기존 대안이 충분하면 종료 범위와 재개 조건을 명시한다.
  주변 코드 전수 정비 대신 실제 쓸 경로만 검증한다. 완료한 불변 검증은 출처를 연결해 재사용한다.
- GPU 두 장은 RESOURCE_POLICY에 따라 활용한다. 현재 사용자 환경 지시대로 기본 환경과 캐시는 변경하지
  않으며 패키지 설치·환경 변경이 필요하면 먼저 알린다. 기존 모델/사고 등급·smart·한도 재시도 규칙은 유지한다.
- 문헌 전용 discovery와 TOF 실험을 재개하지 않는다. 기존 연구 Telegram에 연구 질문·현재 단계·직전 결과와의
  연결·남은 판단을 짧게 알린다. 중요한 실제 관찰만 강조하고 실행 완료를 가설 입증이라고 하지 않는다.
