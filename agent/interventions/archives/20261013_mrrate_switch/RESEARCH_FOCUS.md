# 현재 연구 초점 — 의료 VLM의 위치·영상 근거 활용

## 목적과 적용

최종 GOAL은 유지한다. 위치 정보를 활용한 학습·영역 근거가 의료 VLM의 판단을 어떻게 바꾸는지,
강한 기존 방법 이후에도 중요한 문제가 남는지 좁힌다. bbox 점수·LoRA·MedGemma 성공 자체가 목표가 아니다.
RSNA·X-ray·MRI·한 모델에 고정하지 않는다. 공개 정답으로 판단 가능한 범위에서 선택한다.
원 기록·판정은 보존하고 새 요구를 소급 blocker로 추가하지 않는다.
2026-10-13 보완은 운영 구조 정리다. 새 실험 승인·GOAL 변경·과거 gate 완화가 아니다.

## 현재 질문 카드 — iter_120 종료 기준

- 중요한 문제: 참고 영상의 지정 대상 정보를 다른 view의 대상 선택에 제대로 전달하는가?
  위치를 찾는 기본 능력과 대상 정보를 전달하는 능력을 구분하려는 질문이다. 유망성이 확정된 주제는 아니다.
- 현재 근거: iter_120은 Task3 1,148행에서 적격 동일-target 관계쌍 0개로 모델 실험 전에 종료했다.
  자료 조건 불충족이지 모델 실패가 아니다. iter_019/021의 좌표 복사·기본 위치 성능 혼선은 반대 근거다.
- 쉬운 해결책: 좌표 복사·영상 매칭·언어로 설명한 뒤 찾기·공식 대응 모델을 비교할 필요가 있다.
  현재 조건에서 실제 비교는 미실행이며, 기존 방법이 충분한지 모른다.
- 남은 설명: 데이터의 관계 부재 / 기본 인식 부족 / 대상 전달 실패 / 단순 분해의 충분성을 아직 구분 못 했다.
  공개 주석으로 관계를 보장할 수 있는지부터 확인해야 한다. 임상 의미를 추측한 관계 구성은 허용하지 않는다.
- 다음 결정: 현재 승인 대기다. 다음 실행 승인 후, 핵심 자료 조건과 제한된 구성 가능성을 먼저 확인하고
  성립하는 경우에만 상세 비교를 설계한다. 안 되면 그 범위의 자료 부적합과 질문의 가치 부족을 구분한다.
  관계 구성을 이미 승인된 완성 실험처럼 실행하거나 Task3의 같은 집계를 반복하지 않는다.

근거: agent/runs/iter_120/plan.md, review.md. 새 승인·후속 리뷰가 있으면 그 기록이 이 날짜의 카드보다 우선한다.
후속 plan/review는 research_track/related_iterations와 Strategy Check의 같은 다섯 항목을 갱신한다.
매번 이 파일에 iteration별 장문 지시를 누적하지 않는다. 현재 판단의 출처와 변경점만 남긴다.

## 현재 범위와 보호할 것

- 공개 정답으로 기술 질문을 좁히기: 존재·위치·대상 관계 등 주석이 보장하는 것만 평가한다.
  자유 판독문 전체의 임상 의미 평가·외부 전문의 검토는 현재 범위 밖이다. discovery·TOF는 재개하지 않는다.
- 연구 질문을 먼저 정하고 공개 자료·평가·강한 대조를 함께 선택한다. 데이터 하나가 맞지 않으면
  허용된 한정 자료 구성의 가능성을 볼 수 있으나 접근·라이선스·예산을 넘거나 정답을 만들어내지 않는다.
- 현재 초안 교정 묶음과 CURE 특화 오류 검토는 보류다. 기존 RSNA 표 재분석·초안 무시 prompt·
  selector 학습·이름만 바꾼 오류 검토로 재개하지 않는다. 재개에는 질문을 바꿀 구체적인 새 근거가 필요하다.
- 118의 합성 초안 손상은 유효한 제한적 관찰이다. 119의 자연 답 상보성은 방법 필요성의 확증이 아니다.
  원 출력의 재채점으로 투자 근거를 만들지 않는다. 현재 자료에서의 보류를 모든 교정 연구의 기각으로 읽지 않는다.
- 최종 신규성·타 모델 재현을 모든 작은 원인 검증의 선행조건으로 요구하지 않는다.
  작은 method pilot과 본격 개발의 기준은 RESEARCH_POLICY.md를 따른다. 모델 기본 부적합도 별도 설명이다.
- GPU 두 장을 RESOURCE_POLICY에 따라 활용한다. 과거 일회성 CPU-only 제한은 일반 정책이 아니다.
  필수 검증·원본 보존·개발/test 분리·정답 비누수는 유지한다.
- 구현 기본 의사는 Claude이며 실제 담당은 저장된 실행 설정과 사용자 지시를 따른다. 모델 등급은 변경하지 않는다.
  --confirm-each-iter를 유지하고 이후 반복은 승인 없이 시작하지 않는다. 보완 적용만으로 재개하지 않는다.

## 관련 이력 찾아보기

RESEARCH_HISTORY_INDEX.md는 관련 원 리뷰·보류 이유를 찾는 색인이다. 과거 지시는 역사 자료이며 현재 실행 명령이 아니다.
새 질문에 관련된 원문만 확인하고 전체 아카이브를 매 호출 읽지 않는다. 같은 기록을 검증 없이 새 사실로 재분류하지 않는다.
