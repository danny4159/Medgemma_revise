# iter_110 범위 선택에 대한 사용자 승인

사용자는 '자유 판독문 전체의 정확성 검증은 보류하고, 공개 정답이 있는 소견을 미리 지정해 판단과
위치 근거가 함께 맞는지 확인하며 강한 단순 대안 이후의 문제를 검증하는 과제로 조정'하자는 제안에
'그래'라고 승인했다. 이 범위로 재계획하고 재개한다. 구현은 Claude, 반복 종료 후 사용자 승인은 유지한다.

## 유지·보존

GOAL, 이전 가설의 원 판정·코드·출력·checkpoint를 보존한다. iter_110은 Claude 작업이 없는 계획
확인 단계이므로 빈 구현을 시작하거나 성공/실패 실험으로 기록하지 않는다. 원 계획을 보존한 뒤
새 반복에서 GPT가 실제 실행할 비교를 설계한다. 같은 범위 선택을 다시 묻지 않는다.

## 새 계획의 과제와 비교

agent/RESEARCH_FOCUS.md 맨 앞 '현재 적용 범위 — iter_110 이후 사용자 승인'을 우선 적용한다.
사전 지정 소견의 판단과 위치 근거를 공개 정답으로 함께 평가한다. 환자 정답을 질문으로 누설하지 않고,
명시적 oracle 대조는 별도 표시한다. 존재/부재 정답과 양성 위치 정답의 schema·분할·학습 노출을 확인하며
미표기를 음성으로 만들지 않는다. 양성 phrase 위치 찾기를 소견 존재 판단과 같은 과제로 비교하지 않는다.

기술적 질문 하나와 중요한 사용 조건을 구체화하고, 가까운 선행 및 detector/grounder+판단 규칙 같은
강한 단순 대안 이후의 잔여 가치를 반박 가능한 비교로 판단한다. 점수 순위만으로 기여를 주장하지 않고
판단/근거가 함께 맞는다는 관찰과 근거를 실제로 사용한다는 인과적 주장을 구분한다.

## 실행과 종료

데이터/모델은 아직 미정이며 기존 승인 자산 우선이다. 관련 과거 반대 근거를 이어받고 전체 이력
재감사는 하지 않는다. 자료·응답·평가 적합성 한정 점검과 성립 시 작은 실제 비교를 같은 계획에 포함한다.
결과별 다음 투자 결정을 사전에 적고, parser·확대/종료 기준을 구현자가 임의 변경하지 않는다.
성립하지 않으면 이유와 선택지를 보고하며 무리한 생성·방법 개발은 하지 않는다. 종료한 crop·parser
분석, 자유 문장 임상 재판정, 외부 전문가 대기, discovery·TOF를 재개하지 않는다.

이번 재계획과 조건부 비교 실행은 승인됐다. 후속 반복은 --confirm-each-iter로 결과·한계·추천과
대안을 Telegram에 보고한 뒤 사용자 확인을 받는다. 목표 변경이나 --reset은 하지 않는다.
